OpenWalkieTalkie 0.15.0 把伴侣应用带到了 Omarchy，并让对讲机在那里成为听写麦克风：
- 伴侣应用可以在 Omarchy（Linux）上运行，出现在应用启动器里；
- 在 Omarchy 页上按住 PTT，即可在光标处听写；
- Omarchy 页上的滚轮按你看到的窗口顺序移动；
- 服务在 Linux 上把所有文件放在同一个目录里。

对讲机固件没有变化，仍是 0.14.0。

## Omarchy 上的伴侣应用

Mac 和 Windows 上的应用现在也能在 Omarchy（Hyprland）上运行，在应用启动器里叫 **OpenWalkieTalkie**，同样有五个页面：**设备**、**页面与按键**、**集成**、**语音**和**服务**。它会自己找到服务。在 Linux 上：

- **服务 › 登录时启动 / 停止** 对应服务的 systemd 用户单元（`deckd.service`），从窗口重启服务也由这个单元完成。
- **登录时打开** 是一个 XDG 自动启动项，由 Omarchy 的会话启动。
- 没有托盘图标（这是桌面状态栏的事），也没有应用内更新：应用从源码构建，更新就是 `git pull`、构建，再运行一次 `install.sh`。

**页面与按键** 也能适应比设计宽度更窄的平铺窗口（比如屏幕的四分之一）：页面列表会换到第二行，按键编辑区会移到按键网格下方。

安装时，把它和服务一起构建，再一起交给 `install.sh`；步骤见 [Omarchy 指南](https://openwalkietalkie.org/docs/omarchy/)。

## 在 Omarchy 页上听写

在 Omarchy 页上，PTT 的用法和 Superwhisper 自己的按住说话一样：按住说话，松开后，文字会输入到当前接收键盘的窗口的光标处，不会自动回车。按住时按 CANCEL 会放弃这次录音，什么也不输入。装了 Superwhisper 时由它识别，使用它自己的模式、语言和词汇；否则由本机的 Whisper 模型识别。

背后的做法是：Omarchy 适配器在名册上放一个 **Dictate** 条目，在对讲机显示 Omarchy 页时把它设为对讲机的当前频道，离开时再换回你原来的频道。在“助手”页选中 **Dictate** 再按 PTT，也会同样听写。

## 滚轮跟随窗口列表

在 Omarchy 页上，滚轮现在按页面列出的顺序在窗口之间移动，和它在对讲机其他列表里的方向一样，到第一行和最后一行时停住。以前它跟随 Hyprland 自己的窗口顺序，转一格可能会跳过下一行。

## Linux 上只用一个目录

在 Linux 上，服务现在把配置、状态、日志、缓存和 socket 都放在同一个目录 `~/.local/share/openwalkietalkie`（或 `$XDG_DATA_HOME/openwalkietalkie`）里，和 Mac 上用一个目录一样。Omarchy 上的服务本来就在这里运行，所以 Omarchy 安装不用搬任何东西，`deckd` 命令也不再需要 `DECKD_DATA_DIR=…` 前缀。如果你在 Linux 上手动运行过使用旧 XDG 布局（配置在 `~/.config`、socket 在 `$XDG_RUNTIME_DIR` 下）的 `deckd`，它现在会去新目录找：把文件搬过去，或者设置 `DECKD_DATA_DIR`。

## 更新

在 Mac 上选择 **检查更新…**，或者安装已签名、已公证的 **0.15.0** 应用（Apple 芯片或 Intel，macOS 13 及以上）。在 Windows 上，从发布页下载 ZIP。在 Omarchy 上，拉取代码，构建服务和应用，再用这两个文件运行 `install.sh`，步骤见 [Omarchy 指南](https://openwalkietalkie.org/docs/omarchy/)。这个版本不需要更新对讲机固件。
