0.11.0 版把裝置連接到 Conol 桌面應用程式中的對話。在手持裝置上開啟聊天、閱讀最近的訊息、口述後續訊息，或回答提問。同樣的本機配套程式介面也開放給其他應用程式。

你的 Conol 對話，集中在一起

相容的 Conol 桌面應用程式執行並登入後，聊天會出現在 Conol 底下，帶有它的機器人馬賽克圖案與一個 + New chat 啟動器。選擇一段對話，就能查看最近公開的使用者與助理訊息。按住 PTT 口述後續訊息，或對著啟動器口述來建立新聊天。

建立的聊天會在裝置上開啟，等待你的下一則訊息。Conol 會自動找到本機的 OpenWalkieTalkie 服務；沒有需要設定的終端機掛鉤或另外的模型 API 金鑰。這個連線需要具備 OpenWalkieTalkie 橋接的 Conol 桌面應用程式；瀏覽器版不會連線到本機服務。

在手持裝置上回答整份表單

Conol 可以把 AskUser 表單與工作流程核准一次一題地呈現出來。翻閱單選題、切換多選、口述自由文字回答，然後先檢閱與修改，再明確送出整份表單。配套程式的通訊端重新連線後，草稿回答仍會保留。無法以這種方式完成的表單會在 Conol 中開啟。

工作階段面板顯示對話實際使用的模型與思考強度。對 Conol 而言，這些目前是唯讀的；請在 Conol 中變更。對話記錄同步公開的使用者與助理文字。圖片、工具輸出與私人的推理過程則留在所屬的應用程式中。

對其他應用程式開放

這個整合使用公開的 JSON-RPC 介面。應用程式可以透過 agent.companion.set 提供自己的分組與新聊天啟動器，發布訊息與提問，並透過 agent.session.set 回報實際的模型與思考強度。支援可編輯設定的應用程式，會依確切的修訂版本確認每一次要求的變更。

新的原生配套程式指南說明了探索、註冊、對話記錄、表單、設定與重新連線。試試獨立的 Python 範例：它使用預先寫好的回覆，不需要模型 API 金鑰，沒有安裝 Conol 也能執行。自動產生的 API 參考資料記錄了請求結構描述與權限。

讓新的聊天保持焦點

服務現在會在聚焦之前，先告知被取代的槽位由誰接手。裝置會在放開 PTT 後立刻跟隨配套程式的明確選擇；有輸入被按住時會等待；如果你瀏覽到別處，它會讓步。未完成的提問會維持開啟。

八個共用槽位的上限不變。開啟一個溢出的配套程式聊天，可以取代同一連線、同一應用程式與同一帳號下一個未釘選的同層聊天，同時保留啟動器與其他帳號正在忙碌的聊天。

更新到 0.11.0

安裝已簽署並經過公證的 Mac 應用程式（Apple Silicon 或 Intel），或選擇檢查更新。需要 macOS 13 或更新版本。透過 USB-C 連接裝置，然後選擇服務 → 更新 → 檢查韌體更新。原生配套程式支援需要 Mac 上的服務與韌體都是 0.11.0。如果舊的服務仍在執行，請選擇服務 → 重新啟動。另外也請把 Conol 更新到具備 OpenWalkieTalkie 橋接的版本。

一般更新會保留設定與藍牙配對。復原協定 2 與快閃記憶體配置不變。另外的原廠 ZIP 用於生產，會覆寫設定與配對。

自動化測試涵蓋擁有權、分組、槽位提升、設定確認、焦點順序、按住的輸入、協定解析、繪製，以及範例中的表單與重新連線。本版本沒有重做實際的 Conol 對話測試與主機板測試。
