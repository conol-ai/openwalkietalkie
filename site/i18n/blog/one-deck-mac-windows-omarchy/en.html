Version 0.14.0 is the largest release so far. The Mac app becomes the deck's companion, the service also runs on Windows and on Omarchy, Grok Bot joins Claude Code and Codex on the deck, and the deck confirms its own firmware installs.

A companion for the deck

Sessions are read and answered on the deck, and no session text reaches the app's window. The window looks after the deck and the service around it, on five pages: Deck, Faces & Keys, Integrations, Voice and Service. Integrations shows whether each source is arriving, with Send a Test Question and Set Up or Repair for each one. Service has Check my setup, Export Support File, the updates, and everything installed, with Uninstall. A first run installs nothing until you choose Add These.

The roster, card answers, the order box and the Usage page left the window, because the deck has them. ENTER on a session's card brings that session's own app forward, with no Automation permission. Settings are kept per deck, the service checks for updates itself, and it stops collecting 10 minutes after the deck unlinks.

Grok Bot joins Claude Code and Codex

Grok Bot, xAI's teammate app, is the newest integration. Each bot is a row on the deck's own Grok Bot page, drawn with the Grok mark. A press on a bot goes to the webhook of a routine in that bot. The bot answers by running deckd grokbot say on your computer: a short version of its answer appears on the deck and is read out, and the whole answer stays in the bot's chat. A bot can also ask you something on the deck and get your choice back.

To add a bot on a Mac, open Integrations → Grok Bot → Bots…, type its name and choose Copy Prompt. Send the prompt to the bot in Grok Bot's chat, and the bot makes its own routine. Copy the routine's POST to URL and key back into the dialog, then allow the bot to run commands in Grok Bot's Settings → Computer. A command a bot runs can report to the deck, but cannot answer another session's card or change a setting.

Windows, as a preview

The service and the companion app now run on Windows 10 and 11 (x64): the System face, Claude Code, Claude Channels, Codex, the Macropad, voice, Grok Bot, the tray icon, start at sign-in and in-app updates. Every release now includes an unsigned ZIP for Windows. Because it is unsigned, SmartScreen asks for More info → Run anyway, and Smart App Control blocks it. The Windows install guide walks through it.

Omarchy

On an Omarchy (Hyprland) machine, the Linux service and the Omarchy bridge put that machine's Claude Code, Codex and Kimi Code sessions on the deck. The Omarchy face switches windows and workspaces, and voice orders are typed into the session's terminal. Superwhisper recognises your presses when it is installed, and the Macropad types through uinput, so Omarchy's Super shortcuts work. The Omarchy guide covers the build and the install.

The deck confirms its own updates

From firmware 0.14.0 on, a firmware update starts only when you press ENTER on the deck. CANCEL, the timeout, voice and the API install nothing. The update from 0.13 to 0.14 is still confirmed in the app, and a deck in recovery mode installs at once.

A question's notice now takes the next ENTER, so the next press opens the question and the one after answers it. Jumping to a new question also leaves a running Timer, a ringing alarm and a game alone.

Changes to know about

  • The ancestry cap now catches a natively installed Claude Code. Admin deckd commands run inside Claude Code or Codex are refused; run them from a terminal of your own.
  • The local TCP door is off by default and will be removed in the next release.
  • Claude usage on the deck's Usage face is now opt-in, and the service no longer records from the Mac's microphone when the deck's cannot be used.

Update

On a Mac, choose Check for Updates…, or install the signed, notarized 0.14.0 app for Apple Silicon or Intel (macOS 13 or later). Then, with the deck connected by USB, open Service → Updates, choose Check beside the deck, then Review… and Install. The regular update preserves settings and Bluetooth pairing. On Windows, download the ZIP from the release and follow the Windows guide.
