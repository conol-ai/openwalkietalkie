バージョン 0.14.0 は、これまでで最大のリリースです。Mac アプリがデバイスの管理アプリになり、サービスは Windows と Omarchy でも動くようになりました。Grok Bot が Claude Code と Codex に加わり、ファームウェアのインストールはデバイス自身が確認します。

デバイスの管理アプリ

セッションはデバイスで読んで答えます。セッションの内容がアプリのウィンドウに届くことはありません。ウィンドウはデバイスとその周りのサービスを管理するもので、5 つのページがあります：デバイス、ページとキー、連携、音声、サービス。「連携」には各接続元からデータが届いているかが表示され、接続元ごとにテスト質問を送信と、設定するまたは修復があります。「サービス」にはセットアップを確認、サポートファイルを書き出す、更新、インストールされたものすべてとアンインストールがあります。初回起動では、これらを追加を選ぶまで何もインストールされません。

エージェント一覧、カードでの回答、指示の入力欄、「使用量」ページはウィンドウからなくなりました。デバイスにあるからです。セッションのカードで ENTER を押すと、そのセッションのアプリが前面に出ます。オートメーションの権限は要りません。設定はデバイスごとに保存され、サービスは自分で更新を確認し、デバイスの接続が切れてから 10 分後に収集を止めます。

Grok Bot が Claude Code と Codex に加わる

xAI のチームメイトアプリ Grok Bot が、最新の連携です。ボットはそれぞれ、デバイスのGrok Botページに 1 行ずつ、Grok のマーク付きで並びます。ボットを押すと、そのボットのルーティンの Webhook に届きます。ボットはパソコン上で deckd grokbot say を実行して答えます。答えの短い版がデバイスに表示されて読み上げられ、答えの全文はボットのチャットに残ります。ボットからデバイスで質問し、選んだ答えを受け取ることもできます。

Mac でボットを追加するには、連携 → Grok Bot → ボット…を開き、名前を入力してプロンプトをコピーを選びます。そのプロンプトを Grok Bot のチャットでボットに送ると、ボットが自分でルーティンを作ります。ルーティンのPOST先 URL とキーをダイアログにコピーし、Grok Bot の設定 → コンピューターで、ボットがコマンドを実行できるようにします。ボットが実行したコマンドはデバイスに報告できますが、ほかのセッションのカードに答えたり、設定を変えたりはできません。

Windows（プレビュー版）

サービスとアプリが Windows 10 と 11（x64）で動くようになりました。対応するのは「システム」ページ、Claude Code、Claude Channels、Codex、マクロパッド、音声、Grok Bot、タスクトレイのアイコン、サインイン時の起動、アプリ内アップデートです。各リリースには、署名なしの Windows 用 ZIP が含まれるようになりました。署名がないため、SmartScreen では詳細情報 → 実行を選ぶ必要があり、スマート アプリ コントロールではブロックされます。手順はWindows インストールガイドで説明しています。

Omarchy

Omarchy（Hyprland）のマシンでは、Linux のサービスと Omarchy ブリッジが、そのマシンの Claude Code、Codex、Kimi Code のセッションをデバイスに表示します。Omarchy のページではウィンドウとワークスペースを切り替えられ、音声での指示はそのセッションのターミナルに入力されます。Superwhisper がインストールされていれば、押している間の音声は Superwhisper が認識します。マクロパッドは uinput で入力するので、Omarchy の Super ショートカットも使えます。ビルドとインストールはOmarchy ガイドで説明しています。

更新はデバイスが確認する

ファームウェア 0.14.0 以降、ファームウェアの更新はデバイスで ENTER を押したときにだけ始まります。CANCEL、タイムアウト、音声、API では何もインストールされません。0.13 から 0.14 への更新は引き続きアプリで確認します。リカバリーモードのデバイスはすぐにインストールします。

質問の通知が次の ENTER を受け取るようになりました。次に押すと質問が開き、その次に押すと答えます。新しい質問に移っても、動いているタイマー、鳴っているアラーム、ゲームはそのままです。

知っておきたい変更

  • 親プロセスの制限が、ネイティブインストールした Claude Code も捉えるようになりました。Claude Code や Codex の中で実行した管理用の deckd コマンドは拒否されます。自分で開いたターミナルから実行してください。
  • ローカルの TCP の窓口は既定でオフになり、次のリリースで削除されます。
  • デバイスの「使用量」ページでの Claude の使用量は、オンにした場合だけ表示されます。また、デバイスのマイクが使えないときに、サービスが Mac のマイクで録音することはなくなりました。

アップデート

Mac ではアップデートを確認…を選ぶか、Apple Silicon または Intel（macOS 13 以降）用の、署名・公証済みの 0.14.0 アプリをインストールします。次に、デバイスを USB で接続したままサービス → 更新を開き、デバイスの横の確認を選んでから、内容を確認…とインストールを選びます。通常の更新では、設定と Bluetooth のペアリングは保持されます。Windows では、リリースから ZIP をダウンロードし、Windows ガイドに従ってください。
