0.14.0 版是迄今为止最大的一次发布。Mac 应用成为设备的配套应用，服务也能在 Windows 和 Omarchy 上运行，Grok Bot 与 Claude Code、Codex 一起出现在设备上，固件安装由设备自己确认。

设备的配套应用

会话在设备上阅读和回答，会话内容不会进入应用的窗口。窗口负责照看设备和它周围的服务，共有五个页面：设备、页面与按键、集成、语音和服务。“集成”显示每个来源是否有数据进来，每个来源都有发送测试提问，以及设置或修复。“服务”提供检查安装状态、导出支持文件、各项更新和所有已安装的内容，并带有卸载。首次运行时，在你选择添加这些项目之前，什么都不会安装。

助手列表、卡片上的回答、指令输入框和“用量”页面已从窗口中移除，因为设备上都有。在会话卡片上按 ENTER，会把该会话所在的应用切到前台，不需要“自动化”权限。设置按设备分别保存，服务会自己检查更新，设备断开连接 10 分钟后服务停止收集数据。

Grok Bot 与 Claude Code、Codex 一起加入

Grok Bot 是 xAI 的团队协作应用，也是最新的集成。每个机器人在设备自己的Grok Bot页面上占一行，带有 Grok 标志。在某个机器人上按下按键，会发送到该机器人中某个例行任务的 Webhook。机器人在你的电脑上运行 deckd grokbot say 来回复：回复的简短版本显示在设备上并被朗读，完整回复留在机器人的聊天中。机器人也可以在设备上向你提问，并收到你的选择。

在 Mac 上添加机器人：打开集成 → Grok Bot → 机器人…，输入它的名称，然后选择复制提示词。在 Grok Bot 的聊天中把提示词发给该机器人，机器人会自己创建例行任务。把例行任务的POST 到网址和密钥复制回对话框，然后在 Grok Bot 的设置 → 电脑中允许机器人运行命令。机器人运行的命令可以向设备报告，但不能回答其他会话的卡片，也不能更改设置。

Windows 预览版

服务和配套应用现在可以在 Windows 10 和 11（x64）上运行：“系统”页面、Claude Code、Claude Channels、Codex、“快捷键”页面、语音、Grok Bot、托盘图标、登录时启动和应用内更新。每个版本现在都包含一个未签名的 Windows ZIP 包。由于未签名，SmartScreen 会要求你选择更多信息 → 仍要运行，智能应用控制则会阻止它。Windows 安装指南会一步步说明。

Omarchy

在 Omarchy（Hyprland）电脑上，Linux 服务和 Omarchy 桥接程序会把这台电脑上的 Claude Code、Codex 和 Kimi Code 会话放到设备上。Omarchy 页面可以切换窗口和工作区，语音指令会输入到该会话的终端中。装有 Superwhisper 时，由它识别你每次按键说的话；“快捷键”页面通过 uinput 输入，所以 Omarchy 的 Super 组合键可以使用。Omarchy 指南介绍了构建和安装。

设备自己确认更新

从固件 0.14.0 起，只有在设备上按下 ENTER，固件更新才会开始。CANCEL、超时、语音和 API 都不会安装任何东西。从 0.13 到 0.14 的更新仍在应用中确认，处于恢复模式的设备会立即安装。

提问通知现在会接住下一次 ENTER，所以下一次按键打开提问，再下一次回答它。跳到新提问时，也不会打断正在运行的计时器、正在响的闹铃和游戏。

需要了解的变化

  • 祖先进程限制现在也能识别原生安装的 Claude Code。在 Claude Code 或 Codex 中运行的管理类 deckd 命令会被拒绝；请在你自己的终端中运行。
  • 本地 TCP 入口默认关闭，并将在下一个版本中移除。
  • 设备“用量”页面上的 Claude 用量现在需要手动开启；设备的麦克风无法使用时，服务也不再改用 Mac 的麦克风录音。

更新

在 Mac 上，选择检查更新…，或安装已签名并经过公证的 0.14.0 应用，支持 Apple Silicon 和 Intel（macOS 13 或更高版本）。然后用 USB 连接设备，打开服务 → 更新，选择设备旁的检查更新，再选择查看…和安装。常规更新会保留设置和蓝牙配对。在 Windows 上，从发布页面下载 ZIP 包，并按照 Windows 指南操作。
