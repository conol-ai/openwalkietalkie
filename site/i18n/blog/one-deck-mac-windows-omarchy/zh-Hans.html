0.14.0 是迄今为止内容最多的一次更新。Mac 软件专注于管理对讲机和配套服务，服务也能在 Windows 和 Omarchy 上运行。除了 Claude Code 和 Codex，对讲机现在还能连接 Grok Bot；安装固件前，也需要在设备上亲自确认。

专门管理对讲机的配套软件

在对讲机上阅读和回复会话，软件窗口不接收会话正文。电脑端专门管理设备和服务，分为五页：Deck、Faces & Keys、Integrations、Voice、Service。Integrations 显示各来源是否有数据接入，每项都提供 Send a Test Question，以及 Set Up 或 Repair。Service 包含 Check my setup、Export Support File、更新功能和已安装组件列表，并提供 Uninstall。首次运行时，只有选择 Add These 才会安装组件。

助手列表、卡片答复、指令输入框和 Usage 页面已从电脑端窗口移除，这些操作由对讲机承担。在会话卡片上按 ENTER，会将对应会话所属的应用切到前台，无需自动化权限。每台对讲机分别保存设置；服务会自行检查更新，并在设备断开十分钟后停止采集。

Grok Bot 加入 Claude Code 和 Codex

xAI 的队友应用 Grok Bot 是这次新增的集成。每个机器人在对讲机专属的 Grok Bot 页面中占一行，并显示 Grok 标志。向某个机器人按键说话，会将请求发送到它的一条自动化流程的 webhook。机器人在你的电脑上运行 deckd grokbot say 来回复：简短答复会显示在对讲机上并朗读，完整回答保留在机器人聊天中。机器人也能在对讲机上提问，再接收你的选择。

在 Mac 上添加机器人：打开 集成 → Grok Bot → 机器人…，输入机器人名称并选择 复制提示。将提示发送至 Grok Bot 的聊天中，机器人将创建自己的流程。复制该流程的 POST to URL 和 密钥，并将其粘贴回对话框，然后允许机器人在 Grok Bot 的 设置 → 电脑 中运行命令。机器人运行的命令可向对讲机报告，但无法响应其他会话的卡片或更改设置。

Windows 预览版

配套软件和服务现已支持 Windows 10、11（x64），包括 System 界面、Claude Code、Claude Channels、Codex、宏键盘、语音、Grok Bot、托盘图标、登录时启动和应用内更新。每次发布都会提供未签名的 Windows ZIP。由于未签名，SmartScreen 会显示 More info → Run anyway 提示，而 Smart App Control 会阻止运行。具体说明见 Windows 安装指南。

Omarchy

在 Omarchy（Hyprland）电脑上，Linux 服务和 Omarchy 桥接程序会把 Claude Code、Codex 和 Kimi Code 会话带到对讲机上。Omarchy 界面可切换窗口和工作区，语音指令会输入到对应会话的终端。已安装 Superwhisper 时，用它识别 PTT 录音；宏键盘通过 uinput 发送按键，因此也能使用 Omarchy 的 Super 组合键。构建和安装步骤见 Omarchy 指南。

在对讲机上确认固件更新

从 0.14.0 固件开始，只有在对讲机上按 ENTER 确认，才会开始安装新固件。按 CANCEL、等待超时、使用语音或调用 API，都不会批准安装。从 0.13 升到 0.14 仍在软件中确认；已处于恢复模式的对讲机会直接开始安装。

问题提示现在会占用下一次 ENTER 按键：按一次打开问题，选好答案后再按一次即可提交。跳转到新问题时，也会保留正在运行的计时器、响铃的警报以及独立运行的游戏。

关于新功能的说明

  • 祖先进程限制现在也能识别原生安装的 Claude Code。在 Claude Code 或 Codex 中运行的管理类 deckd 命令会被拒绝；请在你自己的终端中运行。
  • 本地 TCP 接口默认关闭，并将在下一个版本移除。
  • Usage（用量统计）中的 Claude 用量需要手动开启。对讲机麦克风无法使用时，服务也不再改用 Mac 麦克风录音。

Update

在 Mac 上选择检查更新…，或安装已签名并通过公证的 0.14.0 版应用，支持 Apple Silicon 和 Intel，需要 macOS 13 或更高版本。用 USB 连接对讲机，打开服务 → 更新，点击设备旁的检查，再依次点击查看…和安装。常规更新会保留设置和蓝牙配对。Windows 用户可从发布页下载 ZIP，并按 Windows 指南安装。
