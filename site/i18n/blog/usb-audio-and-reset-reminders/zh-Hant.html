0.9.0 版讓 USB 語音更清楚，並為一件容易忽略的事加上提醒：快要到期、尚未使用的手動用量重設。更新 Mac 應用程式和裝置韌體，就能同時獲得這兩項改進。

聽清楚每個字

我們先用音樂比較 16 kHz 和 48 kHz。聽者沒有聽出明顯差異。英語語音的結果就不一樣了：開啟揚聲器 EQ 並把音量對齊後，48 kHz 的那段聽起來更清楚，16 kHz 版本中聽得到的雜音也不見了。

只要連線的韌體支援，裝置現在就會透過 USB 以 48 kHz 在揚聲器播放。服務會自動檢查這項能力，保持 EQ 開啟，遇到較舊的韌體則退回 16 kHz。切換連線時以及放開按住說話後，播放都會依照協商好的取樣率。

這改善的是播放路徑，不會憑空產生原始語音中沒有的細節。我們測試用的 Kokoro 語音輸出的是 24 kHz 音訊。讓它走 48 kHz 路徑，可以避開之前降到 16 kHz 的步驟，壓縮與重建的路徑也隨之改變。

16 kHz 路徑也更好了

主機現在會嘗試其他 ADPCM 編碼路徑來減少量化誤差，只要原本的結果比較好，就保留原本的結果。韌體在把 16 kHz 音訊送到 48 kHz DAC 之前，改用帶限濾波器取代線性內插。

在同一段英語語音上，修改後的編碼器把編碼誤差的平方降低了約 30%。這是數位量測結果，並不保證聽感上的底噪會完全消失：修改後的 16 kHz 路徑仍需要實際試聽確認。

BLE 播放和麥克風收音仍維持 16 kHz。USB 比較測試在兩種取樣率下都沒有出現斷音、欠載、佇列丟棄或序號錯誤。透過 BLE 長時間以 48 kHz 播放尚未經過驗證，所以此版本只在 USB 上使用較高的取樣率。

在到期前用掉重設

當未使用的手動重設額度將在 72 小時內到期時，Mac 上的「用量」頁和裝置上的「用量」頁面會在每週用量條下方顯示一則琥珀色的小提示。例如：「2 次重設將在 1 天 6 小時後到期。」

這和每週額度更新前的一般倒數是兩回事。提示會採用最近的額度到期時間，只計算在這個期限到期的額度。額度用掉或到期後提示就會消失；切換帳號時會清除畫面上先前帳號的額度資料；中斷連線時提示會隱藏。如果服務商沒有提供這項資料，就不會出現提醒。裝置不會替你兌換重設。

兩邊都要更新

安裝已簽署並經過公證的 Mac 應用程式（Apple Silicon 或 Intel），或選擇檢查更新。需要 macOS 13 或更新版本。接著透過 USB-C 連接裝置，使用服務 → 更新 → 檢查韌體更新。應用程式、服務和韌體都應顯示 0.9.0。

在使用復原協定 2 的裝置上，一般更新會保留設定和藍牙配對。較舊的復原版本使用現有的引導式移轉。各主機板的原廠 ZIP 仍會提供，用於生產；其中整顆晶片的映像檔會覆寫設定和配對，所以現有裝置請使用應用程式的更新功能。

部落格是版本發行的一部分

發行驗證程式現在要求先備妥一篇部落格文章、它的訂閱來源項目、部落格索引連結、網站地圖項目，以及最新的 Mac 下載檔，才能發行版本。先前缺少的 0.7.0 和 0.8.0 文章現在也已補上。

開發版韌體和語音比較都在 Rev A 上透過 USB 檢查過；重新啟動更新後的服務後，也確認了常駐程式的一般播放為 48 kHz。自動檢查涵蓋取樣率協商、連線切換、音訊編碼與濾波、重設到期與帳號切換，以及算繪。這次沒有在 Rev B 上實機測試音訊。
