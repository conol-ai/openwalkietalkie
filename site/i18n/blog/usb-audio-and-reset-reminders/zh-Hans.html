0.9.0 版让 USB 语音更清晰，并为一件容易错过的事加了提醒：即将过期、尚未使用的手动用量重置。更新 Mac 应用和设备固件即可获得这两项改进。

听清每个字

我们先用音乐对比了 16 kHz 和 48 kHz。听者没有听出明显差别。英语语音的结果则不同：开启扬声器 EQ 并对齐音量后，48 kHz 的那段听起来更清晰，16 kHz 版本中能听到的噪声也消失了。

只要所连接的固件支持，设备现在就通过 USB 以 48 kHz 在扬声器播放。服务会自动检查这项能力，保持 EQ 开启，遇到较旧的固件则回退到 16 kHz。切换连接时以及松开按住说话后，播放都会使用协商好的采样率。

这改进的是播放通路，并不会凭空生成源语音中没有的细节。我们测试用的 Kokoro 语音输出的是 24 kHz 音频。让它走 48 kHz 通路，可以避免之前降到 16 kHz 的那一步，压缩和重建的路径也随之改变。

16 kHz 通路也更好了

主机现在会尝试多种 ADPCM 编码路径来减小量化误差，只要原来的结果更好就保留原来的结果。固件在把 16 kHz 音频送到 48 kHz DAC 之前，用带限滤波器取代了线性插值。

在同一段英语语音上，修改后的编码器把编码误差的平方降低了约 30%。这是数字测量结果，并不保证听感上的底噪完全消除：修改后的 16 kHz 通路还需要通过试听确认。

BLE 播放和麦克风录音仍为 16 kHz。USB 对比测试在两种采样率下都没有出现断续、欠载、队列丢弃或序号错误。通过 BLE 持续以 48 kHz 播放尚未经过验证，所以此版本只在 USB 上使用更高的采样率。

在过期前用掉重置

当未使用的手动重置额度将在 72 小时内过期时，Mac 上的“用量”页和设备上的“用量”页面会在每周用量条下方显示一条琥珀色的小提示。例如：“2 次重置将在 1 天 6 小时后过期。”

这和每周额度刷新前的常规倒计时是两回事。提示采用最近的一个额度过期时间，只计算在这个期限过期的额度。额度用掉或过期后提示会消失；切换账户时会清除上一个账户的额度；断开连接时提示会隐藏。如果服务商不提供这项数据，就不会出现提醒。设备不会替你兑换重置。

两边都要更新

安装已签名并经过公证的 Mac 应用（Apple Silicon 或 Intel），或选择检查更新。需要 macOS 13 或更高版本。然后用 USB-C 连接设备，使用服务 → 更新 → 检查固件更新。应用、服务和固件都应显示 0.9.0。

在使用恢复协议 2 的设备上，普通更新会保留设置和蓝牙配对。较旧的恢复版本使用现有的引导式迁移。各主板的出厂 ZIP 仍然提供，用于生产；其中的整片镜像会覆盖设置和配对，所以已有设备请使用应用的更新功能。

博客是版本发布的一部分

发布校验程序现在要求先有一篇博客文章、它的订阅源条目、博客索引链接、站点地图条目和最新的 Mac 下载，才能发布版本。之前缺少的 0.7.0 和 0.8.0 文章现在也已补上。

开发版固件和语音对比都在 Rev A 上通过 USB 检查过；重启更新后的服务后，也确认了守护进程的正常播放为 48 kHz。自动检查覆盖采样率协商、连接切换、音频编码和滤波、重置过期和账户切换以及渲染。这次没有在 Rev B 上实地测试音频。
