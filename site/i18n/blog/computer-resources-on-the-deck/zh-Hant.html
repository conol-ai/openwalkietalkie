0.10.0 版在訂閱「用量」旁邊，又為裝置加了一個實用的頁面：系統，即時顯示正在工作的那台電腦。不必再開一個視窗擋住編輯器，就能查看 CPU 負載、記憶體、GPU 負載與剩餘的儲存空間。

四項讀數，每兩秒一次

Mac 上的服務會取樣 CPU 總使用率、已用與總記憶體、圖形處理器使用率，以及可寫入開機卷宗的剩餘與總空間。CPU 會依所有核心正規化。記憶體包括 App 記憶體、聯動記憶體與壓縮記憶體。對於有多個圖形加速器的 Mac，GPU 量表會顯示最忙碌的那一個。

儲存百分比代表剩餘空間。空間不足時顏色會改變。缺少的計數器顯示無法取得，超過十秒的讀數會變灰並顯示已過期，主機中斷時顯示離線。第一個 CPU 百分比需要兩次取樣。

讀數每兩秒送達一次，但沒有變化的量表不會重繪。這是只在裝置上的頁面；訂閱額度仍在「用量」中，Mac 應用程式也沒有新增頁面。

在哪裡找到它

在全新的配置中，「系統」排在「用量」後面。更新時會保留你已儲存的配置，所以請透過連按兩下 Shift → + → 系統 → Enter加入它。韌體與 Mac 上的服務都需要更新。如果舊的服務仍在執行，請選擇服務 → 重新啟動。

像素小鳥的顯示工作更少

像素小鳥現在只更新小鳥、水管與分數所在的區域，而不是在每個模擬步驟都讓整個螢幕失效。顯示路徑會正確地打包局部矩形，包括旋轉安裝的 Rev A 與 Rev B 面板，影格計時器也會把已經花在繪製上的時間算進去。

在一個包含多根水管與回收水管的 360 影格繪製測試中，傳輸的像素平均減少 51.5%。這是傳輸面積的量測，不是裝置上的影格率承諾。局部影格在分數變化、暫停與遊戲結束時都與完整重繪比對過。TE 同步仍然關閉，所以這並不保證動畫不會撕裂。

有發展空間的音樂

三首原創合成曲現在各有 48 小節：像素小鳥 96 秒，貪食蛇 115.2 秒，雷電 76.8 秒。前奏引出主題、應答旋律、較安靜的段落與再現，低音型、打擊樂與脈衝音色也在變化。

暫停或重玩同一個遊戲，會保留音樂的進度。換遊戲則從那個遊戲的主題開始。聲音仍由你透過遊戲 → 音效 → Enter控制：關閉、僅音效，或音樂與音效。

更新到 0.10.0

安裝已簽署並經過公證的 Mac 應用程式（Apple Silicon 或 Intel），或選擇檢查更新。需要 macOS 13 或更新版本。透過 USB-C 連接裝置，然後選擇服務 → 更新 → 檢查韌體更新。應用程式、服務與韌體都會顯示 0.10.0。

一般的應用程式更新會保留設定與藍牙配對。舊的開機載入程式沿用現有的引導式遷移。另外的原廠 ZIP 用於生產，會覆寫設定與配對。

0.10.0 韌體已在 Rev A 上透過 USB 燒錄、驗證並重新啟動，Mac 上的取樣器回傳了全部四項指標。自動檢查涵蓋訊息驗證、相容性、時效、繪製、模擬計時與音樂連續性。這項功能沒有在 Rev B 硬體上重新測試，也沒有重新測試實際斷電後的復原。
