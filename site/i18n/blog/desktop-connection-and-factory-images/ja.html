OpenWalkieTalkie 0.5.0 は、Codex Desktop とデバイスの間の接続を修正します。また、ファームウェアが 2 種類の代替のフラッシュチップに対応し、工場での書き込み用にチップ全体のイメージをまとめました。

Desktop のタスクが共有サービスに届く

以前のランチャーは Desktop を問題なく開けても、その会話が OpenWalkieTalkie から見えないままになることがありました。Desktop の既定のプラグイン設定によって、暗黙の共有サービスのモードが非公開のサーバーに切り替わっていたためです。更新したランチャーは、共有のローカル接続を明示的に選びます。

ChatGPT.app と Codex.app のどちらの名前でも、対応するインストールを検出します。ランチャーは既存の Codex のサービスを使い回し、実行中の Desktop のタスクには手を出しません。別の修正で、OpenWalkieTalkie が会話を購読する前に終わる短いタスクの返信も届くようになりました。

更新後に連携を修復する

0.5.0 のアプリをインストールし、そのサービスも 0.5.0 になっていることを確認します。連携 → Codex Desktopを開き、連携をインストールまたは修復します。Desktop のタスクが待機中になったら、Codex Desktop / ChatGPT を終了して ~/Applications/Codex with OpenWalkieTalkie.app を開きます。

これは、インストール済みの Desktop アプリのための小さなランチャーです。今後もこれで起動してください。元のアプリを直接開くと、共有の接続は有効になりません。対応していない Desktop のビルドでは、接続されていないセッションを黙って開くのではなく、エラーを表示します。

フラッシュの選択肢と工場用イメージ

ファームウェアは、既存の Winbond W25Q128JVSIQ（C97521）に加えて、Puya PY25Q128HA-SUH-IR（C5354566）と GigaDevice GD25Q128ESIGR（C2928891）も受け付けるようになりました。設定、ペアリング、ブートローダーの書き込みは、対応する安定したチップ ID を確認してから書き込みを有効にします。代替部品を実装した基板は、まだ実機での確認が必要です。

このリリースには、Rev A と Rev B それぞれの 16 MiB のイメージを収めた工場用の ZIP が含まれます。どちらも、リリースしたアプリケーションとリカバリーのバイナリそのものに、新しいフラッシュのテーブルと空の個体用ストレージを組み合わせたものです。中国語の説明、部品ごとのハッシュ、単体で動く検証ツールも同梱しています。

工場用イメージは、設定とペアリングのデータを含むフラッシュの内容をすべて上書きします。空の基板の準備に使うためのものです。使用中のデバイスは、アプリの通常の USB での更新を使ってください。

使用中のデバイスを更新する

デバイスを 1 台 USB-C で接続し、サービス → 更新 → ファームウェア更新を確認を開きます。パーティションの配置とリカバリープロトコルは 0.4.0 から変わっていないため、すでにリカバリープロトコル 2 のデバイスには通常のアプリケーションの更新が届きます。

まだ古いブートローダーのデバイスには、ガイド付きの移行が必要です。電源をつないだまま、Mac をスリープさせないでください。ブートローダーの置き換え中に電源が切れると、起動も USB のリカバリーもできなくなり、ハードウェアの修理が必要になることがあります。アプリは移行の前にこの警告を表示します。bootstrap やリカバリーのファイルを、アプリケーションのファームウェアとして手動でインストールしないでください。

確認したこと

ランチャーと通信の回帰テストは通っています。開発用の Mac での実地テストでは、Desktop が共有サービスに接続し、DESKTOP-LINK-OK の返信が OpenWalkieTalkie の画面に表示されました。接続した Rev A への USB での配信は正常でした。最後の実機の画面での確認は記録していません。

どちらの基板のバリエーションもソフトウェアのチェックを通っています。同じフラッシュ対応を持つ前の 0.4.1 の開発版ファームウェアで、既存の Rev A の古いブートローダーからの移行が完了しました。そのテストでは CI でビルドした 0.5.0 のファイルは書き込んでいません。出荷用の Rev B、代替チップを載せた基板、空の基板への工場での書き込みは、まだハードウェアでの検証が必要です。デバイスの音声のテストは行っていません。

v0.5.0 を入手する

アップデートを確認を使うか、Apple シリコン用または Intel 用の署名・公証済みの Mac アプリをダウンロードしてください。macOS 13 以降が必要です。

GitHub のリリースには、ファームウェア、工場用イメージ、チェックサム、ビルドの証明、中国語のアップグレードガイドが含まれます。このガイドは各 DMG にも入っています。
