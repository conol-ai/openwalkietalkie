Omarchy で使う OpenWalkieTalkie

デバイスを Omarchy（Hyprland）ノートパソコンのリモコンに

Omarchy では、Mac なしでデバイスがデスクトップとコーディングエージェントを操作します。ノートパソコンでは小さなサービスが 2 つ動きます。Mac アプリが動かすのと同じサービスを Linux 向けにビルドした deckd と、それを Hyprland および Claude Code、Codex、Kimi Code のセッションにつなぐ Omarchy ブリッジです。

  • Omarchy のページ：ワークスペースとウィンドウ。ホイールでウィンドウを、LEFT / RIGHT でワークスペースを切り替え、ENTER で全画面、SHIFT+CANCEL で scratchpad を切り替えます。
  • 一覧に並ぶセッションは、実行中、完了、質問中のいずれかで表示されます。選ぶと、そのターミナルが前面に出ます。
  • 音声の指示：セッションで PTT を押しながら話します。話した言葉がそのターミナルに入力され、ターンが終わると返信が表示され、読み上げられます。
  • マクロパッド、システム、使用量のページには、このノートパソコンの情報が表示されます。
  • コンパニオンアプリは Mac と同じウィンドウで、Omarchy のアプリランチャーにあります。

Linux 版のダウンロードはまだありません。deckd とアプリはソースからビルドします。初回は 10 分ほどかかります。以下のコマンドはすべて Omarchy ノートパソコンのターミナルで実行します。

1. ツールをインストールする

sudo pacman -S --needed base-devel git rustup cmake clang espeak-ng wtype
rustup default stable

cmake と clang はローカルの音声認識エンジンのビルドに、espeak-ng はデバイスでの返信の読み上げに、wtype はターミナルへの指示の入力に使います。ビルドに必要なその他のライブラリ（udev、ALSA、D-Bus）は Omarchy に入っています。

2. ビルドしてインストールする

git clone https://github.com/conol-ai/openwalkietalkie.git
cd openwalkietalkie/host
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

install.sh は deckd とアプリを ~/.local/bin に置き、アプリを OpenWalkieTalkie として Omarchy のランチャーに追加し、ブリッジを ~/.local/share/openwalkietalkie/omarchy にコピーして、両方を systemd のユーザーサービス deckd と omarchy-deck として起動します。ログインのたびに再び起動します。最後に root 権限が必要な手順を表示します。それが次のセクションです。

3. サービスがデバイスを開けるようにする

デバイスの HID デバイスは、udev ルールがあなたに渡すまで root のものです。install.sh が表示した 2 つのコマンドを実行します。

sudo install -m 644 omarchy/70-openwalkietalkie.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw

このルールは、USB-C でも Bluetooth でも同じようにデバイスに一致します。

4. デバイスを接続する

  • USB-C：差し込むだけです。ほかに必要なことはありません。
  • Bluetooth：Omarchy の Bluetooth メニュー（または bluetoothctl）で OpenWalkieTalkie をペアリングします。デバイスが保持するペアリングは一度に 1 つです。Mac とペアリングしていた場合は、先に Mac 側で削除してください。

サービスは数秒以内に自動で接続します。確認するには：

deckd status

link: の行が Connected, session Live になっていれば接続済みです。

5. セッションをデバイスに表示する

使っているエージェントのフックをインストールします。インストールのたびにエージェントの設定ファイルを先にバックアップし、置き換えずに追記します。

python3 omarchy/omarchy_hook.py install claude
python3 omarchy/omarchy_hook.py install codex
python3 omarchy/omarchy_hook.py install kimi

すでに開いているセッションは新しいフックを読み込みません。起動し直すと、エージェントのページに表示されます。

6. 音声

選んだセッションで PTT を押しながら話し、離します。テキストがそのセッションのターミナルに入力され、続けて Enter が押されます。

  • Superwhisper を使う場合（Omarchy の口述入力を使っているなら）、設定は不要です。押すたびに Superwhisper のモード、言語、語彙で認識し、Cloud モードなら 1 秒かかりません。準備ができているかは superwhisper status で確認します。
  • 使わない場合は、ローカルの Whisper モデル（約 465 MB）を一度ダウンロードします。 
    printf '[voice.stt]\nengine = "whisper"\nmodel = "small"\nlanguage = "auto"\n' >> ~/.local/share/openwalkietalkie/config.toml
deckd stt install --model small
    Whisper はノートパソコンの CPU で動くため、プロセッサーによっては 1 回の押下に数秒以上かかります。

音声が届くのは、ターミナルのウィンドウで動いているセッションだけです。別のアプリの中で動くセッションには入力先のターミナルがないため、デバイスには指示が届かなかったと表示されます。

7. 任意：マクロパッドのショートカット

キー操作を設定したマクロパッドのキーは、ノートパソコンでそれを入力します。フォーカス中のアプリのショートカットに加えて Omarchy 自体のショートカット（Super+…）もキーで動かすには、ブリッジがキーボードとして振る舞う必要があり、それには /dev/uinput が必要です。

sudo install -m 644 omarchy/71-openwalkietalkie-uinput.rules /etc/udev/rules.d/
echo uinput | sudo tee /etc/modules-load.d/openwalkietalkie-uinput.conf
sudo udevadm control --reload && sudo modprobe uinput
systemctl --user restart omarchy-deck

これ以降、実行するどのプログラムも ydotool と同じように入力デバイスを作れるようになります。この手順を飛ばしても、マクロパッドのキーはフォーカス中のアプリには届きますが、Omarchy のショートカットは動きません。

8. 任意：Claude の使用量バー

使用量のページに Claude のレート制限の枠を表示できます。Claude Code のログインを使って 5 分ごとに読み取ります。

deckd config set 'usage.providers=["codex","claude"]'

セットアップを確認する

deckd care checks
python3 omarchy/omarchy_hook.py status
journalctl --user -u deckd -u omarchy-deck -f

または、アプリランチャーから OpenWalkieTalkie を開きます。「デバイス」ページに接続状態が表示され、「サービス」ページでサービス（deckd の systemd ユニット）の開始と停止、ログイン時にアプリを開く設定ができます。サービスのファイルはすべて ~/.local/share/openwalkietalkie にあります。

更新

cd openwalkietalkie/host
git pull
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

install.sh をもう一度実行すると、新しいコードで両方のサービスが再起動します。アプリは終了して開き直すと新しいバージョンになります。デバイスのファームウェアを更新するには、USB-C で接続して deckd firmware check、続けて deckd firmware install を実行するか、アプリの「サービス」ページを使います。デバイスはインストール前に ENTER を押すよう求めます。Mac と同じ USB の経路ですが、Omarchy ではまだ試していません。

Omarchy にまだないもの

  • デバイスでの権限の確認への応答。確認はターミナルに残ります。
  • Codex の使用量バーと、Omarchy のセッションのリーダーでの履歴とツールの行。
  • トレイアイコンとアプリの自動更新。アプリはソースからビルドするので、上の方法で更新してください。

アンインストール

python3 omarchy/omarchy_hook.py uninstall all
systemctl --user disable --now deckd omarchy-deck
rm -f ~/.config/systemd/user/deckd.service ~/.config/systemd/user/omarchy-deck.service ~/.local/bin/deckd ~/.local/bin/openwalkietalkie-app
rm -f ~/.local/share/applications/openwalkietalkie.desktop ~/.local/share/icons/hicolor/512x512/apps/openwalkietalkie.png ~/.config/autostart/openwalkietalkie.desktop
rm -rf ~/.local/share/openwalkietalkie
sudo rm -f /etc/udev/rules.d/70-openwalkietalkie.rules /etc/udev/rules.d/71-openwalkietalkie-uinput.rules /etc/modules-load.d/openwalkietalkie-uinput.conf

フックのアンインストールは、各エージェントの設定に自分が追加したものだけを削除します。

うまく動かない場合は、deckd care checks の出力と journalctl --user -u deckd -u omarchy-deck の最後の数行を添えて Issue を作成してください。詳しいリファレンスは Omarchy ブリッジの README です。
