開発者向けドキュメント · 0.11.0+

OpenWalkieTalkie 向けに開発する

あらゆるエージェントのためのネイティブ連携

エージェントの会話をデバイスに表示しましょう。セッションとモデルへの接続はあなたのアプリが管理し、本体のキー操作、音声入力、画面表示は OpenWalkieTalkie が受け持ちます。

アプリ + サービス + ファームウェア 0.11.0+

ネイティブコンパニオン API

グループ化されたセッション、新規チャット用のランチャー、リアルタイムのメッセージ、複数ステップの質問、モデルと思考の深さの設定、そして Omarchy のページへのフィード。Conol と Omarchy ブリッジが使うのと同じインターフェースを、どのエージェントでも使えます。

Windows 版 OpenWalkieTalkie

署名なしの Windows プレビュー版のアプリとサービスをインストールし、SmartScreen の警告を確認して、USB-C でデバイスのファームウェアを更新します。

LINUX · OMARCHY · 0.13.0+

Omarchy で使う OpenWalkieTalkie

サービスと Omarchy ブリッジをビルドしてインストールします。デバイスは Hyprland のリモコンになり、Claude Code、Codex、Kimi Code のセッションが一覧に並び、音声の指示がそれぞれのターミナルに届きます。

デバイスを使うだけなら

セットアップ、操作、トラブルシューティングはイラスト付きの取扱説明書をご覧ください。印刷して手元に置いておくこともできます。

動くサンプルから始める

Python のコンパニオンのサンプルをダウンロード。OpenWalkieTalkie を開いた状態で Python 3.10 以降で実行します。返信はあらかじめ用意したもので、パッケージ、モデルの API キー、Conol のアカウントは不要です。

仕様を調べる

JSON-RPC API の完全なリファレンス（Markdown）。デーモンのリクエストスキーマとメソッドの権限から生成しています。ソースリポジトリにはサンプルと連携テストも含まれます。
