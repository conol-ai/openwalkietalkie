プレビュー版 · 署名なし · 0.14.0+

Windows 版 OpenWalkieTalkie

x64 の Windows 10 と 11 向けのアプリとサービス

Windows プレビュー版は Mac と同じサービスとアプリを動かします。デバイスは USB-C か Bluetooth で接続し、Claude Code と Codex のセッションを表示し、その承認に答え、押して話すで口述を受け取って返信を読み上げます。アプリはデバイスのファームウェアも更新します。プレビュー版なのは、Mac の機能のいくつかが Windows にまだないため（後述）と、コード署名がないためです。そのため Windows は初回の実行前に警告を表示します。

ダウンロード

Windows x64 プレビュー版の ZIP をダウンロード。この単体の Windows プレビュー版には、音声、Claude Code、Codex CLI、Grok Bot が含まれます。リリースノートにソースのリビジョンと SHA-256 チェックサムがあります。0.14.0 以降の正式リリースにも OpenWalkieTalkie-<version>-windows-x86_64.zip という名前の Windows ビルドが含まれます。ダウンロードを検証するには、ダウンロードフォルダーで PowerShell を開いて次を実行します。

Get-FileHash .\OpenWalkieTalkie-*-windows-x86_64.zip -Algorithm SHA256

インストール

  1. 展開します。プログラムを置く場所、たとえば %LOCALAPPDATA%\Programs\OpenWalkieTalkie に展開してください。bin フォルダーはそのままにします。アプリは bin という名前のフォルダーから実行されたときだけファームウェアをインストールし、隣の deckd.exe を起動します。
  2. bin\OpenWalkieTalkie.exe を開きます。プログラムに署名がないため、Windows SmartScreen がWindows によって PC が保護されましたと表示します。詳細情報を選び、実行を選んでください。Windows はこのコピーについて選択を記憶します。
  3. 初回起動の手順に従います。手順の中で、デバイスと通信するサービス deckd.exe がウィンドウなしでバックグラウンドで起動し、サインインのたびに起動するよう設定されます（設定 › アプリ › スタートアップに表示されます）。サービス › ログイン時に起動は、アプリ自体に同じ設定をします。ウィンドウを閉じてもアプリは通知領域に残ります。終了はアイコンのメニューから行います。
  4. デバイスを接続します。USB-C でつなぐか、設定 › Bluetooth とデバイスでペアリングします。サービスが接続すると、アプリの「デバイス」ページに表示されます。

音声

デバイスの押して話すは、この PC 上の Whisper が認識します。アプリの音声ページでモデルをダウンロードしてください（Windows には独自の認識エンジンがないため、モデルが入るまでは押すとその旨を表示します）。返信は Windows 標準の音声で読み上げます。Kokoro（同じ方法でダウンロード）や、自分の OpenAI または ElevenLabs のキーを使うクラウドの音声も選べます。デバイスのマイクとスピーカーは、ケーブルでも Bluetooth でも使えます。

Windows に「実行」が表示されない場合

新しくインストールした Windows 11 の一部では、スマート アプリ コントロールが署名のないプログラムをブロックし、回避する方法がありません。設定はWindows セキュリティ → アプリとブラウザーコントロール → スマート アプリ コントロールで確認できます。オンの間はプレビュー版を実行できません。また多くの Windows のバージョンでは、一度オフにすると Windows を再インストールしない限りオンに戻せないため、その価値があるかご自身で判断してください。ウイルス対策ソフトが、新しい署名なしのダウンロードをしばらく保留することもあります。上のチェックサムで、リリースが公開したファイルであることを確認できます。

デバイスのファームウェアを更新する

デバイスを 1 台 USB-C で接続し、サービスを開いて、デバイスのファームウェアの確認をクリックし、続けて内容を確認…とインストールをクリックします。Mac とまったく同じです。デバイスが戻るまでケーブルを外さないでください。Windows では、より速い USB インターフェース（Windows にドライバーがありません）ではなくデバイスの HID 接続で転送するため、数分かかります（Rev A で 0.13.0 なら約 5 分）。仮想マシンで Windows を動かしている場合は、デバイスの再起動後に再びパススルーされるようにしてください。更新中に 2 回接続し直します。

Grok Bot をつなぐ

Grok Bot：連携 → ボットを開き、ボットのルーティンの Webhook を追加します。「プロンプトをコピー」は、返信や質問をこの PC に送り返す PowerShell コマンドをボットに渡します。Grok Bot の Computer 設定でそれらのコマンドを許可してください。サービスはルーティンのキーを Windows の資格情報マネージャーに保存します。別のデータディレクトリを使うサービスは、代わりに grokbot-keys.toml を使います。

アプリを更新する

サービスを開いてアプリの横の確認をクリックするか、アイコンのメニューからアップデートを確認…を選びます。最新のリリースに新しいバージョンがあれば更新をクリックします。アプリはリリースの zip をダウンロードし、リリースが公開するチェックサムと照合して、新しい OpenWalkieTalkie.exe と deckd.exe を bin フォルダーに置き、再起動します。設定は %LOCALAPPDATA%\OpenWalkieTalkie に残ります。手動で更新する場合は、最新のリリースから zip をダウンロードし、アイコンからアプリを終了して、古いバージョンのフォルダーを新しいものに置き換えます。

Mac との違い

  • クラウドの音声のキーは、Mac ではキーチェーンに、Windows では資格情報マネージャーに保存されます。
  • アプリに署名がないため、サービスは置き場所でアプリを信頼します。つまり deckd.exe の隣の OpenWalkieTalkie.exe です。Mac では代わりにアプリの署名を確認します。
  • Windows にまだないもの：Apple シリコンが必要な MLX の音声と、サービスが共有する Codex デーモンで Codex Desktop を開くランチャー。ターミナルの Codex は Mac と同じように使えます。

アンインストール

bin\deckd.exe uninstall を実行すると、サービスを停止し、サインイン時の起動項目と Claude Code・Codex の連携を削除します。--purge を付けると %LOCALAPPDATA%\OpenWalkieTalkie の中身（設定、音声モデル、ダウンロードしたファームウェア）も削除します。ただし logs フォルダーは残るので、必要なら自分で削除してください。最後にアイコンからアプリを終了し、展開したフォルダーを削除します。

うまく動かない場合は、Issue を作成し、%LOCALAPPDATA%\OpenWalkieTalkie\logs のログを添えてください。
