チュートリアル · CLAUDE CODE · アプリ 0.17.0

Claude Code を接続する

プラグイン、Channels、生きたセッション 1 つ · 所要時間は 10 分ほど

デバイスが話しかけるのは、あなたのマシンで既に動いている Claude Code のセッションです。成り立っている必要があるのは 2 つ：プラグインが Claude Code に入っていること、セッションが Channels 付きで起動していること。

何がつながるのか

アプリの「設定」は Claude Code をインストールしません。~/Library/Application Support/OpenWalkieTalkie/claude-marketplace/ にローカルのプラグインマーケットプレイスを書き、それを登録して、このマシンの Claude Code にデバイスの存在を知らせます。

  • プラグイン：セッションが自分自身をバックグラウンドサービスに報告するためのフック一式。
  • Channels：アプリが読むライブチャネル。セッションがデバイスに並ぶのはこれ経由です。行もスイッチも別です。
  • あなたのプロジェクト：触りません。プラグインはユーザースコープに入り、プロジェクト単位では入れません。

Linux

Linux では、Omarchy ブリッジが Claude Code のセッションをデバイスに表示します。双方向のメッセージを扱う Claude Code Channels はこのバージョンでは使えません。次のバージョンで修正されます。それまでは、以下の手順は macOS と Windows に適用されます。

1 · プラグインを入れる

  1. 連携 を開き、Claude Code を探します。行が 設定する なら押します。
  2. 行に コマンドをコピー があれば、下の 2 つのコマンドをターミナルで実行します。どちらも繰り返し実行できます。
  3. プラグインを入れる前に開いていたセッションは、それを読みません。新しく開くか、その中で /reload-plugins を実行します。
claude plugin marketplace add '<marketplace path>' --scope user --json
claude plugin install openwalkietalkie@openwalkietalkie --scope user --json

ユーザースコープで登録されると、行は 接続済み になります。これはファイルの話で、動いているセッションの話ではありません。

2 · Channels 付きでセッションを起動する

Claude Code は、起動時に指名しない限り Channels を読み込みません。

claude --dangerously-load-development-channels plugin:openwalkietalkie@openwalkietalkie

アプリではこのコマンドが 連携 → Claude Channels → 接続方法… → コマンドをコピー の奥にあり、内容は同じです。初回起動時に Claude が確認を求めるので、承認します。

3 · 何が見えるはずか

  • Claude Code の行：接続済み。セッションが開くとセッション数も付きます。
  • Claude Channels の行：独自の状態。Channels のセッションが動くまではセッション未接続。
  • デバイス側：CANCEL を押して Agents に入ると、セッションが並んでいます。デバイス側でほかに設定するものはありません。

うまくいかないとき

修復が必要
アプリを更新した直後に 修復が必要 と表示されるのは正常です。管理下のプラグインファイルが Claude Code の記録と一致しなくなっています。修復 を一度押すと、アプリがプラグインを書き直して再登録します。
Claude Channels にセッションが接続されない
セッションが Channels フラグ付きで起動していないか、確認を閉じてしまっています。終了して、コピーしたコマンドでもう一度起動します。
接続済みなのにデバイスに出ない
プロジェクト側の .claude/settings.json が enabledPlugins["openwalkietalkie@openwalkietalkie"]: false でそのリポジトリのプラグインを切っていることがあります。アプリからはそのスイッチが見えません。
更新した直後から動かない
プラグインはセッション起動時に読み込まれます。更新前に開いていたセッションは /reload-plugins か再起動が必要です。

このページの確認方法

ラベルとパスはすべてアプリ本体と 0.17.0 のバックグラウンドサービスのソースから取り、2 つのコマンドはアプリがコピーさせるものそのものです。このページは生きた Claude Code セッションで端から端まで実行してはいないので、順序はコードが前提にしている順序として読んでください。実行記録ではありません。
