はじめに

Mac、デバイス、USB-C のデータケーブルを用意します。

01

アプリを開く。

Apple シリコン用または Intel 用の OpenWalkieTalkie（macOS 13 以降）をダウンロードします。「アプリケーション」フォルダにドラッグして起動します。2 ページに従ってコンパニオンサービスを開始します。

02

デバイスを接続する。

USB-C のデータケーブルをつなぎ、確認が出たらアクセサリを許可します。ワイヤレスで使うには、Bluetooth で OpenWalkieTalkie をペアリングします。電源、ペアリング、権限は2 ページで説明します。

03

エージェントを用意する。

下の Codex または Claude Code の手順に従い、最初のタスクを試します。コンパニオンサービスは動かしたままにします。

準備の確認

セッションが offline の表示なしで現れます。SCROLL を回して選び、ENTER を押します。5 ページで最初のメッセージを送る前に、「Voice → Test Voice」で確認してください。

電源を入れて。
接続しよう。

デバイス、USB-C のデータケーブル、Mac を用意します。OpenWalkieTalkie をインストールし、使うコーディングアシスタントにサインインしておきます。

デバイスボタン、画面、音声

MAC アプリ + サービス接続と配信
↔
エージェントCodex / Claude Code

  1. インストールして開き、電源を入れる。

    Mac 版のダウンロードを開き、OpenWalkieTalkie を「アプリケーション」フォルダにドラッグして起動します。USB-C のデータケーブルでデバイスを接続します。PTT を 2 秒間押して電源を入れ、離します。macOS に聞かれたらアクセサリを許可します。画面がロックされている場合は、ホイールを反時計回りに 4 段回します。

  2. 初回のセットアップを終える。

    Connect → What this adds → Voice → Integrationsの順に進みます。バックグラウンドサービスと任意の Claude プラグインを確認して、Add Theseを選びます。音声認識エンジンを選び、Continueで次へ進みます。デバイスを使うには、サービスが動いている必要があります。

    セットアップ済みなら → 「Deck」を開いて接続を確認します。接続がなければ「Service → Check my setup」を使います。

  3. ケーブルなしで接続する。

    ワイヤレスで使うには、macOS のシステム設定 → Bluetoothで OpenWalkieTalkie をペアリングします。プライバシーとセキュリティ → Bluetoothで、コンパニオンのアクセスを許可します。「Deck」に戻って接続状態を確認します。

    確認 → デバイスが接続済みで、状態が取得でき、ライブのページに「offline」が出なくなります。

  4. マイクとスピーカーをテストする。

    Voiceを開きます。「Recognition」と「Spoken replies」を選び、「Speech language」で話す言語を設定し、権限の確認があれば済ませます。Test Voiceをクリックし、デバイスで PTT を押しながら「hello」と話して離します。認識された言葉を確認します。Speak a Sampleをクリックして再生を確認します。続けて Codex または Claude Code に進みます。

デバイスの音声

デバイスのマイクが必要です。0.15.0 では Mac のマイクに切り替わることはありません。Bluetooth の音声はアプリ独自の BLE 接続を使います。macOS の「サウンド」でデバイスをマイクとして探さないでください。英語版アプリには「Deck」「Faces & Keys」「Integrations」「Voice」「Service」の 5 ページがあります。

コーディングアシスタントを接続する03 — CODEX

CODEX を
デバイスへ。

Codex の使い方に合わせて Desktop か CLI を選びます。接続を確認する前に、コンパニオンサービスが動いている必要があります。

CODEX DESKTOP を使う場合

  1. Desktop の連携をインストールする。

    まず公式の Desktop セットアップに従ってインストールし、サインインします。OpenWalkieTalkie でIntegrations → Codex Desktop → Set Upを開きます。提案される変更を読んで確定します。行がすでに「Installed」なら、そのまま進みます。「Repair」はセットアップの修正が必要なときだけ使います。

  2. コンパニオンのランチャーから開き直す。

    作業を終えて Codex Desktop / ChatGPT を終了します。Finder で移動 → フォルダへ移動を選び、~/Applications と入力して Codex with OpenWalkieTalkie.app を開きます。デバイスから使うために Desktop を開き直すときは、いつもこのランチャーを使ってください。

  3. ローカルの会話を開く。

    Codex でローカルのプロジェクトを開き、会話を始めるか再開します。OpenWalkieTalkie でIntegrationsを開き、Codex の行の件数と「State」を確認します。デバイスではAgentsでその会話を見つけ、ENTER を押します。

    確認 → 会話がデバイスに表示され、連携に動作が表示されます。コンパニオンに表示されるのは件数で、チャットの内容ではありません。クラウドと SSH のセッションはこの連携の対象外です。

CODEX CLI を使う場合

  1. 公式の Codex CLI セットアップに従ってインストールし、サインインします。CLI 0.161 以降が対応する共有デーモンのモードを使います。デバイスからの返信には --no-daemon を使わないでください。
  2. Integrationsで Codex CLI をオンにし、連携が一時停止していないことを確認します。このバージョンは Codex 自体を通じて接続するため、CLI のフックを別にインストールする手順はありません。
  3. プロジェクトのフォルダーで codex を実行し、会話を始めます。連携の動作を確認し、デバイスのエージェントの一覧でそのセッションを探します。

行に「Codex is not running」と表示されたら、先にローカルのセッションを開きます。それでも接続できない場合は「Service → Check my setup」を使います。

コーディングアシスタントを接続する04 — CLAUDE CODE

CLAUDE CODE。
ライブのセッションを 1 つ。

「Integrations」の「Claude Code」行を使います。Claude Desktop は別の製品で、このターミナルでの手順の代わりにはなりません。

「Integrations」を開くClaude Code プラグインを設定
→
プロジェクトのターミナルChannels 付きで起動
→
デバイスのエージェント準備できたセッションを選ぶ

  1. Claude Code を準備する。

    公式の Claude Code セットアップに従ってインストールし、サインインします。プロジェクトのターミナルで claude --version を実行し、使えることを確認します。

  2. OpenWalkieTalkie プラグインをインストールする。

    Integrations → Claude Code → Set Upを開きます。提案される変更を確認して確定します。サービスが claude を見つけられない場合、「Set Up」がもう 1 手順を求めます。Copy Commandをクリックし、ターミナルでそのコマンドを実行してください。アプリがセットアップの問題を報告したら、Repairを使い、提案された修正を確認します。インストール後は新しい Claude のセッションを始めます。既存のセッションは /reload-plugins でプラグインを読み込み直せます。

    確認 → Claude Code の行が「Connected」になります。セッションを始めて、動作と件数を確認します。

  3. 音声に対応したセッションを起動する。

    Integrationsで Claude Channels を有効にします。How to Connect… → Copy Commandをクリックします。プロジェクトのフォルダーで開いたターミナルに貼り付けて実行します。このバージョンのアプリでのコマンドは次のとおりです。

    claude --dangerously-load-development-channels plugin:openwalkietalkie@openwalkietalkie

    既存の会話を続けるには、先にそのセッションを終了し、末尾に --resume とセッション ID を付けます。インストールしたアプリが示すコマンドが変わっていたら、そちらに従ってください。

  4. Claude の接続の確認を済ませる。

    Claude のローカル開発の確認を読みます。求められたら、OpenWalkieTalkie の MCP サーバーとその acknowledge による接続確認を許可します。コンパニオンのIntegrationsページに戻ると、接続状態は自動で更新されます。

    確認 → Claude Channels の行が「Connected」になり、Claude のセッションがデバイスに表示されます。「No session connected」は、起動か確認がまだ終わっていないという意味です。

  5. デバイスでそのセッションを選ぶ。

    Agentsに移動します。LEFT / RIGHT でプロジェクトを探し、SCROLL を回して Claude のセッションをハイライトし、ENTER を押します。話し方と返信の手順は次のページにあります。

止まってしまったら

Claude で /mcp を開き、OpenWalkieTalkie のサーバーを確認します。Claude に check_connection を実行するよう頼み、Claude Channels の行をもう一度確認します。Channels はリサーチプレビューで、セッションごとに開発用のフラグが必要です。組織のポリシーは引き続き適用されます。フラグなしで起動し直すとオフになります。接続されるまでは、代替の受信箱がメッセージを別のセッションからのものとして表示することがあります。

選ぶ。話す。
結果を見る。

先にエージェントを 1 つセットアップしておきます。その会話を Mac で開いたままにすると、デバイスがメッセージをどこに送ったかがはっきりわかります。下の画面は例で、あなたのライブのセッションではありません。

1. 正しい会話を選ぶ。

デバイスで：CANCEL を押すと会話から「Agents」の一覧に戻ります。LEFT / RIGHT でプロジェクトのページを、SCROLL でハイライトを動かします。プロジェクトとエージェントを選び、ENTER で開きます。

確認 → 会話のタイトルが Mac で開いているものと同じです。タッチの場合：行をタップして選び、もう一度タップして開きます。

2. PTT を押しながら話し、離す。

デバイスで：左側面の PTT ボタンを押し続けます。エージェント名と「LISTENING」の表示を確認します。「このプロジェクトを要約して、次に何をすればいいか教えて」と話します。PTT を離すと送信します。録音を取り消すには、PTT の状態のまま CANCEL を押します。

MAC では → 話した依頼がそのセッションに届きます。前もって「Voice → Test Voice」で認識を確認してください。聞き取り画面が出ただけでは、届いたことの証明にはなりません。

3. 返信を読む。

デバイスで：エージェントが作業して返信するのを待ちます。SCROLL で会話を読み進めます。SHIFT を押しながら ENTER を押すと最新のメッセージに戻ります。LEFT / RIGHT で前 / 次のエージェントに切り替え、CANCEL で一覧に戻ります。

MAC では → アシスタントはいつものプロジェクトの会話で作業します。デバイスはつながった履歴と状態を表示するだけで、コーディングアシスタントを自分で動かすわけではありません。

4. エージェントに聞かれたら答える。

デバイスで：質問の通知が出たら、それをタップするか、ほかに触れる前に ENTER を押します。保留中のカードがある会話で ENTER を押しても開きます。質問を読み、SCROLL を回して選び、ENTER で送信します。CANCEL はカードを後回しにするだけで、「いいえ」を選ぶわけではありません。上から下へスワイプすると、もう一度見つけられます。

MAC では → 回答で対応する質問が解決します。「not delivered」と出たら、セッションを確認してそちらで答えてください。確定する前に実際の選択肢を読んでください。図の質問は例にすぎません。

続けて質問してみる

同じ会話でもう一度 PTT を押し、続きの質問をします。Codex では、待機中ならメッセージで新しいターンが始まり、実行中なら進行中のターンの方向を変えます。Claude Code では、Channels か代替の受信箱を通じて接続中のセッションに届きます。コンパニオンのウィンドウには会話のテキストは表示されません。

MAC で設定 · デバイスで使う07 — 音声とマクロの設定

あなたの声。
あなたのショートカット。

サービスを動かし、デバイスを接続したままにしておきます。画面例は英語版アプリ 0.15.0 のものです。以下の操作名も画面の英語表記に合わせています。選んだエンジンやページの並びは異なる場合があります。

音声を設定してテストする

  1. 認識の方法を選ぶ。

    Voice → Recognitionを開きます。この Mac で Apple を使うか、Whisper のモデルをダウンロードしてから使います。話す言語に合わせてSpeech languageを設定します。Apple の認識を使う場合は、Speech Recognition → Ask…を使い、macOS の確認で許可します。

  2. 実際の録音を確かめる。

    Test Voiceをクリックします。接続中のデバイスで PTT を押しながら「hello」と話して離します。エージェントに依頼を送る前に、認識されたテキストを確認します。空のままなら、モデルのダウンロード、権限、デバイスの接続を確認してください。

  3. 返信の読み上げを選ぶ。

    Spoken repliesで Apple を選ぶか、先に Kokoro をダウンロードします。クラウドの音声には、そのプロバイダーの設定が必要です。Speak a Sampleをクリックし、音量はDeck → Speakerで調整します。Play a Chimeで通知の音を確認します。

MAC でマクロを 1 つ作る

  1. マクロパッドを追加して選ぶ。

    Faces & Keys → Add a face → Macropadを開きます。ページの並びでそのタイルを選び、Macropad keysで空いている枠を選びます。

  2. キーに名前を付けて割り当てる。

    LabelにScreenshotと入力して Return を押します。Deck buttonを選ぶか、タッチのみのままにします。Keyを 4 にし、Modifiersで ⇧ と ⌘ を有効にします。変更は自動で反映されます。Mac の編集画面に保存ボタンはありません。

  3. デバイスで試す。

    Accessibility → Check…を使い、アクセスが必要ならOpen Settingsに従います。Mac のデスクトップにフォーカスを合わせます。デバイスで SHIFT を押しながら回してマクロパッドへ移動し、「Screenshot」をタップするか、割り当てたボタンを押します。スクリーンショットのカーソルが現れます。Escape で取り消します。

Mac とデバイスのページ順をそろえる

「Faces & Keys」で移動できるページを選び、「Move Left」または「Move Right」で並べ替えます。デバイスでは SHIFT + SCROLL がその順番になります。エージェントと設定は固定です。Mac とデバイスで同じページ名を使って、変更が届いたことを確かめてください。

そのまま進む。

最初の音声メッセージ

  1. エージェントのページで目的のエージェントを選びます。
  2. PTT を押し続けます。「LISTENING」の画面に正しいセッションが表示されていることを確認して、話します。
  3. PTT を離して終えます。認識と配信を待ち、デバイスで返信を読みます。

音声には、接続中のホストと設定済みの音声認識が必要です。返信の読み上げはホストの音声の設定にも左右されます。

最初のマクロ

  1. マクロパッドを開きます。「+ assign」をタップするか、SHIFT + CANCEL を押してキーを選びます。
  2. PTT を押したまま「Screenshot」と話し、ラベルにします。「Modifiers」→ ENTER を選び、SCROLL を回して ⇧⌘ にして ENTER。「Key」→ ENTER を選び、4 を選んで ENTER。「Save」→ ENTER を選びます。これで cmd + shift + 4 が割り当てられます。
  3. Mac のデスクトップにフォーカスを合わせ、「Screenshot」をタップします。macOS がアクセシビリティのアクセスを求めたら、「プライバシーとセキュリティ → アクセシビリティ」で表示されたアプリを有効にし、もう一度試します。スクリーンショットのカーソルが現れます。Escape で取り消します。

ショートカットは、フォーカスのあるアプリに送られます。

反応しないとき

デバイスに「offline」と表示される
OpenWalkieTalkie でService → Check my setupを開きます。USB のデータケーブルか Bluetooth の接続を確認します。デバイスを接続し直し、必要なら Macアプリで「Service → Restart」を使います。デモデータはライブの接続ではありません。
エージェントのセッションがない
Codex は 3 ページ、Claude Code は 4 ページに従ってください。「Installed」は連携のファイルがあることを示すだけで、セッションも開いて接続している必要があります。Desktop ではコンパニオンのランチャーを使ってください。
音声が入力されない
選んだセッション、ホストとの接続、音声認識エンジンを確認します。BLE では Bluetooth のアクセスを許可してください。Mac のマイクに切り替わることはありません。「Voice → Test Voice」で、選んだエンジンと権限を確認してください。BLE のデバイスは macOS の「サウンド」の入力デバイスではありません。
マクロが動かない
キーに割り当てがあり、ホストにアクセシビリティの権限があることを確認します。目的のデスクトップのアプリを選んで、もう一度ショートカットを試します。
画面がロックされている
どれかのキーを押すか、ホイールを回すか、画面に触れると点灯します。ホイールを反時計回りに 4 段回すとロックが外れます。その回転で下の画面が操作されることはありません。

ちょっと遊ぶ

フラッピーバード：PTT をタップして飛ぶ。
スネーク：ホイールを左 / 右に回す。
雷電：Left / Right を押し続けて移動。自動で撃ちます。
ENTER で一時停止。ベストスコアは再起動まで残ります。

電源と更新

PTT を 2 秒間押すと電源が入り、CANCEL を 3 秒間押すと電源が切れます。ファームウェアは Macアプリの「Service」ページから USB で更新します。ファームウェア 0.14.0 からは、デバイスで ENTER を押してインストールを始めます。
