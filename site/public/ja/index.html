押して話す

作業用のページでキーを押し続けると、画面が「聞き取り中」の表示に変わります。離すと、認識が終わるまで文字起こしが表示されたままになります。デバイスのマイクの音声は Mac に送られ、言葉は次のプロンプトとして選択中のエージェントに届き、返信はデバイスのスピーカーで読み上げることもできます。

一覧

エージェントはそれぞれ 1 つのチャンネルです。赤い点は質問、緑は完了、青は実行中。質問は上に並ぶので、最初に目に入る行が、あなたを必要としている行です。

質問 · 完了 · 実行中

カード

権限の確認や選択式の質問はカードになります。選択肢までスクロールして ENTER を押すか、タップするか、声で答えます。Claude Code や Codex の権限のカードを承認できるのは人だけです。

1 回で回答 · 判断に必要な情報を 1 枚に

ホイール

1 段で 1 行。SHIFT を押しながら同じホイールを回すと、ページが切り替わります。エージェント、Omarchy、マクロパッド、使用量、システム、ゲーム。SHIFT を 2 回押すと並べ替えられます。

SCROLL · SHIFT+SCROLL

マクロパッドのページ

タッチスクリーン上の 9 つのキーに、それぞれラベルとキー操作。ホストがその組み合わせをデスクトップに送ります。キーはデバイスの上で編集でき、ラベルは PTT で口述できます。

⌘⇧4 · タップまたは本体キーに割り当て

使用量のページ

Claude と Codex の利用枠を、集計期間ごとのバーで表示します。使用中のアカウントと、各枠がリセットされるまでの時間も確認できます。ホストは既存のログイン情報を使って取得します。

セッション · 週 · リセット

ケーブルでも無線でも

USB-C でつなぐと、ホストは 1 ミリ秒未満でレポートを書き込みます。外すと、音声も含めて同じ接続が Bluetooth LE に移ります。ケーブルがあれば、ホストはいつもケーブルを使います。

        第 6 章

        設計図

        オープンな設計から自分で作るか、完成品のためにウェイトリストに登録してください。基板、ファームウェア、ホスト側のサービス、通信プロトコルがすべて 1 つのツリーにあります。

        リポジトリの構成 · openwalkietalkie MIT + CERN-OHL-P
        • openwalkietalkie/ 基板、ファームウェア、Macアプリがまとめて入っています。クローンしてすぐ始められます。
        • ├─ hardware/rev-b/ メイン基板 Rev B：ガーバー、BOM、実装座標付きの KiCad プロジェクト。CERN-OHL-P 2.0。
        • ├─ hardware/rev-a/ 始まりの場所：CoHDL の回路図のソース、製造した 4 つのリリース、ケースの CAD。
        • ├─ src/ embassy 上の Rust ファームウェア：各ページ、BLE と USB による HID 接続、ペアリングの記録、電源管理。
        • ├─ native/ Bluetooth オーディオ付きの RT-Thread イメージ。同じ UI のコアを載せています。
        • ├─ host/ deckd と Macアプリ、Rust + gpui：接続、Claude Code と Codex のアダプター、音声、オープンな API。
        • └─ docs/deck-protocol.md チャンネル 5 の通信仕様。これに沿ってスクリプトを実装すれば、デバイスのエージェント一覧に表示できます。

        ソフトウェアは MIT。基板、ケース、すべての設計ファイルは、制約の少ない CERN オープンハードウェアライセンス。作るのも、改造するのも、売るのも、許可はいりません。

        ハードウェアの設計は CoHDL から始まりました。Rev A の回路図は、オープンソースのハードウェア言語で書かれたソースコードで（cohdl.org）、そのコンパイラーで検査しています。Rev B はその流れを受けて、KiCad で手作業で配置・配線しました。

        ★ GitHub で設計図を入手 ▼ Mac 版をダウンロード Discord に参加

        Macアプリには deckd、アプリの自動更新、Rev A と Rev B のファームウェア更新が含まれます。ソースには、最初の USB-C または UART での書き込みに使うツールも含まれます。

        第 7 章

        実物

        作り直した本体を 2 色で、2026年11月に撮影しました。続いて Rev A 基板のレンダリング。基板の設計と、以前の BodyV6.13 のケースはリポジトリにあります。

        1 / 8
        • 頭脳SiFli SF32LB52x、Cortex-M33、16 MB フラッシュ、8 MB PSRAM。embassy 上で Rust が動きます
        • 画面2.16 インチ CO5300 AMOLED、480 × 480、CST9220 タッチ
        • 基板4 層のメイン基板と 2 層のエンコーダー基板。どちらもリポジトリにあります
        • ケース3D プリント。2026年11月に作り直しました。以前の BodyV6.13 の Fusion のソースはハードウェアに同梱しています
        • オーディオMP34DT05 PDM マイクと NS4150B スピーカーアンプ
        • 接続USB-C と Bluetooth LE、1 つの HID デバイス：VID 1209、PID 5754
        • バッテリー3.7 V、500 mAh のセル。USB-C で充電
        • 状況Rev A の試作機が作業台に · Rev B のメイン基板は設計済み

        アプリを入手

        v0.17.0。macOS 13 以降、署名・公証済み。Mac、Windows、Omarchy で使える、デバイスのコンパニオンアプリです。Windows 10 と 11 は署名なしのプレビュー版です。

        ↓ Mac · Apple シリコン ↓ Mac · Intel ↓ Windows · x64 プレビュー版 Omarchy · Linux

        ディスクイメージを開き、OpenWalkieTalkie を「アプリケーション」フォルダにドラッグして、アプリのセットアップに従います。M シリーズの Mac は Apple シリコンを、Intel の Mac は Intel を選んでください。

        Windows 10 または 11（x64）では、署名なしのプレビュー版が音声、Claude Code、Codex CLI、Grok Bot に対応しています。セットアップと SmartScreen については Windows のインストールガイドを読み、プレビュー版のリリースノートとチェックサムを確認してください。

        Omarchy（Hyprland）のノートパソコンでは、サービスと Omarchy ブリッジをソースからビルドします。デスクトップのリモコン、エージェントのセッション、音声の指示については Omarchy のガイドに従ってください。

        アプリには、自動更新と、基板に合わせた Rev A・Rev B の USB でのファームウェア更新が含まれます。最初の書き込みには対応するブートローダーが必要です。リリースノート、ファームウェア、チェックサム →
