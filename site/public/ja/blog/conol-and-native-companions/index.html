OpenWalkieTalkie v0.11.0：Conol とネイティブコンパニオン

2026年10月28日アプリとファームウェアの更新

0.11.0 では、デバイスが Conol のデスクトップアプリの会話につながります。ハンディデバイスからチャットを開き、最近のメッセージを読み、続きを口述し、質問に答えられます。同じローカルのコンパニオンのインターフェースは、ほかのアプリでも使えます。

Conol の会話をひとまとめに

対応する Conol のデスクトップアプリが動いていてサインイン済みなら、チャットは Conol の下に、ロボットのモザイクの絵柄と + New chat のランチャーとともに表示されます。会話を選ぶと、最近の公開のユーザーとアシスタントのメッセージが見られます。PTT を押して続きを口述するか、ランチャーに向かって口述すると新しいチャットを作れます。

作ったチャットはデバイスで開き、次のメッセージを待ちます。Conol はローカルの OpenWalkieTalkie のサービスを自動的に見つけるので、ターミナルのフックや別のモデルの API キーを設定する必要はありません。この接続には、OpenWalkieTalkie ブリッジを備えた Conol のデスクトップアプリが必要です。ブラウザー版はローカルのサービスに接続しません。

フォーム全体にハンディデバイスで答える

Conol は AskUser のフォームやワークフローの承認を、1 問ずつ表示できます。単一選択をページ送りし、複数選択を切り替え、自由入力を口述し、確認と修正をしてから、フォーム全体を明示的に送信します。下書きの回答は、コンパニオンのソケットが接続し直しても残ります。この操作に収まらないフォームは Conol で開きます。

セッションのパネルには、会話で実際に使われているモデルと思考の深さが表示されます。Conol では今のところ読み取り専用なので、変更は Conol で行ってください。会話の履歴には公開のユーザーとアシスタントのテキストが反映されます。画像、ツールの出力、非公開の推論は所有するアプリに残ります。

ほかのアプリにも開かれている

この連携は公開の JSON-RPC のインターフェースを使います。アプリは agent.companion.set で独自のグループ分けと新しいチャットのランチャーを提供し、メッセージや質問を公開し、agent.session.set で実際のモデルと思考の深さを報告できます。変更可能な設定に対応するアプリは、要求された変更をそれぞれ正確なリビジョンに対して確定します。

新しいネイティブコンパニオンのガイドでは、検出、登録、会話の履歴、フォーム、設定、再接続を説明しています。単体で動く Python のサンプルも試してください。用意された返信を使うので、モデルの API キーは不要で、Conol をインストールしていなくても動きます。自動生成した API リファレンスには、リクエストのスキーマと権限が載っています。

新しいチャットにフォーカスを保つ

サービスは、入れ替えたスロットの新しい持ち主を、フォーカスする前に知らせるようになりました。デバイスは PTT を離した直後にコンパニオンの明示的な選択に従い、入力が押されている間は待ち、あなたがほかへ移動したら譲ります。終わっていない質問は開いたままです。

共有の 8 スロットの上限は変わりません。あふれたコンパニオンのチャットを開くと、同じ接続・同じアプリ・同じアカウントの、固定されていない同列のチャットと入れ替わることがあります。ランチャーと、ほかのアカウントの作業中のチャットは残ります。

0.11.0 に更新する

Apple シリコン用または Intel 用の、署名・公証済みの Mac アプリをインストールするか、アップデートを確認を選んでください。macOS 13 以降が必要です。デバイスを USB-C で接続し、サービス → 更新 → ファームウェア更新を確認を選びます。ネイティブコンパニオンに対応するには、Mac のサービスとファームウェアの両方が 0.11.0 である必要があります。古いサービスがまだ動いている場合は、サービス → 再起動を選びます。Conol も、OpenWalkieTalkie ブリッジを備えたビルドに更新してください。

通常の更新では、設定と Bluetooth のペアリングは保たれます。リカバリープロトコル 2 とフラッシュの配置は変わりません。別の工場用 ZIP は製造用で、設定とペアリングを上書きします。

自動テストは、所有権、グループ分け、スロットの繰り上げ、設定の確定、フォーカスの順番、押されている入力、プロトコルの解析、描画、サンプルのフォームと再接続を確認しています。このリリースでは、実際の Conol の会話と基板でのテストは繰り返していません。
