OpenWalkieTalkie v0.9.0：聞き取りやすい USB 音声とリセットのリマインダー

2026年10月22日アプリとファームウェアの更新

バージョン 0.9.0 では USB での音声が聞き取りやすくなり、見落としやすいことのリマインダーが加わりました。期限切れが近い、未使用の手動の使用量リセットです。両方の改善を使うには、Macアプリとデバイスのファームウェアを更新してください。

言葉を聞く

最初に音楽で 16 kHz と 48 kHz を聞き比べました。聞き手にははっきりした違いは分かりませんでした。英語の音声では結果が違いました。スピーカー EQ を有効にして音量をそろえると、48 kHz の一節のほうが聞き取りやすく、16 kHz 版で聞こえていたノイズも消えました。

接続中のファームウェアが対応していれば、デバイスはUSB 経由で 48 kHz のスピーカー再生を使うようになりました。サービスがこの機能を自動で確認し、EQ を有効にしたまま、古いファームウェアでは 16 kHz に戻します。接続を切り替えたときや、押して話す機能を離したあとも、再生はネゴシエーションしたレートに従います。

これは再生経路の改善であり、元の音声になかった細部を作り出すものではありません。テストに使った Kokoro の音声は 24 kHz で出力されました。これを 48 kHz の経路に通すと、以前の 16 kHz への変換を避けられ、圧縮と再構成の経路も変わります。

16 kHz の経路も改善

ホストは量子化誤差を減らすために別の ADPCM エンコード経路を探し、元の結果のほうが良い場合は元の結果を残します。ファームウェアは、16 kHz の音声を 48 kHz の DAC に送る前の処理で、線形補間の代わりに帯域制限フィルターを使うようになりました。

同じ英語の一節で、改良したエンコーダーはエンコード誤差の二乗を約 30% 減らしました。これはデジタルでの測定値であり、聞こえるヒスノイズが完全に消えるという約束ではありません。改良した 16 kHz の経路は、まだ聞いての確認が必要です。

BLE での再生とマイクの録音は 16 kHz のままです。USB での比較は、どちらのレートでも途切れ、アンダーラン、キューの破棄、シーケンスエラーなしで完了しました。BLE で 48 kHz の再生を続けた場合の検証はまだなので、このリリースでは高いレートを USB に限っています。

期限切れの前にリセットを使う

未使用の手動リセットのクレジットが 72 時間以内に期限切れになるとき、Mac の「使用量」ページとデバイスの「使用量」ページで、週間バーの下に小さな琥珀色のヒントが表示されるようになりました。例：「2 回のリセットがあと 1日6時間で期限切れ」

これは、週ごとの上限が回復するまでの通常のカウントダウンとは別のものです。ヒントは最も近いクレジットの期限を使い、その期限のクレジットだけを数えます。クレジットを使うか期限が切れると消え、アカウントが変わると前のアカウントのクレジットを消し、未接続の間は表示されません。プロバイダーがこのデータを提供しない場合、リマインダーは表示されません。デバイスがリセットを代わりに使うことはありません。

両方を更新する

署名・公証済みの Macアプリ（Apple Silicon または Intel）をインストールするか、アップデートを確認を選びます。macOS 13 以降が必要です。次にデバイスを USB-C で接続し、サービス → 更新 → ファームウェア更新を確認を使います。アプリ、サービス、ファームウェアがすべて 0.9.0 と表示されるはずです。

リカバリープロトコル 2 を使っているデバイスでは、通常の更新で設定と Bluetooth のペアリングが保持されます。それより古いリカバリーのバージョンでは、既存のガイド付き移行を使います。基板ごとの出荷時 ZIP は製造用に引き続き提供しますが、チップ全体のイメージが設定とペアリングを上書きするため、お使いのデバイスにはアプリのアップデーターを使ってください。

ブログもリリースの一部

リリースの検証ツールは、リリースを公開する前に、ブログ記事、そのフィード項目、ブログ一覧へのリンク、サイトマップの項目、最新の Mac 用ダウンロードがそろっていることを求めるようになりました。抜けていた 0.7.0 と 0.8.0 の記事も公開しました。

開発版ファームウェアと音声の比較は Rev A で USB 経由で確認し、更新したサービスを再起動したあと、デーモンの通常の再生が 48 kHz であることも確認しました。自動チェックでは、レートのネゴシエーション、接続の切り替え、音声のエンコードとフィルター、リセットの期限とアカウントの切り替え、描画を確認しています。このセッションでは Rev B の音声を実機で試していません。
