OpenWalkieTalkie v0.4.0：画面でわかるリカバリーと、広がった容量

2026年10月18日アプリとファームウェアの更新

OpenWalkieTalkie 0.4.0 では、デバイスに機能を載せる余地が広がり、ファームウェアのリカバリーの様子がデバイス本体に表示されるようになりました。中国語テキストにも対応し、Codex の質問と回答も読みやすくなっています。

アプリケーションが使えるフラッシュが増えました

16 MiB の NOR フラッシュのうち、15.75 MiB をアプリケーションのコードとアセットに使えるようになりました。パーティションテーブル、ブートローダー、2 つの Bluetooth 保存領域は、それぞれの領域を引き続き確保しています。中国語フォントはアプリケーション領域の上位バンクに置き、下位バンクにコード用の余裕を残しています。

クロック設定を修正したことで、ファームウェアは再び NOR フラッシュから直接実行されます。起動時にアプリケーション全体を PSRAM にコピーすることはなくなりました。

リカバリー画面と、より速い USB 更新

新しいブートローダーは、リカバリーの手順、転送の進捗、完了、エラーをデバイスの画面に表示します。更新済みのデバイスはスパース転送とパイプライン化した USB バルク転送を使えるため、パディング部分への書き込みを省き、Bluetooth 保存領域をそのまま残します。

古いブートローダーからの最初の更新は、これまでどおり一時的なアップデーターを HID で転送するところから始まります。この段階には数分かかります。以降の段階では新しい転送方式を使えますが、フラッシュの消去と書き込みにかかる時間は全体の時間に含まれます。

0.3.0 からの更新

0.4.0 の Macアプリをインストールし、USB-C データケーブルでデバイスを 1 台接続して、サービス → 更新 → ファームウェア更新を確認 を開きます。先に進む前に、基板のリビジョンとシリアル番号を確認してください。

この更新ではブートローダーが置き換えられることがあります。アプリが成功を表示するまで、USB-C の電源を接続したままにし、Mac をスリープさせないでください。ブートローダーの置き換え中に電源が切れると、起動も USB によるリカバリーもできなくなり、ハードウェア修理が必要になることがあります。アプリはこの警告を表示し、移行の前に明示的な確認を求めます。

アプリは一時的なアップデーターをインストールし、ブートローダーをバックアップしてから置き換え、読み戻して書き込みを検証し、最後に最終版のファームウェアをインストールします。bootstrap や recovery のファイルを手動で書き込まず、このガイド付きの手順を使ってください。アップデーターはパーティションテーブルを書き換えず、Bluetooth 保存領域も飛ばします。

完了すると、デバイスの「情報」に 0.4.0 · Rev A または 0.4.0 · Rev B と表示されます。バージョン表示はファームウェアのビルドに自動で追従するようになりました。両方の基板のファームウェアと検証済みのマニフェストがアプリに同梱されているため、オフラインでもファームウェアを更新できます。

中国語テキストと、読みやすくなったエージェントとのやり取り

同梱の Noto Sans CJK フォントにより、簡体字と繁体字の中国語を表示できるようになりました。Codex の確認の質問と回答は、転送用のエンベロープのままではなく、読みやすい見出し、質問の文脈、回答の本文として表示されます。このリリースには、0.3.0 以降に追加された Codex Desktop との連携と Bluetooth の電波強度表示も含まれています。

テスト済みの内容

両方の基板向けにビルドでき、ソフトウェアのチェックにも合格しています。以前の 0.3.1 候補版では、Rev A で元の 0.3.0 から新しいブートローダーへの GUI による移行を最後まで完了し、所要時間は約 5 分半でした。使ったリカバリーのソースは同じです。CI でリリース用に再ビルドしたものはブートローダーのバイト列が異なり、このテストでは書き込んでいません。

0.4.0 最終版での GUI の再テストは、書き込みの前にローカルのデスクトップ自動化によって止まりました。出荷済みの Rev B が手元になかったため、その完全な移行、表示の動作、ペアリングと設定が保持されるかどうかは、まだ実機で確認する必要があります。これらは未完了の確認であり、完了した検証ではありません。今回のセッションではデバイスの音声テストは行っていません。

v0.4.0 を入手する

アップデートを確認 を使うか、Apple Silicon または Intel 向けの署名・公証済みの Macアプリをダウンロードしてください。macOS 13 以降が必要です。

GitHub のリリースには、ファームウェア、チェックサム、中国語のアップグレードガイドが含まれています。同じガイドは DMG の中にも入っています。
