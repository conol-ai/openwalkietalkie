OpenWalkieTalkie v0.2.0：ワークフローがひと目でわかる

2026年10月13日アプリとファームウェアの更新

OpenWalkieTalkie v0.2.0 では、バックグラウンドで動き続ける作業を追いやすくなりました。Macアプリとハンディデバイスで、エージェントとの会話と並べてワークフローの進捗をリアルタイムに表示します。

作業を追う

セッションを開いて「ワークフロー」に切り替えると、そのプランとコンパクトなツールの動作が表示されます。Claude Dynamic Workflows では、実行ごとの名前、進捗バー、完了したワーカー数と開始したワーカー数、経過時間、トークン数も表示されます。親の会話が止まっているあいだも、バックグラウンドの実行は更新され続けます。

デバイスは、置き換えの内容が届くまで現在のワークフローページを表示し続けます。これにより、定期的な更新時のちらつきが解消されました。スクロール位置はそのまま保たれ、ツールの詳細も引き続き展開できます。

使用中のアカウントの使用量

Macアプリに専用の「使用量」ページが加わりました。アカウントが Claude Fable の週間使用量上限を提供している場合は、アプリとデバイスの両方に表示されます。各メーターには、使用中のアカウント、使用率、リセット時刻が表示されます。Claude と Codex の上限は並べて表示されます。

v0.2.0 の入手

Macアプリでアップデートを確認を使うか、Apple Silicon または Intel 用の署名・公証済みのパッケージをダウンロードしてください。macOS 13 以降が必要です。

デバイスは USB で接続し、アプリでサービス → 更新を開きます。ファームウェアを確認し、選択された基板を確かめてから v0.2.0 をインストールしてください。Rev A と Rev B のイメージが含まれています。最初の書き込みには、対応するブートローダーが引き続き必要です。

リリースノート、ファームウェアのダウンロード、チェックサムをご覧ください。
