OpenWalkieTalkie v0.12.0：Conol があなたの声を聞き取り、ポモドーロも

2026年11月5日Macアプリ、サービス、ファームウェア

デバイスから Conol のチャットに話しかけたとき、その言葉は Conol に直接入力した場合に Conol が聞き取るものと同じであるべきです。バージョン 0.12.0 では、その録音を Conol 自身の音声モデルに渡し、話している間は録音のタイムラインを表示し、Conol がいま何をしているかを映し出し、ポモドーロ付きの「タイマー」ページを追加しました。

Conol が自分のチャットを文字起こし

Conol のチャットや + New chat で PTT を押すと、Mac のサービスがその録音を Conol デスクトップアプリに渡します。Conol は入力欄のマイクに使っているクラウド音声モデルで文字起こしし、キーを離したあとデバイスに表示され、送信されるのはそのテキストです。Conol の質問への口述の回答も同じです。

押している間は Mac 自身の認識エンジンも動いています。Conol が応答できない、失敗した、または 20 秒以上かかった場合は Mac の文字起こしが使われるため、録音が失われることはありません。ほかのエージェントや、デバイス上での声による名前付けは Mac 上で処理されたままです。Mac の外に出るのは Conol のチャット宛ての録音だけで、送り先はサインインしている Conol アプリだけです。[voice.stt] companion = false を設定すると、すべての録音をローカルに留められます。これには更新された Conol のデスクトップ版と Web 版が必要です。古い Conol アプリでは何も変わりません。

話している間のタイムライン

Mac のライブの文字起こしは Conol が聞き取る内容とは異なるため、これらの録音ではデバイスに表示しなくなりました。代わりに録音中、大きな経過時間、タイムラインを表示します。赤い再生ヘッドが左から右へ進み、その後ろにデバイス自身のマイクで測ったあなたの声の波形が描かれていきます。長く押すとスクロールします。キーを離すとデバイスは文字起こし中を表示し、続いて Conol の文字起こしを表示します。

Conol がしていることを見る

実行中の Conol のチャットは、現在の公開ステップを「Running a command」のように短いプレビュー付きでデバイスに表示するようになりました。一覧と会話の両方に表示されます。表示はその場で更新され、ステップが終わると消えます。ツールの入力と結果の全文は Conol に残ります。

タイマーとポモドーロ

ページ管理の + テンプレートからタイマーを追加すると、ラップ付きのストップウォッチ、プリセット付きのカウントダウン、そしてポモドーロが使えます。ポモドーロは集中 25 分と休憩 5 分で、集中を 4 回終えると 15 分の休憩になります。各フェーズは次へ / Enterを押すまで待ちます。タイマーはデバイス本体で動き、ほかのページにいるときや画面がスリープしている間も進み、終了すると画面を点けて通知を表示します。

コンパニオンアプリの開発者向け

独自の認識エンジンを持つネイティブのコンパニオンアプリは、caps.transcribe: "push" を登録し、agent.transcribe の依頼を受け取り、agent.transcribe.audio で 16 kHz の WAV をページ単位で取得し、agent.transcribe.result で回答できます。アクティビティ行には agent.reply の message.summary を使います。ネイティブコンパニオンのガイドと API リファレンスで両方を説明しています。

更新

アップデートを確認を選ぶか、署名・公証済みの 0.12.0 Macアプリ（Apple Silicon または Intel）をインストールしてください。macOS 13 以降が必要です。録音のタイムラインと「タイマー」ページにはファームウェア 0.12.0 が必要です。デバイスを USB で接続した状態で、サービス → 更新 → ファームウェア更新を確認を開いてください。設定と Bluetooth のペアリングは保持されます。
