卡片

权限请求或选择题会变成一张卡片。滚动到一个选项按 ENTER、点按它，或者用语音回答。Claude Code 或 Codex 的权限卡片只能由人来批准。

滚轮

转一格，移一行。按住 SHIFT，同一个滚轮就在页面之间滑动：助手、Omarchy、快捷键、用量、系统和游戏。连按两次 SHIFT 可以重新排序。

SCROLL · SHIFT+SCROLL

“快捷键”页面

触摸屏上的九个按键，每个都有标签和按键组合。主机端把组合键发到你的桌面。直接在设备上编辑按键，用 PTT 口述它的标签。

⌘⇧4 · 点按或绑定

“用量”页面

你的 Claude 和 Codex 速率限制窗口显示为进度条，带有当前账户和每次重置的倒计时。主机端只用你已有的登录来读取，别无其他。

        第六章

        设计图纸

        按开放的设计自己动手做一台，或加入候补名单等成品。主板、固件、主机端服务和通信协议都在同一个仓库里。

        清单 · openwalkietalkie MIT + CERN-OHL-P
        • openwalkietalkie/ 主板、固件和 Mac 应用，全在一起。克隆下来就能开始。
        • ├─ hardware/rev-b/ Rev B 主板：一个 KiCad 项目，含 Gerber、BOM 和贴片坐标。CERN-OHL-P 2.0。
        • ├─ hardware/rev-a/ 一切的起点：CoHDL 原理图源文件、四个已打样的版本、外壳 CAD。
        • ├─ src/ 基于 embassy 的 Rust 固件：各个页面、经 BLE 和 USB 的 HID 连接、配对日志、电源管理。
        • ├─ native/ 带蓝牙音频的 RT-Thread 镜像，挂载同一套界面核心。
        • ├─ host/ deckd 和 Mac 应用，Rust + gpui：连接、Claude Code 和 Codex 适配器、语音、开放 API。
        • └─ docs/deck-protocol.md 通道 5 上的通信约定。读完它，你的脚本就能成为设备上的助手。

        软件采用 MIT 许可。主板、外壳和所有设计文件采用宽松的 CERN 开放硬件许可证。制作、修改、出售，都无需许可。

        硬件设计始于 CoHDL。Rev A 原理图是用开源硬件语言写成的源代码，见 cohdl.org，由它的编译器检查；Rev B 沿着这条脉络，在 KiCad 中手工布局布线。

        ★ 在 GitHub 获取设计图纸 ▼ 下载 Mac 版 加入 Discord

        Mac 应用包含 deckd、应用自动更新，以及 Rev A 和 Rev B 的固件更新。源代码中包含首次通过 USB-C 或 UART 烧录所需的工具。

        第七章

        实物

        重新设计的机身，两种配色，摄于 2026 年 11 月；后面是 Rev A 电路板的渲染图。电路板设计和早期的 BodyV6.13 外壳都在仓库里。

        1 / 8
        • 大脑SiFli SF32LB52x，Cortex-M33，16 MB 闪存，8 MB PSRAM，运行基于 embassy 的 Rust
        • 屏幕2.16" CO5300 AMOLED，480 × 480，配 CST9220 触摸
        • 电路板四层主板和两层编码器板，都在仓库里
        • 外壳3D 打印，2026 年 11 月重新设计；早期的 BodyV6.13 Fusion 源文件随硬件一起提供
        • 音频MP34DT05 PDM 麦克风和 NS4150B 扬声器功放
        • 连接USB-C 和低功耗蓝牙，同一个 HID 设备：VID 1209，PID 5754
        • 电池3.7 V、500 mAh 电芯，通过 USB-C 充电
        • 状态Rev A 原型机在工作台上 · Rev B 主板已完成设计
