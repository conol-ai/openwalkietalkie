按键通话

在工作界面按住 PTT，屏幕就会显示正在聆听。松手后，识别完成前，转写文字仍会留在屏幕上。麦克风把声音传到 Mac，识别出的文字会成为当前助手的下一条指令；回复也可以从对讲机的扬声器播出来。

助手列表

每个助手都是一个频道。红点表示有问题等你处理，绿点表示本轮已完成，蓝点表示正在运行。待回答的问题会排在最上面，不用再挨个找。

待回答 · 已完成 · 运行中

交互卡片

需要授权或选择答案时，屏幕会弹出一张卡片。转动滚轮选好，再按 ENTER；也可以触屏或语音回答。Claude Code 和 Codex 的授权卡片必须由你亲自确认。

看清来龙去脉，按一下就回应

滚轮

滚轮每转一格，就移动一行。按住 SHIFT 再转，就能切换助手、Omarchy、宏键盘、用量、系统和小游戏界面。双击 SHIFT，还可以调整它们的顺序。

SCROLL · SHIFT+SCROLL

宏键盘

触摸屏上有九个自定义按键，每个都能设置名称和快捷键组合。点一下，配套软件就会在电脑上执行。你也能直接在对讲机上编辑按键，按住 PTT 说出它的名字。

⌘⇧4 · 点按或绑定

用量统计

用进度条查看 Claude 和 Codex 各个限额周期的用量，同时显示当前账号和重置倒计时。配套服务使用你已有的登录信息读取这些数据。

会话额度 · 每周额度 · 重置时间

插线用，也能无线用

通过 USB-C 连接时，电脑端写入一条 HID 报文用不到一毫秒。拔掉数据线，数据和语音就改走低功耗蓝牙；插线时优先使用 USB。

        第六章

        开源设计

        想自己做，就用公开的设计文件；想买成品，就加入等候名单。电路板、固件、配套服务和通信协议，都放在同一个仓库里。

        仓库内容 · openwalkietalkie MIT + CERN-OHL-P
        • openwalkietalkie/ 电路板、固件和 Mac 软件都在这里，克隆仓库就能开始。
        • ├─ hardware/rev-b/ Rev B 主板：KiCad 工程，附 Gerber、物料清单和贴片坐标文件。采用 CERN-OHL-P 2.0 许可。
        • ├─ hardware/rev-a/ 项目的起点：CoHDL 原理图源码、四个已打样版本，以及外壳 CAD 文件。
        • ├─ src/ 基于 embassy 的 Rust 固件：各功能页面、蓝牙与 USB HID 连接、配对记录和电源管理。
        • ├─ native/ 支持蓝牙音频的 RT-Thread 镜像，使用同一套界面核心。
        • ├─ host/ deckd 和 Mac 软件，使用 Rust + gpui：设备连接、Claude Code 与 Codex 适配、语音，以及开放 API。
        • └─ docs/deck-protocol.md 第 5 通道的通信协议。照着接入，你的脚本也能作为助手出现在对讲机上。

        软件采用 MIT 许可；电路板、外壳和全部设计文件采用宽松的 CERN 开源硬件许可。你可以制作、修改和销售，无需另行申请许可。

        硬件设计从 CoHDL 起步。Rev A 的原理图用开源硬件语言编写，并由其编译器检查；语言介绍见 cohdl.org。Rev B 延续这一设计，在 KiCad 中手工布局和布线。

        ★ 去 GitHub 获取设计文件 ▼ 下载 Mac 版 加入 Discord 社区

        Mac 软件内置 deckd、软件自动更新，以及 Rev A 和 Rev B 的固件更新。源码中也包含首次通过 USB-C 或 UART 刷写所需的工具。
