入门指南 · 应用 0.17.0

入门指南

macOS、Windows 与 Linux · 约十分钟

装好应用、连上设备、接通一个编程 agent。三步之后，设备就是你已打开会话的第二块屏幕。

你需要准备

  • 一台有电的设备。
  • 一台 macOS 13 或更新版本的 Mac、一台 Windows 电脑，或 Linux（受支持的配置是 Omarchy）。
  • 一根 USB-C 数据线。只供电的线连不上任何东西。
  • 一个已安装并登录的编程 agent：Claude Code、Codex 或 Grok Bot。

1 · 安装应用

macOS

  1. 从下载区按你的芯片下载磁盘映像，打开后把 OpenWalkieTalkie 拖进 应用程序。
  2. 从「应用程序」启动，不要从磁盘映像里启动。从映像里运行的副本会被 macOS 隔离，无法注册后台服务。

Windows

  1. 从发布页下载 OpenWalkieTalkie-0.17.0-windows-x86_64.zip，解压到一个你会长期保留的文件夹。
  2. 这个构建没有签名：SmartScreen 会提示 Windows 已保护你的电脑。点更多信息，再点仍要运行。

Windows 指南讲预览版、托盘图标，以及通过 USB-C 升级固件。

Linux

受支持的配置是 Omarchy。编译并安装服务与应用，再加载设备与虚拟键盘的两条 udev 规则。Omarchy 指南里有命令，照着那页做：本页只说它排在流程的哪一步。

2 · 连接设备

  1. 先接线。接上 USB-C 数据线，macOS 询问时允许该配件。按住 PTT 两秒开机。
  2. 无线连。在蓝牙里配对 OpenWalkieTalkie，并在隐私与安全性 → 蓝牙里允许这个配套应用。
  3. 确认连接。打开 设备 → 你的设备 → 连接。出现带 线缆 或 蓝牙 的绿点，说明服务看得到它。

3 · 启动后台服务

打开 服务。第一张卡片说明后台服务是否在运行；设备上其余的一切都依赖它。

  • macOS。没在运行就按 启动。如果那一行说在等待批准，就打开「系统设置」，在登录项里允许它：不批准它不会启动。
  • Windows。服务通过 Run 键在登录时启动，登录时启动 这一行显示并控制它。
  • Linux。systemctl --user status deckd。如果没有这个 unit，说明 Omarchy 指南里的安装脚本还没跑过。

关窗口之前把 登录时启动 打开。没有服务的设备，只会显示离线。

4 · 接通一个 agent

先接一个就够。集成 页每一行对应一个 agent，具体步骤见各篇教程。

  • Claude Code —— 装插件，再带 Channels 启动会话。Claude Code 教程
  • Codex —— CLI 自己会挂上；Codex Desktop 需要配套的启动器。Codex 教程
  • Grok Bot —— 一个 routine 的 webhook 进来，命令出去。Grok Bot 教程

已连接 指集成的文件已经就位。真正让一行出现在设备上的，是活着的会话。

5 · 说一句话

  1. 在设备上按 CANCEL 进入 Agents。LEFT / RIGHT 换项目，滚轮移动高亮，ENTER 打开会话。
  2. 按住 PTT，说「总结一下这个项目，告诉我下一步做什么」，然后松开。录音会发到你 Mac 上打开的那个会话。
  3. 在设备上读回复。agent 提问时，按 ENTER 打开卡片，滚轮选择，ENTER 作答。

出问题的时候

服务没在运行
服务 → 启动。macOS 上如果那一行说在等待，就到登录项里允许。按了「启动」没反应，说明用的不是安装好的那份副本。
设备上没有会话
集成要设置好，并且得有一个打开的会话。Codex 未运行 表示还没有活着的本地会话。
语音输入没反应
先看选中的会话、连接状态，以及 语音 里选的语音引擎。用 测试语音。它不会退回去用 Mac 的麦克风。
设备显示离线
检查线缆或配对，然后 服务 → 重启。演示数据不是真实连接。
屏幕锁住了
按任意键或触摸屏幕，然后把滚轮逆时针转四格。这四格只解锁，不会移动选中项。
服务已注册，但起不来
macOS 找到了后台项，却没把 Contents/MacOS/deckd 解析到应用包里，launchd 以退出码 78 放弃。先用 Finder 打开一次应用，或对已安装的副本跑一次 lsregister -f 刷新 bundle 索引，再点「启动」。系统自己也会重试；之后启动成功，last exit code = 78 仍会留着：看 state 和 pid，别看这个数字。

这一页是怎么核对的

本页引用的界面文字和截图都取自安装在 Mac 上的 0.17.0。截图由应用自带的合成渲染模式生成，不会碰正在运行的服务。写这一页时没有接真设备，所以连接设备的相关步骤没有端到端跑过；Linux 侧确认了服务单元已安装并启用、两条 udev 规则已就位。Windows 的步骤依据 0.17.0 安装包与 Windows 指南整理。
