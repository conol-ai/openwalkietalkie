在 Omarchy 上使用 OpenWalkieTalkie

把设备变成 Omarchy（Hyprland）笔记本的遥控器

在 Omarchy 上，设备直接操控你的桌面和编程助手，不需要 Mac。笔记本上运行两个小服务：deckd，即 Mac 应用所运行的同一个服务的 Linux 版本；以及 Omarchy 桥接，它把服务连接到 Hyprland 以及你的 Claude Code、Codex 和 Kimi Code 会话。

  • Omarchy 页面：你的工作区和窗口。滚轮切换窗口，LEFT / RIGHT 切换工作区，ENTER 切换全屏，SHIFT+CANCEL 切换 scratchpad。
  • 列表中的会话，显示为运行中、已完成或正在提问。选中一个会把它的终端切到最前。
  • 语音指令：在一个会话上按住 PTT 说话。说的话会输入到它的终端里，这一轮结束时回复会显示并朗读出来。
  • “快捷键”、“系统”和“用量”页面，数据来自这台笔记本。
  • 配套应用，和 Mac 上是同一个窗口，在 Omarchy 的应用启动器中。

Linux 版还没有下载包：你需要从源代码构建 deckd 和应用，第一次大约需要十分钟。下面的每条命令都在 Omarchy 笔记本的终端中运行。

1. 安装工具

sudo pacman -S --needed base-devel git rustup cmake clang espeak-ng wtype
rustup default stable

cmake 和 clang 用于构建本地语音识别器，espeak-ng 在设备上朗读回复，wtype 把指令输入到终端。构建所需的其他库（udev、ALSA、D-Bus）Omarchy 已自带。

2. 构建并安装

git clone https://github.com/conol-ai/openwalkietalkie.git
cd openwalkietalkie/host
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

install.sh 会把 deckd 和应用放到 ~/.local/bin，把应用以 OpenWalkieTalkie 的名称加入 Omarchy 的启动器，把桥接复制到 ~/.local/share/openwalkietalkie/omarchy，并把两者作为 systemd 用户服务 deckd 和 omarchy-deck 启动。每次登录时它们都会再次启动。最后它会打印需要 root 权限的步骤，也就是下一节。

3. 让服务能打开设备

设备的 HID 设备节点属于 root，直到一条 udev 规则把它交给你。运行 install.sh 打印出的两条命令：

sudo install -m 644 omarchy/70-openwalkietalkie.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw

这条规则对通过 USB-C 和蓝牙连接的设备都适用。

4. 连接设备

  • USB-C：插上即可，不需要其他操作。
  • 蓝牙：在 Omarchy 的蓝牙菜单中（或用 bluetoothctl）配对 OpenWalkieTalkie。设备同一时间只保留一个配对：如果它曾与 Mac 配对，请先在 Mac 上移除。

服务会在几秒内自动连接。检查一下：

deckd status

link: 一行应显示 Connected, session Live。

5. 把会话放到设备上

为你使用的助手安装钩子。每次安装都会先备份助手的设置文件，并在其中追加内容，而不是替换它：

python3 omarchy/omarchy_hook.py install claude
python3 omarchy/omarchy_hook.py install codex
python3 omarchy/omarchy_hook.py install kimi

已经打开的会话不会加载新的钩子：重新启动它们，它们就会出现在“助手”页面上。

6. 语音

在选中的会话上按住 PTT，说话，然后松开。文字会输入到该会话的终端中，并接着按下 Enter。

  • 如果使用 Superwhisper（Omarchy 的口述工具，如果你在用），不需要任何设置。它按自己的模式、语言和词汇识别每次按键，在 Cloud 模式下不到一秒。用 superwhisper status 确认它已就绪。
  • 如果不使用，下载一次本地 Whisper 模型（约 465 MB）： 
    printf '[voice.stt]\nengine = "whisper"\nmodel = "small"\nlanguage = "auto"\n' >> ~/.local/share/openwalkietalkie/config.toml
deckd stt install --model small
    Whisper 在笔记本的 CPU 上运行，所以每次按键需要几秒或更久，取决于处理器。

语音只能送达在终端窗口中运行的会话。托管在其他应用内的会话没有可输入的终端，设备会显示该指令未送达。

7. 可选：“快捷键”页面的快捷方式

带有按键组合的“快捷键”按键会在笔记本上输入它。要让按键既能触发聚焦应用的快捷键，也能触发 Omarchy 自己的快捷键（Super+…），桥接需要充当键盘，这需要 /dev/uinput：

sudo install -m 644 omarchy/71-openwalkietalkie-uinput.rules /etc/udev/rules.d/
echo uinput | sudo tee /etc/modules-load.d/openwalkietalkie-uinput.conf
sudo udevadm control --reload && sudo modprobe uinput
systemctl --user restart omarchy-deck

之后，你运行的任何程序都可以创建输入设备，和 ydotool 一样。不做这一步，“快捷键”按键仍能送达聚焦的应用，但无法触发 Omarchy 的快捷键。

8. 可选：Claude 用量条

“用量”页面可以显示你的 Claude 速率限制窗口，每五分钟用你的 Claude Code 登录读取一次：

deckd config set 'usage.providers=["codex","claude"]'

检查安装

deckd care checks
python3 omarchy/omarchy_hook.py status
journalctl --user -u deckd -u omarchy-deck -f

也可以从应用启动器打开 OpenWalkieTalkie：它的“设备”页面显示连接状态，“服务”页面可以启动和停止服务（deckd systemd 单元），并设置登录时打开应用。服务的所有文件都在 ~/.local/share/openwalkietalkie。

更新

cd openwalkietalkie/host
git pull
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

再次运行 install.sh 会用新代码重启两个服务；退出并重新打开应用即可运行新版本。要更新设备的固件，用 USB-C 连接设备，运行 deckd firmware check，然后运行 deckd firmware install，或者使用应用的“服务”页面。设备会在安装前要求你按 ENTER。这和 Mac 使用的是同一条 USB 路径，但还没有在 Omarchy 上试过。

Omarchy 上暂时没有的功能

  • 在设备上回应权限请求：它们仍留在终端里。
  • Codex 的用量条，以及 Omarchy 会话在阅读视图中的历史和工具行。
  • 托盘图标和应用自动更新：应用是从源代码构建的，请按上面的方法更新。

卸载

python3 omarchy/omarchy_hook.py uninstall all
systemctl --user disable --now deckd omarchy-deck
rm -f ~/.config/systemd/user/deckd.service ~/.config/systemd/user/omarchy-deck.service ~/.local/bin/deckd ~/.local/bin/openwalkietalkie-app
rm -f ~/.local/share/applications/openwalkietalkie.desktop ~/.local/share/icons/hicolor/512x512/apps/openwalkietalkie.png ~/.config/autostart/openwalkietalkie.desktop
rm -rf ~/.local/share/openwalkietalkie
sudo rm -f /etc/udev/rules.d/70-openwalkietalkie.rules /etc/udev/rules.d/71-openwalkietalkie-uinput.rules /etc/modules-load.d/openwalkietalkie-uinput.conf

卸载钩子只会移除它在各个助手设置中添加的内容。

遇到问题？请提交 Issue，附上 deckd care checks 的输出和 journalctl --user -u deckd -u omarchy-deck 的最后几行。完整的参考是 Omarchy 桥接的 README。
