正在使用对讲机？

查看图文使用说明书，了解连接设置、按键操作和故障排查；也可以打印一份放在桌边。

先运行一个示例

下载 Python 接入示例。保持 OpenWalkieTalkie 运行，用 Python 3.10+ 执行示例。它使用预设回复，无需安装额外依赖、配置模型 API 密钥或登录 Conol。

查阅接口规范

完整 JSON-RPC API 参考文档（Markdown）根据守护进程的请求结构和方法权限生成。源码仓库中还提供示例和集成测试。
