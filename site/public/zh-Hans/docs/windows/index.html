OpenWalkieTalkie Windows 版

适用于 Windows 10 和 11 的 x64 版本应用和服务

Windows 预览版运行与 Mac 相同的配套软件和服务。对讲机通过 USB-C 或蓝牙连接，可显示 Claude Code 和 Codex 会话、处理授权请求、接收 PTT 语音输入并朗读回复；软件也能更新设备固件。由于下文列出的部分 Mac 功能尚未移植，因此目前是预览版。软件没有代码签名，Windows 会在首次运行时提示。

下载

下载 Windows x64 预览版 ZIP。这个独立的 Windows 预览版包含语音、Claude Code、Codex CLI 和 Grok Bot。它的发布说明列出了源代码版本和 SHA-256 校验和。从 0.14.0 起，每个正式发布也都包含名为 OpenWalkieTalkie-<version>-windows-x86_64.zip 的 Windows 版本。要校验下载的文件，在“下载”文件夹中打开 PowerShell 运行：

Get-FileHash .\OpenWalkieTalkie-*-windows-x86_64.zip -Algorithm SHA256

安装

  1. 解压到你存放程序的地方，例如 %LOCALAPPDATA%\Programs\OpenWalkieTalkie。保持 bin 文件夹原样：应用只有从名为 bin 的文件夹运行时才会安装固件，并会启动旁边的 deckd.exe。
  2. 打开 bin\OpenWalkieTalkie.exe。因为程序没有签名，Windows SmartScreen 会显示Windows 已保护你的电脑。选择更多信息，然后选择仍要运行。Windows 会为这一份副本记住你的选择。
  3. 按首次运行的步骤操作。这些步骤会在后台无窗口地启动 deckd.exe（与设备通信的服务），并设为每次登录时启动（设置 › 应用 › 启动中会列出它）。服务 › 登录时启动对应用本身做同样的设置。关闭窗口后应用仍留在通知区域；在它的图标菜单中退出。
  4. 用 USB-C 连接设备，或在设置 › 蓝牙和其他设备中配对。服务连接上设备后，应用的“设备”页面就会显示它。

语音

对讲机上的 PTT 录音由电脑本地的 Whisper 识别。先在软件的 Voice 页面下载模型；Windows 版没有可用的内置识别器，模型尚未安装时，按下 PTT 会提示这一点。回复默认用 Windows 系统语音朗读，也可下载 Kokoro，或配置自己的 OpenAI、ElevenLabs 密钥来使用云端语音。对讲机的麦克风和扬声器均支持有线和蓝牙连接。

如果 Windows 没有“仍要运行”选项

部分新安装的 Windows 11 开启了 Smart App Control，它会阻止未签名程序，且不提供单次放行选项。可在 Windows Security → App & browser control → Smart App Control 查看状态。开启期间无法运行此预览版；许多 Windows 版本在关闭它后，需要重装系统才能重新开启，因此请自行权衡。杀毒软件也可能暂时阻止新下载的未签名文件；上方的校验和可用来确认文件与发布版本一致。

更新对讲机的固件

用 USB-C 连接一台对讲机，打开 Service，点击 Deck firmware 旁的 Check，再依次点击 Review… 和 Install，与 Mac 上的操作相同。保持数据线连接，直到设备恢复运行。Windows 没有更快 USB 接口所需的驱动，因此使用 HID 连接传输，需要几分钟（Rev A 更新到 0.13.0 约五分钟）。如果 Windows 运行在虚拟机中，要确保设备每次重启后都重新直通给虚拟机；更新过程中会重连两次。

连接 Grok Bot

Grok Bot：打开 Integrations → Bots，添加机器人自动化流程的 webhook。Copy Prompt 会生成供机器人使用的 PowerShell 命令，用于向本机发回回复和问题；需在 Grok Bot 的 Computer 设置中允许这些命令。服务将流程密钥保存在 Windows 凭据管理器中；使用独立数据目录运行的服务则保存在 grokbot-keys.toml。

更新应用

打开 Service，点击软件旁的 Check，或从托盘图标菜单选择 Check for Updates…。发现新版本后点击 Update：软件会下载发布页的 ZIP、核对校验和，将新的 OpenWalkieTalkie.exe 和 deckd.exe 放进 bin 文件夹，然后重启。设置仍保存在 %LOCALAPPDATA%\OpenWalkieTalkie。手动更新则从最新发布页下载 ZIP，在托盘图标菜单中退出软件，再用新文件夹替换旧版本。

与 Mac 不同

  • 云端语音密钥保存在 Windows 凭据管理器中；Mac 版则使用钥匙串。
  • 应用没有签名，所以服务按位置信任它：即 deckd.exe 旁边的 OpenWalkieTalkie.exe。Mac 版则检查应用的签名。
  • Windows 尚不支持需要 Apple Silicon 的 MLX 语音，也没有通过共享 Codex 守护进程打开 Codex Desktop 的配套启动器。终端中的 Codex 与 Mac 版一样可以使用。

卸载

运行 bin\deckd.exe uninstall，停止服务并移除登录时启动项，以及 Claude Code 和 Codex 集成。加上 --purge，还会删除 %LOCALAPPDATA%\OpenWalkieTalkie 中的设置、语音模型和已下载固件；logs 文件夹会保留，可自行删除。最后从托盘图标菜单退出软件，删除解压出来的程序文件夹。

遇到问题？请提交 issue，并附上 %LOCALAPPDATA%\OpenWalkieTalkie\logs 中的日志。
