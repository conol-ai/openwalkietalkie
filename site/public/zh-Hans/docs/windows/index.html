Windows 版 OpenWalkieTalkie

适用于 x64 Windows 10 和 11 的应用和服务

Windows 预览版运行的服务和应用与 Mac 版相同：设备通过 USB-C 或蓝牙连接，显示你的 Claude Code 和 Codex 会话，处理它们的批准请求，接收按住说话的口述并朗读回复，应用还能更新设备的固件。之所以是预览版，是因为有几项 Mac 功能在 Windows 上还没有（见下文），而且它没有代码签名，所以 Windows 在第一次运行前会发出警告。

下载

下载 Windows x64 预览版 ZIP。这个独立的 Windows 预览版包含语音、Claude Code、Codex CLI 和 Grok Bot。它的发布说明列出了源代码版本和 SHA-256 校验和。从 0.14.0 起，每个正式发布也都包含名为 OpenWalkieTalkie-<version>-windows-x86_64.zip 的 Windows 版本。要校验下载的文件，在“下载”文件夹中打开 PowerShell 运行：

Get-FileHash .\OpenWalkieTalkie-*-windows-x86_64.zip -Algorithm SHA256

安装

  1. 解压到你存放程序的地方，例如 %LOCALAPPDATA%\Programs\OpenWalkieTalkie。保持 bin 文件夹原样：应用只有从名为 bin 的文件夹运行时才会安装固件，并会启动旁边的 deckd.exe。
  2. 打开 bin\OpenWalkieTalkie.exe。因为程序没有签名，Windows SmartScreen 会显示Windows 已保护你的电脑。选择更多信息，然后选择仍要运行。Windows 会为这一份副本记住你的选择。
  3. 按首次运行的步骤操作。这些步骤会在后台无窗口地启动 deckd.exe（与设备通信的服务），并设为每次登录时启动（设置 › 应用 › 启动中会列出它）。服务 › 登录时启动对应用本身做同样的设置。关闭窗口后应用仍留在通知区域；在它的图标菜单中退出。
  4. 用 USB-C 连接设备，或在设置 › 蓝牙和其他设备中配对。服务连接上设备后，应用的“设备”页面就会显示它。

语音

设备上的按住说话由这台电脑上的 Whisper 识别：在应用的语音页面下载它的模型（Windows 没有自带的识别器，所以在模型下载完成前，按下说话键时会提示这一点）。回复默认由 Windows 自带的语音朗读，你也可以选择 Kokoro（用同样的方式下载），或使用你自己的 OpenAI 或 ElevenLabs 密钥的云端语音。设备的麦克风和扬声器通过数据线和蓝牙都能使用。

如果 Windows 没有提供“仍要运行”

在一些新安装的 Windows 11 上，智能应用控制会拦截未签名的程序，而且无法绕过。你可以在Windows 安全中心 → 应用和浏览器控制 → 智能应用控制中查看它的设置。它开启时预览版无法运行；而在很多 Windows 版本上，一旦关闭就无法再打开，除非重装 Windows，所以请自己判断是否值得。杀毒软件也可能会暂时拦截新的未签名下载；上面的校验和可以确认这就是发布中公布的文件。

更新设备的固件

用 USB-C 连接一台设备，打开服务，在设备固件上点击检查更新，然后点击查看…和安装，和在 Mac 上完全一样。在设备恢复之前不要拔掉数据线。在 Windows 上，传输使用设备的 HID 连接，而不是更快的 USB 接口（Windows 没有它的驱动），所以需要几分钟（在 Rev A 上安装 0.13.0 约五分钟）。如果你在虚拟机中运行 Windows，请确保设备重启后再次被直通给虚拟机：更新过程中它会重新连接两次。

连接 Grok Bot

Grok Bot：打开集成 → 机器人，添加机器人的例行任务 Webhook。“复制提示词”会给机器人一组 PowerShell 命令，用来把回复和提问发回这台电脑；请在 Grok Bot 的 Computer 设置中允许这些命令。服务把例行任务的密钥保存在 Windows 凭据管理器中。使用单独数据目录的服务则改用 grokbot-keys.toml。

更新应用

打开服务，点击应用旁边的检查更新，或者在图标菜单中选择检查更新…。最新发布中有更新的版本时，点击更新：应用会下载该发布的 zip，用发布公布的校验和进行检查，把新的 OpenWalkieTalkie.exe 和 deckd.exe 放进你的 bin 文件夹，然后重新启动。你的设置保存在 %LOCALAPPDATA%\OpenWalkieTalkie。如果想手动更新，从最新发布下载 zip，在图标菜单中退出应用，再用新文件夹替换旧版本的文件夹。

与 Mac 版的不同

  • 云端语音的密钥保存在 Windows 凭据管理器中，Mac 版则保存在钥匙串中。
  • 应用没有签名，所以服务按位置信任它：即 deckd.exe 旁边的 OpenWalkieTalkie.exe。Mac 版则检查应用的签名。
  • Windows 上暂时没有：需要 Apple 芯片的 MLX 语音，以及在服务共享的 Codex 守护进程上打开 Codex Desktop 的启动器。终端中的 Codex 与 Mac 上一样可用。

卸载

运行 bin\deckd.exe uninstall 可以停止服务，并移除登录时启动的条目以及 Claude Code 和 Codex 集成；加上 --purge 还会删除 %LOCALAPPDATA%\OpenWalkieTalkie 中的内容（设置、语音模型、已下载的固件），只保留 logs 文件夹，你可以自己删除它。然后在图标菜单中退出应用，并删除你解压出的文件夹。

遇到问题？请提交 Issue，并附上 %LOCALAPPDATA%\OpenWalkieTalkie\logs 中的日志。
