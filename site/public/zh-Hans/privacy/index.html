OPENWALKIETALKIE

隐私政策

更新于 2026年10月16日

本声明适用于 openwalkietalkie.org 及其设备候补名单，二者由 COHDL 旗下项目 OpenWalkieTalkie 的团队运营。联系我们：privacy@cohdl.ai。

我们收集什么

  • 候补名单：你提交的电子邮件地址、登记日期，以及你同意接收设备开售动态时所显示的声明版本。
  • 连接信息：Cloudflare 会处理请求元数据（包括你的 IP 地址），以提供和保护网站。我们的登记端点会使用你的 IP 进行短时的频率限制。我们不会把 IP、你的浏览器信息或来源 URL 存入候补名单数据库。
  • 浏览器偏好：你选择的日间/夜间主题，以及你对隐私声明的确认，都保存在你的浏览器中。参见 Cookie 说明。

我们为何使用

在你同意的前提下，我们使用你的邮箱告诉你设备何时开售，并发送相关的开售动态。加入名单不构成订单、预订或付款，也不保证交付日期。我们不会把你加入 Cohdl 软件候补名单或无关的邮件列表。

连接元数据用于提供网站、防止垃圾信息和诊断故障。我们的应用日志不包含登记表单的内容。本网站没有广告或分析脚本。

谁处理这些数据

运营 OpenWalkieTalkie 的团队可以访问该名单，以管理登记并发送你所要求的动态。Cloudflare 托管本网站，并将名单存储在其 D1 数据库中；处理可能在 Cloudflare 开展业务的国家进行。参见 Cloudflare 的隐私政策。我们不会出售你的候补名单数据。

指向 GitHub、Discord 和其他网站的链接会把你带到各自有隐私政策的服务。

我们保留多久

候补名单条目会在两年后自动删除。你可以要求提前删除。已删除的数据可能仍会留在服务商的备份中，直到其正常保留周期结束。

你的选择与请求

如需退出名单、更正邮箱，或索取、删除你的登记信息副本，请用你登记时使用的地址发邮件至 privacy@cohdl.ai。撤回同意后，你将不再收到之后的开售通知邮件。在披露或更改数据之前，我们可能需要核实请求。

根据你所在的地区，你可能还享有其他权利：限制或反对处理、获取可携带的副本，或向当地数据保护机构投诉。

设备和 Mac 应用

本声明说明的是网站和候补名单。加入名单不会把你与助手的对话、语音录音或已连接设备中的信息发送给我们。浏览器演示使用预设内容，不会录制你的麦克风。

变更

网站的数据处理方式发生变化时，我们会更新此页面。上方的日期标识了此版本。
