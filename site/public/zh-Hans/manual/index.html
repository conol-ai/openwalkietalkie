开始

准备好你的 Mac、设备和一根 USB-C 数据线。

01

打开应用。

下载适用于 Apple 芯片或 Intel 的 OpenWalkieTalkie（macOS 13+）。把它拖进“应用程序”并启动。按照第 2 页启动配套服务。

02

连接设备。

接上 USB-C 数据线，如有提示，允许该配件。如需无线使用，在蓝牙中配对 OpenWalkieTalkie。第 2 页介绍电源、配对和权限。

03

接入一个助手。

按照下面 Codex 或 Claude Code 的步骤操作，然后完成你的第一个任务。保持配套服务运行。

就绪检查

你的会话出现，且没有 离线 标记。转动 SCROLL 选中它，然后按 ENTER。在第 5 页发送第一条消息之前，先检查“语音 → 测试语音”。

设备 + 配套应用02 — 首次连接

开机。
连接。

准备好设备、一根 USB-C 数据线和一台 Mac。安装 OpenWalkieTalkie，并登录你打算使用的编程助手。

设备按键、显示与语音
↔
MAC 应用 + 服务连接与送达
↔
你的助手Codex / Claude Code

  1. 安装、打开并开机。

    打开 Mac 下载，把 OpenWalkieTalkie 拖进“应用程序”并启动。用 USB-C 数据线连接设备。按住 PTT 2 秒开机，然后松开。如果 macOS 询问，允许该配件。如果屏幕已锁定，把滚轮逆时针转四格。

  2. 完成首次设置。

    依次完成连接 → 将添加的内容 → 语音 → 集成。查看后台服务和可选的 Claude 插件，然后选择添加这些项目。选择你的语音识别引擎，用继续进入下一步。服务必须保持运行，设备才能工作。

    已经设置过？→ 打开“设备”检查连接；如果没有连接，使用“服务 → 检查安装状态”。

  3. 不用数据线连接。

    如需无线使用，在 macOS 的系统设置 → 蓝牙中配对 OpenWalkieTalkie。在隐私与安全性 → 蓝牙中，允许配套应用访问。回到“设备”，检查它的连接状态。

    检查 → 设备已连接，状态可用，实时页面不再显示离线。

  4. 测试麦克风和扬声器。

    打开语音。选择“语音识别”和“语音回复”，设置语音识别语言，并处理所有权限提示。点击测试语音，然后在设备上按住 PTT，说“hello”，再松开。检查识别出的文字。点击朗读示例检查播放。然后按照 Codex 或 Claude Code 操作。

设备语音

必须使用设备的麦克风。0.15.0 版不会回退到 Mac 的麦克风。蓝牙语音使用应用自己的 BLE 连接；不要在 macOS 的“声音”中把设备当作麦克风查找。应用的五个页面是“设备”、“页面与按键”、“集成”、“语音”和“服务”。

连接你的编程助手03 — CODEX

把 CODEX
带到设备上。

根据你使用 Codex 的方式选择 Desktop 或 CLI。检查连接之前，配套服务必须已在运行。

如果你使用 CODEX DESKTOP

  1. 安装 Desktop 集成。

    先按照官方 Desktop 设置说明安装并登录。在 OpenWalkieTalkie 中，打开集成 → Codex Desktop → 设置。阅读拟进行的更改并确认。如果这一行已经是“已安装”，直接继续；只有在设置需要修复时才使用“修复”。

  2. 通过配套启动器重新打开。

    完成正在进行的工作，退出 Codex Desktop / ChatGPT。在“访达”中选择前往 → 前往文件夹，输入 ~/Applications，然后打开 Codex with OpenWalkieTalkie.app。以后为了使用设备而重新打开 Desktop 时，都用这个启动器。

  3. 打开一个本地对话。

    在 Codex 中打开一个本地项目，开始或继续一个对话。在 OpenWalkieTalkie 中打开集成，检查 Codex 一行的数量和状态。在设备上，到助手中找到这个对话，然后按 ENTER。

    检查 → 对话出现在设备上，集成显示有活动。配套应用只显示数量，不显示聊天内容。云端和 SSH 会话不在这个集成的范围内。

如果你使用 CODEX CLI

  1. 按照官方 Codex CLI 设置说明安装并登录。使用 CLI 0.161+ 支持的共享守护进程模式；如需设备回复，不要使用 --no-daemon。
  2. 在集成中打开 Codex CLI，并确认集成没有被暂停。这个版本通过 Codex 本身连接；没有单独安装 CLI 钩子的步骤。
  3. 在你的项目文件夹中运行 codex 并开始一个对话。检查集成的活动，并在设备的“助手”列表中找到这个会话。

如果这一行显示“Codex is not running”，先打开一个本地会话。如果仍然无法连接，使用“服务 → 检查安装状态”。

连接你的编程助手04 — CLAUDE CODE

CLAUDE CODE。
一个实时会话。

使用“集成”中的 Claude Code 一行。Claude Desktop 是另一个产品，不能代替这些终端步骤。

集成设置 Claude Code 插件
→
项目终端用 Channels 启动
→
设备上的助手选中就绪的会话

  1. 准备 Claude Code。

    按照官方 Claude Code 设置说明安装并登录。在项目终端中运行 claude --version，确认它可用。

  2. 安装 OpenWalkieTalkie 插件。

    打开集成 → Claude Code → 设置。查看拟进行的更改并确认。如果服务找不到 claude，“设置”会多要求一步：点击复制命令，在终端中运行该命令。如果应用报告设置有问题，使用修复并查看建议的修复。安装后开始一个新的 Claude 会话；已有的会话可以用 /reload-plugins 重新加载插件。

    检查 → Claude Code 一行显示“已连接”。开始一个会话，确认它的活动和数量。

  3. 启动支持语音的会话。

    在集成中启用 Claude Channels。点击如何连接… → 复制命令。把它粘贴到在项目文件夹中打开的终端里运行。这个版本的应用中，命令是：

    claude --dangerously-load-development-channels plugin:openwalkietalkie@openwalkietalkie

    要继续已有的对话，先退出那个会话，再在末尾加上 --resume 和它的会话 ID。如果已安装的应用显示的命令有变化，请以应用为准。

  4. 完成 Claude 的连接提示。

    查看 Claude 的本地开发确认。出现提示时，允许 OpenWalkieTalkie MCP 服务器及其 acknowledge 连接检查。回到配套应用的集成页面；它的连接状态会自动刷新。

    检查 → Claude Channels 一行显示“已连接”，你的 Claude 会话出现在设备上。“未连接会话”表示启动或确认还没有完成。

  5. 在设备上选中这个会话。

    进入助手。用 LEFT / RIGHT 找到项目，转动 SCROLL 高亮 Claude 会话，然后按 ENTER。按照下一页的步骤说话和回复。

如果卡住了

在 Claude 中打开 /mcp，检查 OpenWalkieTalkie 服务器。让 Claude 运行 check_connection，然后重新检查 Claude Channels 一行。Channels 是研究预览功能，需要为每个会话加上开发标志；组织策略依然适用。不带该标志重新启动即可关闭它。在连接之前，备用收件箱可能会把消息标记为来自另一个会话。

从头到尾跟完一个任务05 — 上手

选中。说话。
看结果。

先完成一个助手的设置。让它的对话在 Mac 上保持打开，这样你就能准确看到设备把消息发到了哪里。下面的屏幕图片只是示例，不是你的实时会话。

1. 选对对话。

在设备上：按 CANCEL 从对话返回“助手”。LEFT / RIGHT 切换项目页，SCROLL 移动高亮。选中你的项目和助手，然后按 ENTER 打开。

检查 → 对话标题与 Mac 上打开的一致。触摸操作：点按一行选中，再点按一次打开。

2. 按住 PTT，说话，然后松开。

在设备上：按住左侧的 PTT 按键。确认助手名称和“正在聆听”指示。说：“总结一下这个项目，告诉我下一步该做什么。”松开 PTT 发送。要放弃这段录音，在 PTT 状态下按 CANCEL。

在 MAC 上 → 你说的请求会送达那个会话。事先用“语音 → 测试语音”检查识别；只看到聆听界面并不能证明已送达。

3. 阅读回复。

在设备上：等助手完成工作并回复。SCROLL 浏览对话。按住 SHIFT 再按 ENTER 回到最新消息。LEFT / RIGHT 切换到上一个 / 下一个助手；CANCEL 回到列表。

在 MAC 上 → 助手在它平常的项目对话中工作。设备显示关联的记录和状态；它自己并不运行编程助手。

4. 助手提问时作答。

在设备上：弹出提问通知时，点按它，或在触碰其他东西之前按 ENTER。在有待处理卡片的对话上按 ENTER 也会打开它。阅读问题，转动 SCROLL 选择，然后按 ENTER 提交。CANCEL 会把卡片稍后提醒；它不会选择“否”。从顶部向下滑动可以再次找到它。

在 MAC 上 → 回答会解决对应的提问。如果出现“未送达”，检查会话并在那里作答。确认之前请阅读实际的选项；图中的提问只是示例。

试试追问

在同一个对话上再次按住 PTT，提一个后续问题。在 Codex 中，空闲时这条消息会开始新一轮，运行中则会引导当前这一轮。在 Claude Code 中，它通过 Channels 或备用收件箱送达已连接的会话。配套应用的窗口不显示对话文字。

学会这些控件06 — 日常使用

几个按键。
一整张桌面。

SCROLL

转动可移动高亮；在对话中，转动可阅读更早的消息。按住 SHIFT 再按 ENTER，可重新跟随最新回复。

PTT

按住为选中的助手录音；松开发送。录音时按 CANCEL 可放弃。在“游戏”中，PTT 控制游戏。

SHIFT + ↕

按住 SHIFT 并转动 SCROLL 切换页面。选择某一行之前先松开 SHIFT。连按两次 SHIFT 打开页面管理。

CANCEL

按一次返回；在页面的顶层时，回到“助手”。在提问卡片上，它是稍后提醒，而不是拒绝。有些布局把这个键标为 ESC。

ENTER

打开高亮的助手或待处理的卡片；确认选中的回答。在对话中没有待处理卡片时，切换“聊天 / 工作流”。

LEFT / RIGHT

在“助手”中切换项目页。在对话中切换助手。在提问卡片上，在待处理的卡片之间移动。

先在“页面与按键”中添加“快捷键”页面，然后按住 SHIFT 并转到它。使用分配的快捷键之前，先让目标 Mac 应用获得焦点。在第 7 页的 Mac 应用中设置按键；设备上的示例见第 8 页。

页面 04

用量

按住 SHIFT 并转到“用量”。按 ENTER 请求刷新；SCROLL 查看其余内容。如果缺少数值，在 Mac 应用中打开“页面与按键 → 用量”，启用服务商的数据来源。Claude 用量需要主动开启。

页面 05

系统

按住 SHIFT 并转到“系统”，查看主机状态。如果显示灰色或离线，按照第 2 页检查连接。CANCEL 在这里没有作用；按住 SHIFT 并转动即可离开。

页面 06

游戏

按你的方式排列

连按两次 SHIFT 打开页面管理。SCROLL 选择一个可移动的页面；ENTER 拿起它，SCROLL 移动，ENTER 放下。CANCEL 撤销拿起。连按两次 SHIFT 退出。“助手”和“设置”固定不动；页面管理最多支持八个页面，其中最多三个“快捷键”。

在 MAC 上设置 · 在设备上使用07 — 语音与快捷键设置

你的声音。
你的快捷键。

保持服务运行、设备已连接。这些英文截图来自 0.15.0 版应用；你选择的引擎和页面列表可能不同。

设置语音，然后测试

  1. 选择识别方式。

    打开语音 → 语音识别。选择在这台 Mac 上使用 Apple，或者先下载 Whisper 模型再使用。为你要说的语言设置语音识别语言。使用 Apple 识别时，点击语音识别 → 请求授权…，并在 macOS 的提示中允许。

  2. 检查一次真实录音。

    点击测试语音。在已连接的设备上按住 PTT，说“hello”，然后松开。向助手发送请求之前，先检查识别出的文字。如果是空白，检查模型下载、权限和设备连接。

  3. 选择语音回复。

    在语音回复下选择 Apple，或先下载 Kokoro。云端语音需要先设置它的服务提供商。点击朗读示例；在设备 → 扬声器中调整音量。用播放提示音检查通知声音。

在 MAC 上做一个快捷键

  1. 添加并选中“快捷键”。

    打开页面与按键 → 添加页面 → 快捷键。在页面列表中选中它的方块，然后在“快捷键”页面的按键下选中一个空位。

  2. 为按键命名并分配。

    在标签中输入截图并按 Return。选择一个实体按键，或保持仅触摸。把按键设为 4，并在修饰键中启用 ⇧ 和 ⌘。更改会自动生效；Mac 上的编辑器没有“保存”按钮。

  3. 在设备上试一试。

    使用辅助功能 → 检查…，如果需要授权，按照打开设置操作。让 Mac 桌面获得焦点。在设备上，按住 SHIFT 并转到“快捷键”；点按“截图”或按下它分配的按键。截图光标出现。按 Escape 取消。

保持同步

在“页面与按键”中，选中一个可移动的页面，用“向左移动 / 向右移动”调整顺序。在设备上，SHIFT + SCROLL 按这个顺序切换。“助手”和“设置”固定不动。在 Mac 和设备上使用同一个页面名称，以确认你的更改已经同步。

你的第一条语音消息

  1. 在“助手”页面上选中目标助手。
  2. 按住 PTT。确认“正在聆听”界面显示的是正确的会话，然后说话。
  3. 松开 PTT 结束。等待识别和送达；在设备上阅读回复。

语音需要已连接的主机和已设置好的语音识别。语音回复还取决于主机的语音设置。

你的第一个快捷键

  1. 打开“快捷键”。点按“+ 分配”，或按 SHIFT + CANCEL 并选择一个按键。
  2. 按住 PTT，说“截图”作为标签。选择“修饰键”→ ENTER，转动 SCROLL 到 ⇧⌘，然后按 ENTER。选择“按键”→ ENTER，选择 4，然后按 ENTER。选择“保存”→ ENTER。这样就分配了 cmd + shift + 4。
  3. 让 Mac 桌面获得焦点，点按“截图”。如果 macOS 请求辅助功能权限，在“隐私与安全性 → 辅助功能”中启用它提到的应用，然后再试一次。截图光标出现；按 Escape 取消。

快捷键会发给当前获得焦点的应用。

没有反应时

设备显示“离线”
在 OpenWalkieTalkie 中打开服务 → 检查安装状态。检查 USB 数据线或蓝牙连接。重新连接设备；如有需要，在 Mac 应用中使用“服务 → 重新启动”。演示数据不是实时连接。
没有助手会话
Codex 请按照第 3 页，Claude Code 请按照第 4 页。“已安装”只说明集成文件已就位；还必须有一个打开并已连接的会话。Desktop 请使用配套启动器。
没有语音输入
检查选中的会话、主机连接和语音识别引擎。使用 BLE 时，允许蓝牙访问。不会回退到 Mac 的麦克风；使用“语音 → 测试语音”，检查选中的引擎和权限。BLE 设备不是 macOS“声音”中的输入设备。
快捷键没有反应
检查按键是否有绑定，以及主机是否有辅助功能权限。选中目标桌面应用，然后再试一次快捷键。
屏幕已锁定
按任意键、转动滚轮或触摸屏幕即可唤醒。把滚轮逆时针转四格解锁。这几格转动不会操作下面的界面。
