OpenWalkieTalkie v0.2.1：我们的对讲机，无处不在

2026年10月15日应用和固件更新

我们网站上的黄色像素对讲机，现在成为 OpenWalkieTalkie 在 Mac 应用和手持设备上的标识。0.2.1 版在你打开、连接和更新设备的各个地方使用同一个标志。

在设备上

启动画面把对讲机和网站上奶油色与金色叠排的标题放在一起。下方是一个小小的 COHDL 标志和“A COHDL PROJECT”字样。设置 → 关于 也使用同样的标识，并显示固件版本和主板信息。

在你的 Mac 上

应用有了新的程序坞和访达图标、菜单栏中的单色对讲机，侧边栏、欢迎界面和固件更新程序中也使用了一致的品牌标识。当有助手需要你处理时，菜单栏的状态标记仍会显示。服务 → 关于 中包含版本号和项目署名。

获取 v0.2.1

在 Mac 应用中使用检查更新，或下载经过签名和公证的安装包，支持 Apple Silicon 或 Intel。需要 macOS 13 或更高版本。

通过 USB 连接设备，然后打开服务 → 更新，安装对应的 Rev A 或 Rev B 固件。
