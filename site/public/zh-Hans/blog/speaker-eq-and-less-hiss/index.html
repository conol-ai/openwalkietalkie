OpenWalkieTalkie v0.7.0：更清晰的语音，减少杂音

2026年10月20日应用和固件更新

版本 0.7.0 专注于对讲机的声音表现。Mac 服务现在在将语音和提示音发往扬声器前，先按固定参数进行均衡处理，而 Rev A 会再次从 RAM 中运行其代码和字体资源，以减少与闪存活动相关的杂音。

音频在送达扬声器前进行均衡处理

该服务在通过 USB 或 Bluetooth LE 发送之前，会处理混合后的语音和提示音。预设包含一个 250 Hz 的高通滤波器，同时在 1.1 kHz 处削减 5 dB，在 6.3 kHz 处削减 6 dB。它保留 3 dB 的余量，并将样本限制在 −1 dBFS。

滤波器状态在音频块和静音之间保持连续，当输出重新打开时会重置。无效样本不会影响后续音频。

自定义的 16 kHz 设备音频输出会自动启用这套预设，本版没有 EQ 开关。它不增强扬声器的深低频，也不补偿频响中狭窄的凹陷，因此低频较多的内容可能听起来更轻。本地合成的小游戏声音、旧版 CoreAudio 输出和原始测量音不受影响。

Rev A 的闪存活动减少

Rev A 的代码、常量和字体资源在启动时复制到 PSRAM，中断向量位于 SRAM。启动过程会验证这些复制内容，并在三次失败后返回 USB 恢复模式。Rev B 和 LilyGo 仍从 NOR 闪存中执行。

闪存分区和两处蓝牙存储区保持原位，PSRAM 的最后 1 MiB 仍保留给诊断功能。

我们听到的和验证的内容

在 USB 连接的 Rev A 板上测试了 EQ 和 RAM 执行变更。语音播放完成时未丢失主机音频帧，操作员报告杂音显著减少，使用相同 EQ 实现的注明了是否开启均衡的低频对比试听中，启用 EQ 的版本更受青睐。

这些是听觉测试结果，而非新的声学校准测量。Rev B 硬件和仅蓝牙连接的听觉测试未在本次测试中进行。自动化检查覆盖了特定板级的执行布局、启动复制边界、向量位置、受保护的闪存存储，以及 EQ 到编码设备流的传递。

更新双端

安装适用于 Apple Silicon 或 Intel 的已签名并通过公证的 Mac 应用程序，或使用 Check for Updates。需要 macOS 13 或更高版本。确认应用程序和服务均报告 0.7.0，连接一个对讲机到 USB-C，然后使用 Service → Updates → Check firmware。

已使用恢复协议 2 的设备将接收常规应用更新。使用旧版引导程序的设备需要现有引导迁移流程：按照应用的电源和 USB 操作说明进行，并在继续前接受其警告。使用应用更新器更新现有设备；完整芯片的出厂镜像将覆盖设置和配对数据。
