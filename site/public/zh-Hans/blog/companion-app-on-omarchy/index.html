OpenWalkieTalkie v0.15.0：配套应用来到 Omarchy

2026年11月17日Omarchy 应用、听写和服务

0.15.0 版把配套应用带到了 Omarchy，并让设备在那里成为听写用的麦克风。设备固件保持 0.14.0 不变。

Omarchy 上的配套应用

Mac 和 Windows 上的应用现在也能在 Omarchy（Hyprland）上运行，在应用启动器中名为 OpenWalkieTalkie，同样有五个页面：设备、页面与按键、集成、语音和服务。它会自己找到服务。服务通过服务的 systemd 用户单元启动和停止服务，登录时打开是一个 XDG 自动启动项。没有托盘图标，那是桌面状态栏的事；也没有应用内更新，因为应用是从源代码构建的。

页面与按键也能适应比应用设计宽度更窄的平铺窗口：页面列表会换到第二行，按键编辑区会移到按键网格下方。Omarchy 指南介绍了如何构建和安装它。

在 Omarchy 页面上听写

在 Omarchy 页面上，PTT 的用法和 Superwhisper 自己的按住说话一样。按住说话，松开，你的话就会输入到当前拥有键盘焦点的窗口的光标处，不会按 Enter。按住时按 CANCEL 会丢弃这段录音。装有 Superwhisper 时由它识别，使用它自己的模式、语言和词汇表；否则由本地 Whisper 模型识别。为此，桥接程序会在列表中添加一个 Dictate 条目，在“助手”页面上选中它，也能以同样的方式听写。

滚轮跟着行走

在 Omarchy 页面上，滚轮现在按页面列出的顺序在窗口行之间移动，和它在设备其他列表中的移动方式一样，并在第一行和最后一行停住。以前它按 Hyprland 自己的窗口顺序移动，所以转一下可能会跳过下面那一行。

Linux 上只用一个文件夹

Linux 服务现在把所有内容放在一个文件夹 ~/.local/share/openwalkietalkie 中，就像在 Mac 上用一个文件夹存放一样。Omarchy 安装本来就在那里运行，deckd 命令也不再需要 DECKD_DATA_DIR=… 前缀。如果你曾在 Linux 上按旧布局手动运行 deckd，请把它的文件移到该文件夹，或设置 DECKD_DATA_DIR。

更新

在 Mac 上，选择检查更新…，或安装已签名并经过公证的 0.15.0 应用，支持 Apple Silicon 和 Intel（macOS 13 或更高版本）。在 Windows 上，从发布页面下载 ZIP 包。在 Omarchy 上，拉取代码，构建服务和应用，再用这两者运行 install.sh，具体见 Omarchy 指南。本次发布不需要更新设备固件。
