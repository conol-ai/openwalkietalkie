OpenWalkieTalkie v0.12.0：Conol 语音接入与番茄钟

2026年11月5日Mac 应用程序、服务和固件

通过对讲机向 Conol 说话，应该像直接在 Conol 里输入文字一样，把意思准确传过去。0.12.0 将这类录音交给 Conol 自己的语音模型识别；说话时显示录音时间线，工作时同步 Conol 的当前步骤，同时新增带番茄钟的 Timer 界面。

发给 Conol 的语音，由 Conol 来识别

选中 Conol 对话或 + New chat 后按住 PTT，Mac 服务会录下这段语音并交给 Conol 桌面应用。Conol 使用与输入框麦克风相同的云端语音模型转写。松手后，对讲机显示和最终发送的都是这份识别结果；用语音回答 Conol 的问题时也是如此。

按住 PTT 时，Mac 本地识别器也会继续工作。如果 Conol 无法响应、识别失败或超过 20 秒仍未返回，就改用 Mac 的转写结果，避免丢掉这次语音。发给其他助手的录音，以及给对讲机起名字时的录音，仍在 Mac 上处理。只有发给 Conol 对话的录音会交给你已登录的 Conol 应用处理；设置 [voice.stt] companion = false 可让所有录音都留在本地识别。此功能需要更新后的 Conol 桌面版和网页端配合；旧版 Conol 的行为保持不变。

对话时的实时时间线

Mac 的实时识别文字不一定等于最终发给 Conol 的内容，因此这类录音不再显示本地实时文字。屏幕改为显示 RECORDING、醒目的录音时长和时间线：红色进度指示从左向右移动，对讲机麦克风采集的波形随之填入；录音较长时，时间线会滚动。松手后先显示 TRANSCRIBING，再显示 Conol 返回的转写结果。

查看 Conol 当前的操作状态

当前运行的 Conol 聊天现在在对讲机上显示其当前的公开步骤，例如 "执行命令" 并附带简要预览，既在助手列表中也出现在对话界面中。显示内容会原地更新，步骤结束后自动清除。完整的工具输入和结果仍保留在 Conol 中。

计时器和番茄工作法

在页面管理器的 + 添加菜单里选择 Timer，即可使用带分段计时的秒表、带预设的倒计时和番茄钟。番茄钟每轮专注 25 分钟、休息 5 分钟，完成四轮专注后休息 15 分钟；每个阶段结束后，都等待你按 Next / Enter 再继续。计时在对讲机本地运行，切到其他页面或屏幕休眠都不会中断；结束时会唤醒屏幕并弹出通知。

给原生应用接入开发者

拥有自己语音识别器的原生接入应用，可以注册 caps.transcribe: "push"，接收 agent.transcribe 转写请求，通过 agent.transcribe.audio 分页读取 16 kHz WAV 音频，再用 agent.transcribe.result 返回结果。活动状态行使用 agent.reply 中的 message.summary 字段。两种接口都在原生应用接入指南和 API 参考文档中说明。

Update

选择 Check for Updates，或安装已签名并通过公证的 0.12.0 版 Mac 应用，支持 Apple Silicon 和 Intel，需要 macOS 13 或更高版本。录音时间线和 Timer 页面需要 0.12.0 固件。用 USB 连接对讲机，打开 Service → Updates → Check firmware 更新。设置和蓝牙配对会保留。
