OpenWalkieTalkie v0.9.0：更清晰的 USB 语音与重置次数到期提醒

2026年10月22日应用和固件更新

0.9.0 改善了 USB 语音播放，还会提醒你一件容易忘的事：尚未使用的手动额度重置次数快到期了。更新 Mac 软件和对讲机固件，即可获得这两项改进。

听一听语音内容

我们首先进行了 16 kHz 和 48 kHz 的音乐对比测试。听者未察觉到明显差异。英语语音则呈现出不同情况：在启用扬声器均衡器且音量匹配的情况下，48 kHz 版本听起来更清晰，而在 16 kHz 样本中能听见的杂音，在这段 48 kHz 样本中听不到了。

连接的固件支持时，对讲机现在会通过 USB 以 48 kHz 播放扬声器音频。服务自动检测这项能力，保持 EQ 开启；遇到旧固件则回退到 16 kHz。切换连接或松开 PTT 后，也会按双方协商的采样率播放。

这优化了播放路径；它不会产生原本声源中不存在的细节。我们的 Kokoro 测试语音生成了 24 kHz 音频。通过 48 kHz 路径传输可以避免之前降为 16 kHz 的情况，并改变压缩和重建路径。

16 kHz 路径也得到了优化

主机现在会搜索其他 ADPCM 编码路径以减少量化误差，在原始结果更优时会保留原结果。固件在发送 16 kHz 音频到 48 kHz DAC 前，会用带限滤波器替代线性插值。

在同一英文段落中，改进的编码器将平方编码误差降低了约 30%。这是一个数字指标，而非完全消除可听杂音的承诺：改进后的 16 kHz 路径仍需通过听觉确认来验证。

BLE 播放和麦克风采集仍保持在 16 kHz。 USB 对比测试在两种速率下均未出现断续、欠流、队列丢失或序列错误。目前尚未验证 BLE 上的持续 48 kHz 播放，因此本次版本仍将更高速率限定于 USB。

重置次数快到期，记得及时用

Mac 的 Usage 页面和对讲机的用量页面，现在会在每周用量条下方显示琥珀色提示：当尚未使用的手动重置次数将在 72 小时内到期时，就会提醒你。例如：“2 次重置将在 1 天 6 小时后到期。”

这和每周额度自动刷新的倒计时是两回事。提示采用最近的到期时间，只统计同一时间到期的重置次数。用掉或到期后，提示就会清除；切换账号时会清掉上一账号的数据，断开连接时会隐藏。如果服务方不提供这些数据，就不会显示提醒。对讲机不会替你执行额度重置。

更新双端

安装已签名并通过公证的 Mac 应用，按机型选择 Apple Silicon 或 Intel 版，也可以选择 Check for Updates。需要 macOS 13 或更高版本。用 USB-C 连接对讲机，再打开 Service → Updates → Check firmware。应用、服务和固件的版本应均为 0.9.0。

一个正常更新会保留使用恢复协议 2 的设备上的设置和蓝牙配对。较旧版本的恢复程序使用现有的引导迁移流程。针对不同主板的出厂 ZIP 文件仍可供制造使用；其完整芯片镜像会覆盖设置和配对，因此对于现有设备，请使用应用程序更新器。

博客是发布的一部分

发布验证器现在需要博客文章、对应的 Atom 订阅条目、博客索引链接、站点地图条目以及当前 Mac 下载链接才能发布版本。缺少的 0.7.0 和 0.8.0 博客文章也已提供。

开发固件和语音对比测试在 Rev A 上通过 USB 进行，重启更新服务后确认后台服务按正常流程播放音频，采样率为 48 kHz。自动化检查涵盖速率协商、连接变更、音频编码和滤波、重置过期以及账户变更和渲染。Rev B 的音频本场未进行实地测试。
