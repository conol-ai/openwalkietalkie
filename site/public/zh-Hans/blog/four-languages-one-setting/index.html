OpenWalkieTalkie v0.13.0：四种语言，一个设置

2026年11月8日Mac 应用、服务和固件

0.13.0 版为 Mac 应用和设备都带来了 English、简体中文、繁體中文和日本語。在任意一端选择语言；选择在重新启动后仍会保留，两端连接时也会共享。

在手边的那一端选择语言

在 Mac 上，打开服务 → 语言。在设备上，打开设置 → 显示 → 语言，需要在“显示”中向下滚动才能看到。四个选项始终以各自的语言显示名称：English、简体中文、繁體中文和日本語。

界面会立即切换：列表和对话中的控件、安装、设置、权限、通知、锁屏、教程、游戏和计时器。聊天、工具输出、自定义名称、文件路径和实体按键上的标签保持原文。语音识别和语音回复仍使用各自配置的引擎和语言。

两端都会记住

在未连接的设备上选择的语言会保存在设备本地。重新连接时，它会与 Mac 上保存的选择进行协调。保存的语言修订号较高的一方生效；相同时以 Mac 应用为准。恢复旧的页面列表或设置不会覆盖较新的语言选择。你也可以在连接设备之前就选择应用的语言。双向同步需要配套的 0.13.0 版应用和固件。

百分之一秒和有声提醒

秒表现在显示到百分之一秒。倒计时结束时，设备扬声器会发出提示音；番茄钟在专注结束时播放上升的提示音，在休息结束时播放下降的提示音，音量为扬声器设定的音量。

提醒会在 30 秒后停止，或在第一次按键、转动滚轮或触摸屏幕时停止，包括唤醒设备的那一次操作。重新开始或重置计时器，或开始下一个番茄钟阶段，也会让它停止。切到其他页面或屏幕休眠时，计时器仍会继续运行。

更多会话，更少过时的提问

“助手”列表现在是一个轮播：大号的所选会话卡片、相邻会话的预览，以及按项目翻页。在 PSRAM 会话表可用时，Rev A 和 Rev B 最多支持 255 个会话，提问优先。

已在别处处理的 Claude 权限请求不会出现在设备上，已完成或被中断的请求会清除过时的卡片。自动批准后，如果 Codex 自己没有待批准的请求，它会回到运行中状态。Mac 应用还会修复应用被移动或替换后遗留的过时服务注册，服务诊断也能识别由应用注册的 launchd 任务。

固件代码现在在每块主板上都从 NOR 运行。Rev A 不再把代码复制到 PSRAM 中；PSRAM 仍可用于会话数据。

更新

选择检查更新，或安装已签名并经过公证的 0.13.0 版 Mac 应用（Apple Silicon 或 Intel）。需要 macOS 13 或更高版本。如果服务仍显示旧版本，请选择服务 → 重新启动。

通过 USB 连接设备后，打开服务 → 更新 → 检查固件更新，安装固件 0.13.0。常规更新会保留设置和蓝牙配对。出厂固件用于生产，会覆盖它们。
