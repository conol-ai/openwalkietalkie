OpenWalkieTalkie v0.2.0：工作流一目了然

2026年10月13日应用和固件更新

OpenWalkieTalkie v0.2.0 让你更容易跟进在后台持续运行的工作。Mac 应用和手持设备现在会在助手对话旁边显示实时的工作流进度。

跟进工作

打开一个会话并切换到“工作流”，即可查看它的计划和紧凑的工具活动。Claude Dynamic Workflows 还会显示每次运行的名称、进度条、已完成和已启动的 worker 数量、已用时间和 token 数。父对话安静时，后台运行仍会持续更新。

设备会一直显示当前的工作流页面，直到替换内容到达，从而修复了定期刷新时的闪烁。滚动位置保持不变，工具详情仍可展开。

显示你正在使用的账户的用量

Mac 应用有一个专门的“用量”页面；当账户提供 Claude Fable 的每周用量限额时，应用和设备都会显示它。每个用量条都会显示当前账户、用量百分比和重置时间。Claude 和 Codex 的限额会同时显示。

获取 v0.2.0

在 Mac 应用中使用检查更新，或下载经过签名和公证的安装包，支持 Apple Silicon 或 Intel。需要 macOS 13 或更高版本。

设备方面，请通过 USB 连接，然后在应用中打开服务 → 更新。检查固件，核对所选的主板，然后安装 v0.2.0。其中包含 Rev A 和 Rev B 固件映像；首次刷写仍需要兼容的引导程序。
