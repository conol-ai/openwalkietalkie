OpenWalkieTalkie v0.4.0：看得见的恢复进度，更充足的固件空间

2026年10月18日应用和固件更新

OpenWalkieTalkie 0.4.0 版本为对讲机提供了更多空间以支持新功能，也能直接在设备屏幕上看到固件恢复进度。它还增加了中文文本支持，以及更清晰的 Codex 问答内容。

更多闪存空间可供应用程序使用

16 MiB NOR 闪存现在有 15.75 MiB 可用于应用固件代码和资源。闪存分区表、引导程序和两处蓝牙存储区仍保留各自的空间。中文字体放在应用区的高地址存储段，给低地址段的代码腾出更多空间。

修正时钟配置后，固件恢复为直接从 NOR 闪存执行，不再在启动时将整个应用复制到 PSRAM。

恢复界面和更快的 USB 更新

新的引导程序在对讲机屏幕上显示恢复说明、传输进度、完成状态和错误信息。更新后的设备可使用稀疏传输和流水线 USB 批量传输，避免写入填充区域，从而保护蓝牙存储区域。

从旧引导程序升级的第一阶段仍会通过 HID 传输临时更新程序，该阶段耗时几分钟。后续阶段可使用新传输方式，但闪存擦除和写入时间仍会增加总耗时。

从 0.3.0 升级

安装 0.4.0 Mac 应用程序，用 USB-C 数据线连接一台对讲机，然后打开 Service → Updates → Check firmware。升级前请检查板子版本和序列号。

此升级可替换引导程序。保持 USB-C 电源连接，让 Mac 保持唤醒，直到应用报告成功。在引导程序替换过程中断电，可能导致设备无法启动，也无法通过 USB 恢复，甚至需要硬件维修。 应用程序会显示此警告，并在迁移前要求明确确认。

应用程序会安装一个临时更新程序，备份并替换引导程序，读回以验证写入，然后安装最终固件。请使用此引导流程，而不是手动刷写引导程序或恢复文件。更新程序不会重写闪存表，也不会操作蓝牙存储区域。

完成之后，设备的关于页面应显示 0.4.0 · Rev A 或 0.4.0 · Rev B。版本标签现在会自动跟随固件构建版本。两种板型及其验证清单均随应用打包，因此固件更新也可在离线状态下运行。

中文文本和更清晰的 AI 助手对话

内置 Noto Sans CJK 字体，支持简体和繁体中文。Codex 请求澄清的问题和回答，会显示为易读的标题、问题背景和答案正文，不再直接显示底层传输数据。本次更新还包含 0.3.0 之后加入的 Codex Desktop 集成和蓝牙信号强度指示。

已测试的内容

两种板型均能正常编译并通过软件测试。一个早期的 0.3.1 候选版本在 Rev A 上完成了从原始 0.3.0 到新引导程序的完整 GUI 迁移，耗时约五分半钟，使用了相同的恢复源。CI 版本重新构建的引导程序字节不同，该版本在测试中未被刷写。

最终的 0.4.0 图形界面复测在刷写前被本地桌面自动化环节阻断。由于没有可用的出货版 Rev B，其完整迁移流程、屏幕显示，以及配对和设置是否保留，仍待实机检查。这些都是尚未完成的验证。本次没有测试设备音频。

获取 v0.4.0

使用 Check for Updates 或 从官网下载已签名并通过公证的 Mac 应用程序，适用于 Apple Silicon 或 Intel。需要 macOS 13 或更高版本。

GitHub 发布页提供固件、校验和和中文升级指南；DMG 内也附有同一份指南。
