OpenWalkieTalkie for Windows

The app and service for Windows 10 and 11 on x64

The Windows preview runs the same service and app as the Mac: your deck links over USB-C, the app shows it, and the app updates the deck’s firmware. It is a preview because several Mac features are not built for Windows yet (below), and it is not code-signed, so Windows warns before it runs it the first time.

Download

Open the latest release and download OpenWalkieTalkie-<version>-windows-x86_64.zip. Windows builds are published with every release from 0.14.0 on. The release also lists the zip’s SHA-256 checksum; to compare it, run this in PowerShell in your Downloads folder:

Get-FileHash .\OpenWalkieTalkie-*-windows-x86_64.zip -Algorithm SHA256

Install

  1. Unzip it somewhere you keep programs, for example %LOCALAPPDATA%\Programs\OpenWalkieTalkie. Keep the bin folder as it is: the app installs firmware only when it runs from a folder named bin, and it starts the deckd.exe beside it.
  2. Open bin\OpenWalkieTalkie.exe. Windows SmartScreen shows Windows protected your PC, because the program is not signed. Choose More info, then Run anyway. Windows remembers the choice for this copy.
  3. Start the service. In the app, open Service and press Start. It runs deckd.exe, the service that talks to the deck, in the background with no window.
  4. Connect the deck with USB-C. The app’s Deck page shows it once the service has linked.

If Windows does not offer “Run anyway”

Smart App Control, on some new Windows 11 installations, blocks unsigned programs and gives no way past it. You can see its setting in Windows Security → App & browser control → Smart App Control. The preview cannot run while it is on, and on many Windows versions it cannot be turned back on without reinstalling Windows once it is off, so decide whether that is worth it for you. Antivirus software may also hold back a new unsigned download for a while; the checksum above tells you it is the file the release published.

Update the deck’s firmware

With one deck connected by USB-C, open Service, click Check on Deck firmware, then Review… and Install, exactly as on the Mac. Keep the cable connected until the deck is back. On Windows the transfer uses the deck’s HID connection rather than its faster USB interface, which Windows has no driver for, so it takes a few minutes (about five for 0.13.0 on Rev A). If you run Windows in a virtual machine, make sure the deck is passed through again after it restarts: it reconnects twice during an update.

Not in the preview yet

  • Voice: push-to-talk dictation and spoken replies.
  • Starting with Windows: start the service from the app after you sign in.
  • Claude Code and Codex on the deck, and focusing their windows.
  • Automatic app updates: download each new version from the latest release and unzip it over the old one (quit the app and end deckd.exe first).

Uninstall

Quit the app, end deckd.exe in Task Manager, and delete the folder you unzipped. Settings, logs and downloaded firmware live in %LOCALAPPDATA%\OpenWalkieTalkie; delete it too to remove everything.

Something not working? Open an issue with the log from %LOCALAPPDATA%\OpenWalkieTalkie\logs.
