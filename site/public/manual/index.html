PRESS START

Begin with your Mac, the deck and a USB-C data cable.

01

Open the app.

Download OpenWalkieTalkie for Apple Silicon or Intel (macOS 13+). Drag it into Applications and launch it. Follow page 2 to start the companion service.

02

Connect the deck.

Connect a USB-C data cable and allow the accessory if prompted. For wireless use, pair OpenWalkieTalkie in Bluetooth. Page 2 covers power, pairing and permissions.

03

Bring an agent.

Follow the Codex or Claude Code steps below, then work through your first task. Keep the companion service running.

READY CHECK

Your session appears without an offline tag. Turn SCROLL to select it, then press ENTER. Check Voice → Test Voice before sending your first message on page 5.

DEVICE + COMPANION APP02 — FIRST CONNECTION

POWER ON.
GET CONNECTED.

Have your deck, a USB-C data cable and a Mac ready. Install OpenWalkieTalkie and sign in to the coding assistant you plan to use.

THE DECKButtons, display & voice
↔
MAC APP + SERVICEConnection & delivery
↔
YOUR AGENTCodex / Claude Code

  1. Install, open and power on.

    Open the Mac download, drag OpenWalkieTalkie into Applications, and launch it. Connect the deck with a USB-C data cable. Hold PTT for 2 seconds to power on, then release. Allow the accessory if macOS asks. Turn the wheel counterclockwise four ticks if the screen is locked.

  2. Complete the first-run setup.

    Follow Connect → What this adds → Voice → Integrations. Review the background service and optional Claude plugin, then choose Add These. Choose your speech engine and use Continue to move on. The service must stay running for the deck to work.

    ALREADY SET UP? → Open Deck to check the link; use Service → Check my setup if it is missing.

  3. Connect without the cable.

    For wireless use, pair OpenWalkieTalkie in macOS System Settings → Bluetooth. Under Privacy & Security → Bluetooth, allow the companion’s access. Return to Deck and check its link state.

    CHECK → The deck is linked, its status is available, and live faces no longer say offline.

  4. Test the microphone and speaker.

    Open Voice. Choose Recognition and Spoken replies, set Speech language, and resolve any permission prompt. Click Test Voice, then hold PTT on the deck, say “hello” and release. Check the recognized words. Click Speak a Sample to check playback. Then follow Codex or Claude Code.

DEVICE VOICE

The deck’s microphone is required. Version 0.15.0 does not fall back to the Mac microphone. Bluetooth voice uses the app’s own BLE connection; do not look for the deck as a microphone in macOS Sound. In English, the five app pages are Deck, Faces & Keys, Integrations, Voice and Service.

CONNECT YOUR CODING ASSISTANT03 — CODEX

BRING CODEX
TO THE DECK.

Choose Desktop or CLI to match how you use Codex. The companion service must be running before you check the connection.

IF YOU USE CODEX DESKTOP

  1. Install the Desktop integration.

    Follow the official Desktop setup to install and sign in first. In OpenWalkieTalkie, open Integrations → Codex Desktop → Set Up. Read the proposed changes and confirm. If the row is already Installed, continue; use Repair only when setup needs fixing.

  2. Reopen through the companion launcher.

    Finish active work and quit Codex Desktop / ChatGPT. In Finder, choose Go → Go to Folder, enter ~/Applications, and open Codex with OpenWalkieTalkie.app. Use this launcher whenever you reopen Desktop for deck access.

  3. Open a local conversation.

    Open a local project and start or resume a conversation in Codex. In OpenWalkieTalkie, open Integrations and check the Codex row’s count and State. On the hardware, find the conversation on Agents and press ENTER.

    CHECK → The conversation appears on the deck and the integration reports activity. The companion shows counts, not chat content. Cloud and SSH sessions are outside this integration.

IF YOU USE CODEX CLI

  1. Follow the official Codex CLI setup to install and sign in. Use the shared-daemon mode supported by CLI 0.161+; do not use --no-daemon for deck replies.
  2. In Integrations, turn on Codex CLI and make sure integrations are not paused. This version connects through Codex itself; there is no separate CLI hook installation step.
  3. Run codex in your project folder and start a conversation. Check the integration’s activity and find the session on the hardware’s Agents list.

If the row says “Codex is not running”, open a local session first. Use Service → Check my setup if it still cannot connect.

CONNECT YOUR CODING ASSISTANT04 — CLAUDE CODE

CLAUDE CODE.
ONE LIVE SESSION.

Use the Claude Code row in Integrations. Claude Desktop is a separate product and does not replace these terminal steps.

INTEGRATIONSSet up Claude Code plugin
→
PROJECT TERMINALLaunch with Channels
→
AGENTS ON DECKSelect the ready session

  1. Prepare Claude Code.

    Follow the official Claude Code setup to install and sign in. In your project terminal, run claude --version to check that it is available.

  2. Install the OpenWalkieTalkie plugin.

    Open Integrations → Claude Code → Set Up. Review the proposed changes and confirm them. If the service cannot find claude, Set Up asks for one more step: click Copy Command and run the command in a terminal. If the app reports a setup problem, use Repair and review the proposed fix. Start a new Claude session after installation; an existing session can reload the plugin with /reload-plugins.

    CHECK → The Claude Code row reports Connected. Start a session to verify its activity and count.

  3. Launch the voice-enabled session.

    In Integrations, enable Claude Channels. Click How to Connect… → Copy Command. Paste it into a terminal opened in your project folder and run it. The command in this app version is:

    claude --dangerously-load-development-channels plugin:openwalkietalkie@openwalkietalkie

    To continue an existing conversation, exit that session first and append --resume followed by its session ID. Use the command shown by your installed app if it changes.

  4. Complete Claude’s connection prompts.

    Review Claude’s local development confirmation. Allow the OpenWalkieTalkie MCP server and its acknowledge connection check when prompted. Return to the companion’s Integrations page; its connection status refreshes automatically.

    CHECK → The Claude Channels row reports Connected, and your Claude session appears on the deck. “No session connected” means the launch or confirmation is unfinished.

  5. Select that session on the deck.

    Go to Agents. Use LEFT / RIGHT to find the project, turn SCROLL to highlight the Claude session, and press ENTER. Follow the speaking and reply steps on the next page.

IF IT STALLS

In Claude, open /mcp and check the OpenWalkieTalkie server. Ask Claude to run check_connection, then recheck the Claude Channels row. Channels is a research preview with a per-session development flag; organization policy still applies. Restart without the flag to turn it off. Until connected, the fallback inbox may label messages as coming from another session.

FOLLOW ONE TASK FROM START TO FINISH05 — HANDS ON

SELECT. SPEAK.
SEE THE RESULT.

Complete one agent setup first. Keep its conversation open on your Mac so you can see exactly where your deck sends the message. The screen images below are examples, not your live sessions.

1. Pick the right conversation.

ON THE DECK: Press CANCEL to return from a conversation to Agents. LEFT / RIGHT changes project pages; SCROLL moves the highlight. Select your project and agent, then press ENTER to open it.

CHECK → The conversation title matches the one open on your Mac. Touch alternative: tap a row to select, then tap it again to open.

2. Hold PTT, speak, then release.

ON THE DECK: Hold the left-side PTT button. Check the agent name and LISTENING indicator. Say: “Summarize this project and tell me what to do next.” Release PTT to send. To discard the recording, press CANCEL while still in the PTT session.

ON THE MAC → Your spoken request reaches that session. Use Voice → Test Voice to check recognition beforehand; a listening screen alone does not prove delivery.

3. Read the response.

ON THE DECK: Wait for the agent to work and return a reply. SCROLL browses the conversation. Hold SHIFT and press ENTER to return to the latest messages. LEFT / RIGHT switches to the previous / next agent; CANCEL returns to the roster.

ON THE MAC → The assistant works in its normal project conversation. The deck shows the linked history and status; it does not run the coding assistant by itself.

4. Answer when the agent asks.

ON THE DECK: When a question notice pops up, tap it, or press ENTER before touching anything else. ENTER on a conversation with a pending card also opens it. Read the question, turn SCROLL to choose, then press ENTER to submit. CANCEL snoozes the card; it does not choose “No”. Swipe down from the top to find it again.

ON THE MAC → The answer resolves the corresponding question. If “not delivered” appears, check the session and answer there. Read the actual options before confirming; the pictured question is only an example.

TRY A FOLLOW-UP

Hold PTT again on the same conversation and ask a follow-up. In Codex, the message starts a turn when idle or steers a running turn. In Claude Code, it reaches the connected session through Channels or its fallback inbox. The companion window does not display conversation text.

LEARN THE CONTROLS06 — EVERYDAY USE

A FEW KEYS.
A WHOLE DESK.

SCROLL

Turn to move the highlight; in a conversation, turn to read older messages. Hold SHIFT + press ENTER to follow the latest reply again.

PTT

Hold to record for the selected agent; release to send. Press CANCEL during recording to discard. In Arcade, PTT controls the game.

SHIFT + ↕

Hold SHIFT and turn SCROLL to change face. Release SHIFT before selecting a row. Double-tap SHIFT to open the face manager.

CANCEL

Press once to go back; at a face’s top level, return to Agents. On a question card, snooze rather than reject. Some layouts label this key ESC.

ENTER

Open a highlighted agent or pending card; confirm the selected answer. With no card pending in a conversation, switch Chat / Workflow.

LEFT / RIGHT

In Agents, change project pages. In a conversation, change agents. On a question card, move between pending cards.

CHANGE FACE, THEN USE IT

SHIFT + SCROLL →
FACE 01

Agents

Press CANCEL at a face’s top level to go home. Select a session with SCROLL and open it with ENTER. Follow page 5 to send and answer a message.

FACE 02

Omarchy

Hold SHIFT + turn to Omarchy. On a connected Omarchy / Hyprland host, tap a workspace chip or a window row to switch to it. The Mac app alone cannot supply this host. On the supported Omarchy host, PTT dictates at the cursor; release inserts text without Enter.

FACE 03

Macropad

Add Macropad in Faces & Keys first, then hold SHIFT + turn to it. Focus the target Mac app before using an assigned shortcut. Set up keys in the Mac app on page 7; see the on-device example on page 8.

FACE 04

Usage

Hold SHIFT + turn to Usage. Press ENTER to request a refresh; SCROLL reads the rest. If values are missing, open Faces & Keys → Usage in the Mac app and enable the provider source. Claude usage is opt-in.

FACE 05

System

Hold SHIFT + turn to System and read the host status. If it is gray or offline, check the connection on page 2. CANCEL does nothing here; hold SHIFT + turn to leave.

FACE 06

Arcade

Hold SHIFT + turn to Arcade. SCROLL chooses a game and ENTER opens it. Use the game controls on page 8; CANCEL returns to the list. PTT does not record here.

MAKE IT YOURS

Double-tap SHIFT to open the manager. SCROLL selects a movable face; ENTER grabs it, SCROLL moves it, and ENTER drops it. CANCEL reverts a grab. Double-tap SHIFT to exit. Agents and Settings stay pinned; the manager supports eight faces, including three Macropads.

SET UP ON THE MAC · USE ON THE DECK07 — VOICE & MACRO SETUP

YOUR VOICE.
YOUR SHORTCUTS.

Keep the service running and the deck linked. These English screenshots show the 0.15.0 app; your selected engines and face strip may differ.

SET UP SPEECH, THEN TEST IT

  1. Choose recognition.

    Open Voice → Recognition. Choose Apple on this Mac, or download the Whisper model before using it. Set Speech language for what you will speak. For Apple recognition, use Speech Recognition → Ask… and allow the macOS prompt.

  2. Check an actual recording.

    Click Test Voice. Hold PTT on the linked deck, say “hello” and release. Check the recognized text before sending an agent request. If it is blank, check the model download, permission and deck connection.

  3. Choose spoken replies.

    Under Spoken replies, choose Apple, or download Kokoro first. Cloud voice requires its provider setup. Click Speak a Sample; adjust volume on Deck → Speaker. Use Play a Chime to check notification audio.

BUILD ONE MACRO ON YOUR MAC

  1. Add and select Macropad.

    Open Faces & Keys → Add a face → Macropad. Select its tile in the face strip, then select an empty slot under Macropad keys.

  2. Name and assign the key.

    Enter Screenshot in Label and press Return. Choose a Deck button, or leave it touch-only. Set Key to 4 and enable ⇧ and ⌘ in Modifiers. Changes apply automatically; the Mac editor has no Save button.

  3. Try it from the deck.

    Use Accessibility → Check… and follow Open Settings if access is needed. Focus the Mac desktop. On the deck, hold SHIFT + turn to Macropad; tap Screenshot or press its assigned button. The screenshot cursor appears. Press Escape to cancel.

KEEP IT IN SYNC

In Faces & Keys, select a movable face and use Move Left / Move Right to reorder it. On the deck, SHIFT + SCROLL follows that order. Agents and Settings stay pinned. Use the same face name on the Mac and on the deck to check that your changes arrived.

KEEP THIS PAGE NEARBY08 — QUICK REFERENCE

HOLD. TALK.
KEEP GOING.

YOUR FIRST VOICE MESSAGE

  1. Select the intended agent on the Agents face.
  2. Hold PTT. Check that the LISTENING view shows the right session, then speak.
  3. Release PTT to finish. Wait for recognition and delivery; read the response on the deck.

Voice needs a connected host and configured speech recognition. Spoken replies also depend on the host’s voice settings.

YOUR FIRST MACRO

  1. Open Macropad. Tap “+ assign”, or press SHIFT + CANCEL and choose a key.
  2. Hold PTT and say “Screenshot” for the Label. Select Modifiers → ENTER, turn SCROLL to ⇧⌘, then ENTER. Select Key → ENTER, choose 4, then ENTER. Select Save → ENTER. This assigns cmd + shift + 4.
  3. Focus the Mac desktop and tap Screenshot. If macOS asks for Accessibility access, enable the app it names under Privacy & Security → Accessibility, then try again. The screenshot cursor appears; press Escape to cancel.

Shortcuts go to whichever app has focus.

WHEN SOMETHING DOESN’T RESPOND

Deck says “offline”
Open Service → Check my setup in OpenWalkieTalkie. Check the USB data cable or Bluetooth connection. Reconnect the deck; if needed, use Service → Restart in the Mac app. Demo data is not a live connection.
No agent sessions
Follow page 3 for Codex or page 4 for Claude Code. Installed confirms integration files; a session must also be open and connected. For Desktop, use the companion launcher.
No voice input
Check the selected session, host connection and speech engine. For BLE, allow Bluetooth access. There is no fallback to the Mac microphone; use Voice → Test Voice and check the selected engine and permissions. The BLE deck is not a macOS Sound input device.
A macro does nothing
Check that the key has a binding and the host has Accessibility permission. Select the intended desktop app, then try the shortcut again.
The screen is locked
Press any key, turn the wheel or touch the screen to wake it. Turn the wheel counterclockwise four ticks to unlock. Those ticks do not activate the underlying screen.

PLAY A LITTLE

Flappy Bird: tap PTT to fly.
Snake: turn the wheel left / right.
Raiden: hold Left / Right to move; auto-fire.
ENTER pauses. Best scores last until restart.

POWER & UPDATES

Hold PTT for 2 seconds to power on; hold CANCEL for 3 seconds to power off. Update firmware over USB from the Mac app’s Service page. From firmware 0.14.0, press ENTER on the deck to start the install.
