開始

準備好你的 Mac、裝置和一條 USB-C 傳輸線。

01

開啟應用程式。

下載適用於 Apple 晶片或 Intel 的 OpenWalkieTalkie（macOS 13+）。把它拖進「應用程式」並啟動。依照第 2 頁啟動配套服務。

02

連接裝置。

接上 USB-C 傳輸線，若出現提示，請允許此配件。若要無線使用，請在藍牙中配對 OpenWalkieTalkie。第 2 頁說明電源、配對與權限。

03

接上一個助理。

依照下方 Codex 或 Claude Code 的步驟操作，然後完成你的第一個任務。讓配套服務保持執行。

就緒檢查

你的工作階段出現了，而且沒有 離線 標記。轉動 SCROLL 選取它，然後按 ENTER。在第 5 頁傳送第一則訊息之前，先檢查「語音 → 測試語音」。

裝置 + 配套應用程式02 — 首次連線

開機。
連線。

準備好裝置、一條 USB-C 傳輸線和一台 Mac。安裝 OpenWalkieTalkie，並登入你打算使用的程式設計助理。

裝置按鍵、顯示與語音
↔
MAC 應用程式 + 服務連線與送達
↔
你的助理Codex / Claude Code

  1. 安裝、開啟並開機。

    開啟 Mac 下載，把 OpenWalkieTalkie 拖進「應用程式」並啟動。用 USB-C 傳輸線連接裝置。按住 PTT 2 秒開機，然後放開。若 macOS 詢問，請允許此配件。如果螢幕已鎖定，把滾輪逆時針轉四格。

  2. 完成首次設定。

    依序完成連接 → 將新增的內容 → 語音 → 整合。檢視背景服務與選用的 Claude 外掛，然後選擇新增這些項目。選擇你的語音辨識引擎，按繼續前往下一步。服務必須保持執行，裝置才能運作。

    已經設定過了？→ 開啟「裝置」檢查連線；若沒有連線，請使用「服務 → 檢查安裝狀態」。

  3. 不用連接線連線。

    若要無線使用，請在 macOS 的系統設定 → 藍牙中配對 OpenWalkieTalkie。在隱私權與安全性 → 藍牙中，允許配套應用程式取用。回到「裝置」，檢查它的連線狀態。

    檢查 → 裝置已連線，狀態可以讀取，即時頁面不再顯示離線。

  4. 測試麥克風與揚聲器。

    開啟語音。選擇「語音辨識」與「語音回覆」，設定語音辨識語言，並處理所有權限提示。按一下測試語音，然後在裝置上按住 PTT，說「hello」，再放開。檢查辨識出的文字。按一下朗讀範例檢查播放。接著依照 Codex 或 Claude Code 操作。

裝置語音

必須使用裝置的麥克風。0.15.0 版不會改用 Mac 的麥克風。藍牙語音使用應用程式自己的 BLE 連線；請不要在 macOS 的「聲音」中把裝置當成麥克風尋找。應用程式的五個頁面是「裝置」、「頁面與按鍵」、「整合」、「語音」與「服務」。

連接你的程式設計助理03 — CODEX

把 CODEX
帶到裝置上。

依你使用 Codex 的方式選擇 Desktop 或 CLI。檢查連線之前，配套服務必須已在執行。

如果你使用 CODEX DESKTOP

  1. 安裝 Desktop 整合。

    先依照官方 Desktop 設定說明安裝並登入。在 OpenWalkieTalkie 中，開啟整合 → Codex Desktop → 設定。閱讀預計進行的變更並確認。如果該列已是「已安裝」，直接繼續；只有在設定需要修正時才使用「修復」。

  2. 透過配套啟動器重新開啟。

    完成進行中的工作，結束 Codex Desktop / ChatGPT。在 Finder 中選擇前往 → 前往檔案夾，輸入 ~/Applications，然後開啟 Codex with OpenWalkieTalkie.app。之後為了使用裝置而重新開啟 Desktop 時，都請使用這個啟動器。

  3. 開啟一個本機對話。

    在 Codex 中開啟一個本機專案，開始或繼續一段對話。在 OpenWalkieTalkie 中開啟整合，檢查 Codex 那一列的數量與狀態。在裝置上，到助理中找到這段對話，然後按 ENTER。

    檢查 → 對話出現在裝置上，整合顯示有活動。配套應用程式只顯示數量，不顯示聊天內容。雲端與 SSH 工作階段不在這個整合的範圍內。

如果你使用 CODEX CLI

  1. 依照官方 Codex CLI 設定說明安裝並登入。使用 CLI 0.161+ 支援的共用常駐程式模式；若要接收裝置的回覆，請不要使用 --no-daemon。
  2. 在整合中開啟 Codex CLI，並確認整合沒有暫停。這個版本透過 Codex 本身連線；沒有另外安裝 CLI 掛鉤的步驟。
  3. 在你的專案資料夾中執行 codex 並開始一段對話。檢查整合的活動，並在裝置的「助理」清單中找到這個工作階段。

如果該列顯示「Codex is not running」，請先開啟一個本機工作階段。若仍無法連線，請使用「服務 → 檢查安裝狀態」。

連接你的程式設計助理04 — CLAUDE CODE

CLAUDE CODE。
一個即時工作階段。

請使用「整合」中的 Claude Code 那一列。Claude Desktop 是另一個產品，不能取代這些終端機步驟。

整合設定 Claude Code 外掛
→
專案終端機以 Channels 啟動
→
裝置上的助理選取就緒的工作階段

  1. 準備 Claude Code。

    依照官方 Claude Code 設定說明安裝並登入。在專案終端機中執行 claude --version，確認它可以使用。

  2. 安裝 OpenWalkieTalkie 外掛。

    開啟整合 → Claude Code → 設定。檢視預計進行的變更並確認。如果服務找不到 claude，「設定」會多要求一個步驟：按一下複製指令，並在終端機中執行該指令。若應用程式回報設定有問題，請使用修復並檢視建議的修正。安裝後請開始新的 Claude 工作階段；現有的工作階段可以用 /reload-plugins 重新載入外掛。

    檢查 → Claude Code 那一列顯示「已連線」。開始一個工作階段，確認它的活動與數量。

  3. 啟動支援語音的工作階段。

    在整合中啟用 Claude Channels。按一下如何連線… → 複製指令。把它貼到在專案資料夾中開啟的終端機並執行。這個版本的應用程式中，指令是：

    claude --dangerously-load-development-channels plugin:openwalkietalkie@openwalkietalkie

    若要繼續現有的對話，請先結束那個工作階段，再在後面加上 --resume 與它的工作階段 ID。如果已安裝的應用程式顯示的指令有所不同，請以應用程式為準。

  4. 完成 Claude 的連線提示。

    檢視 Claude 的本機開發確認。出現提示時，允許 OpenWalkieTalkie MCP 伺服器及其 acknowledge 連線檢查。回到配套應用程式的整合頁面；它的連線狀態會自動重新整理。

    檢查 → Claude Channels 那一列顯示「已連線」，你的 Claude 工作階段出現在裝置上。「未連線工作階段」表示啟動或確認還沒有完成。

  5. 在裝置上選取這個工作階段。

    前往助理。用 LEFT / RIGHT 找到專案，轉動 SCROLL 醒目顯示 Claude 工作階段，然後按 ENTER。依照下一頁的步驟說話與回覆。

如果卡住了

在 Claude 中開啟 /mcp，檢查 OpenWalkieTalkie 伺服器。請 Claude 執行 check_connection，再重新檢查 Claude Channels 那一列。Channels 是研究預覽功能，需要為每個工作階段加上開發旗標；組織政策仍然適用。不加旗標重新啟動即可關閉。在連線之前，備用收件匣可能會把訊息標示為來自另一個工作階段。

從頭到尾跟完一個任務05 — 動手做

選取。說話。
看結果。

先完成一個助理的設定。讓它的對話在 Mac 上保持開啟，這樣你就能清楚看到裝置把訊息送到哪裡。下面的螢幕圖片只是範例，不是你的即時工作階段。

1. 選對對話。

在裝置上：按 CANCEL 從對話回到「助理」。LEFT / RIGHT 切換專案頁，SCROLL 移動醒目顯示。選取你的專案與助理，然後按 ENTER 開啟。

檢查 → 對話標題與 Mac 上開啟的相同。觸控操作：點一下某一列選取，再點一下開啟。

2. 按住 PTT，說話，然後放開。

在裝置上：按住左側的 PTT 按鍵。確認助理名稱與「正在聆聽」指示。說：「總結一下這個專案，告訴我下一步該做什麼。」放開 PTT 傳送。若要捨棄這段錄音，請在 PTT 狀態下按 CANCEL。

在 MAC 上 → 你說的請求會送達那個工作階段。事先用「語音 → 測試語音」檢查辨識；只看到聆聽畫面並不能證明已送達。

3. 閱讀回覆。

在裝置上：等助理完成工作並回覆。SCROLL 瀏覽對話。按住 SHIFT 再按 ENTER，回到最新的訊息。LEFT / RIGHT 切換到上一個 / 下一個助理；CANCEL 回到清單。

在 MAC 上 → 助理在它平常的專案對話中工作。裝置顯示連結的記錄與狀態；它本身不會執行程式設計助理。

4. 助理提問時回答。

在裝置上：跳出提問通知時，點一下它，或在碰觸其他東西之前按 ENTER。在有待處理卡片的對話上按 ENTER 也會開啟它。閱讀問題，轉動 SCROLL 選擇，然後按 ENTER 送出。CANCEL 會讓卡片稍後提醒；它不會選擇「否」。從頂端向下滑動可以再次找到它。

在 MAC 上 → 回答會解決對應的提問。如果出現「未送達」，請檢查工作階段並在那裡回答。確認之前請閱讀實際的選項；圖中的提問只是範例。

試試追問

在同一段對話上再次按住 PTT，提出後續問題。在 Codex 中，閒置時這則訊息會開始新的一輪，執行中則會引導目前這一輪。在 Claude Code 中，它會透過 Channels 或備用收件匣送達已連線的工作階段。配套應用程式的視窗不顯示對話文字。

學會這些控制項06 — 日常使用

幾個按鍵。
一整張桌面。

SCROLL

轉動可移動醒目顯示；在對話中，轉動可閱讀較早的訊息。按住 SHIFT 再按 ENTER，可重新跟上最新的回覆。

PTT

按住為選取的助理錄音；放開傳送。錄音時按 CANCEL 可捨棄。在「遊戲」中，PTT 控制遊戲。

SHIFT + ↕

按住 SHIFT 並轉動 SCROLL 切換頁面。選取某一列之前先放開 SHIFT。連按兩下 SHIFT 開啟頁面管理。

CANCEL

按一下返回；在頁面的最上層時，回到「助理」。在提問卡片上，它是稍後提醒，而不是拒絕。有些配置把這個鍵標為 ESC。

ENTER

開啟醒目顯示的助理或待處理的卡片；確認選取的回答。對話中沒有待處理卡片時，切換「聊天 / 工作流程」。

LEFT / RIGHT

在「助理」中切換專案頁。在對話中切換助理。在提問卡片上，在待處理的卡片之間移動。

先切換頁面，再使用它

頁面 01

助理

在頁面的最上層按 CANCEL 回到首頁。用 SCROLL 選取工作階段，用 ENTER 開啟。依照第 5 頁傳送與回答訊息。

頁面 02

Omarchy

按住 SHIFT 並轉到 Omarchy。在已連線的 Omarchy / Hyprland 主機上，點一下工作區標籤或視窗列即可切換過去。只靠 Mac 應用程式無法提供這種主機。在支援的 Omarchy 主機上，PTT 會在游標處口述輸入；放開後插入文字，不按 Enter。

頁面 03

快捷鍵

先在「頁面與按鍵」中新增「快捷鍵」頁面，然後按住 SHIFT 並轉到它。使用指派的快速鍵之前，先讓目標 Mac 應用程式取得焦點。在第 7 頁的 Mac 應用程式中設定按鍵；裝置上的範例請見第 8 頁。

頁面 04

用量

按住 SHIFT 並轉到「用量」。按 ENTER 要求重新整理；SCROLL 查看其餘內容。如果缺少數值，請在 Mac 應用程式中開啟「頁面與按鍵 → 用量」，並啟用服務商的資料來源。Claude 用量需要主動開啟。

頁面 05

系統

按住 SHIFT 並轉到「系統」，查看主機狀態。如果顯示灰色或離線，請依照第 2 頁檢查連線。CANCEL 在這裡沒有作用；按住 SHIFT 並轉動即可離開。

頁面 06

遊戲

按住 SHIFT 並轉到「遊戲」。SCROLL 選擇遊戲，ENTER 開啟。遊戲操作請見第 8 頁；CANCEL 回到清單。在這裡 PTT 不會錄音。

依你的方式排列

連按兩下 SHIFT 開啟頁面管理。SCROLL 選取一個可移動的頁面；ENTER 拿起它，SCROLL 移動，ENTER 放下。CANCEL 取消拿起。連按兩下 SHIFT 離開。「助理」與「設定」固定不動；頁面管理最多支援八個頁面，其中最多三個「快捷鍵」。

在 MAC 上設定 · 在裝置上使用07 — 語音與快捷鍵設定

你的聲音。
你的快速鍵。

讓服務保持執行、裝置保持連線。這些英文截圖來自 0.15.0 版應用程式；你選擇的引擎與頁面清單可能不同。

設定語音，然後測試

  1. 選擇辨識方式。

    開啟語音 → 語音辨識。選擇在這台 Mac 上使用 Apple，或先下載 Whisper 模型再使用。為你要說的語言設定語音辨識語言。使用 Apple 辨識時，請按語音辨識 → 請求授權…，並在 macOS 的提示中允許。

  2. 檢查一次實際錄音。

    按一下測試語音。在已連線的裝置上按住 PTT，說「hello」，然後放開。向助理傳送請求之前，先檢查辨識出的文字。如果是空白，請檢查模型下載、權限與裝置連線。

  3. 選擇語音回覆。

    在語音回覆下選擇 Apple，或先下載 Kokoro。雲端語音需要先設定它的服務供應商。按一下朗讀範例；在裝置 → 揚聲器中調整音量。用播放提示音檢查通知聲音。

在 MAC 上建立一個快捷鍵

  1. 新增並選取「快捷鍵」。

    開啟頁面與按鍵 → 新增頁面 → 快捷鍵。在頁面清單中選取它的方塊，然後在「快捷鍵」頁面的按鍵下選取一個空位。

  2. 為按鍵命名並指派。

    在標籤中輸入截圖並按 Return。選擇一個裝置按鍵，或保持僅限觸控。把按鍵設為 4，並在修飾鍵中啟用 ⇧ 與 ⌘。變更會自動套用；Mac 上的編輯器沒有「儲存」按鈕。

  3. 在裝置上試試看。

    使用輔助使用 → 檢查…，若需要授權，請依照開啟設定操作。讓 Mac 桌面取得焦點。在裝置上，按住 SHIFT 並轉到「快捷鍵」；點一下「截圖」或按下它指派的按鍵。截圖游標出現。按 Escape 取消。

保持同步

在「頁面與按鍵」中，選取一個可移動的頁面，用「向左移動 / 向右移動」調整順序。在裝置上，SHIFT + SCROLL 會依這個順序切換。「助理」與「設定」固定不動。在 Mac 與裝置上使用同一個頁面名稱，確認你的變更已經同步。

語音需要已連線的主機與已設定好的語音辨識。語音回覆也取決於主機的語音設定。

你的第一個快捷鍵

  1. 開啟「快捷鍵」。點一下「+ 指派」，或按 SHIFT + CANCEL 並選擇一個按鍵。
  2. 按住 PTT，說「截圖」作為標籤。選擇「修飾鍵」→ ENTER，轉動 SCROLL 到 ⇧⌘，再按 ENTER。選擇「按鍵」→ ENTER，選擇 4，再按 ENTER。選擇「儲存」→ ENTER。這樣就指派了 cmd + shift + 4。
  3. 讓 Mac 桌面取得焦點，點一下「截圖」。如果 macOS 要求輔助使用權限，請在「隱私權與安全性 → 輔助使用」中啟用它提到的應用程式，然後再試一次。截圖游標出現；按 Escape 取消。

快速鍵會送到目前取得焦點的應用程式。

沒有反應時

裝置顯示「離線」
在 OpenWalkieTalkie 中開啟服務 → 檢查安裝狀態。檢查 USB 傳輸線或藍牙連線。重新連接裝置；如有需要，在 Mac 應用程式中使用「服務 → 重新啟動」。展示資料不是即時連線。
沒有助理工作階段
Codex 請依照第 3 頁，Claude Code 請依照第 4 頁。「已安裝」只代表整合檔案已就位；還必須有一個開啟且已連線的工作階段。Desktop 請使用配套啟動器。
沒有語音輸入
檢查選取的工作階段、主機連線與語音辨識引擎。使用 BLE 時，請允許藍牙取用。不會改用 Mac 的麥克風；請使用「語音 → 測試語音」，檢查選取的引擎與權限。BLE 裝置不是 macOS「聲音」中的輸入裝置。
快捷鍵沒有反應
檢查按鍵是否有綁定，以及主機是否有輔助使用權限。選取目標桌面應用程式，然後再試一次快速鍵。
螢幕已鎖定
按任一鍵、轉動滾輪或觸碰螢幕即可喚醒。把滾輪逆時針轉四格解鎖。這幾格轉動不會操作下方的畫面。

玩一下

像素小鳥：點一下 PTT 飛行。
貪食蛇：向左 / 向右轉動滾輪。
雷電：按住 Left / Right 移動；自動射擊。
ENTER 暫停。最高分保留到重新啟動為止。

電源與更新

按住 PTT 2 秒開機；按住 CANCEL 3 秒關機。在 Mac 應用程式的「服務」頁面透過 USB 更新韌體。從韌體 0.14.0 起，需在裝置上按 ENTER 開始安裝。
