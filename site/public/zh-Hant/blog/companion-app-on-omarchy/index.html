OpenWalkieTalkie v0.15.0：配套應用程式登上 Omarchy

2026年11月17日Omarchy 應用程式、聽寫與服務

0.15.0 版把配套應用程式帶到 Omarchy，並讓裝置在那裡成為聽寫用的麥克風。裝置韌體維持 0.14.0 不變。

Omarchy 上的配套應用程式

Mac 和 Windows 上的應用程式，現在也能在 Omarchy（Hyprland）上執行，在應用程式啟動器中名為 OpenWalkieTalkie，同樣有五個頁面：裝置、頁面與按鍵、整合、語音和服務。它會自己找到服務。服務透過服務的 systemd 使用者單元來啟動和停止服務，登入時開啟則是一個 XDG 自動啟動項目。沒有系統匣圖示，那是桌面狀態列的工作；也沒有應用程式內更新，因為應用程式是從原始碼建置的。

頁面與按鍵也能配合比應用程式設計寬度更窄的並排視窗：頁面清單會換到第二列，按鍵編輯區會移到按鍵方格下方。Omarchy 指南說明了如何建置和安裝。

在 Omarchy 頁面上聽寫

在 Omarchy 頁面上，PTT 的用法就像 Superwhisper 本身的按住說話。按住並說話，放開，你說的話就會輸入到目前取得鍵盤的視窗的游標處，不會按下 Enter。按住時按 CANCEL 會捨棄這段錄音。裝有 Superwhisper 時由它辨識，並使用它自己的模式、語言和詞彙；否則由本機的 Whisper 模型辨識。為此，橋接程式會在清單中加入一個 Dictate 項目，在「助理」頁面上選取它，也能用同樣的方式聽寫。

滾輪跟著列移動

在 Omarchy 頁面上，滾輪現在會依頁面列出的順序在視窗列之間移動，就像它在裝置其他清單中移動一樣，並在第一列和最後一列停住。以前它依照 Hyprland 本身的視窗順序，所以轉一下可能會跳過下一列。

Linux 上只用一個資料夾

Linux 服務現在把所有內容放在同一個資料夾 ~/.local/share/openwalkietalkie，就像在 Mac 上由一個資料夾存放一樣。Omarchy 的安裝原本就在那裡執行，deckd 指令也不再需要 DECKD_DATA_DIR=… 前綴。如果你曾在 Linux 上依照舊的配置手動執行 deckd，請把它的檔案移到該資料夾，或設定 DECKD_DATA_DIR。

更新

在 Mac 上，選擇檢查更新…，或安裝已簽署並經過公證的 0.15.0 應用程式，支援 Apple Silicon 或 Intel（macOS 13 或更新版本）。在 Windows 上，請從發行頁面下載 ZIP 檔。在 Omarchy 上，拉取程式碼，建置服務和應用程式，再用兩者執行 install.sh，做法請見 Omarchy 指南。這次發行不需要更新裝置韌體。
