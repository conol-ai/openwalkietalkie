OpenWalkieTalkie v0.12.0：Conol 聽得見你，還有番茄鐘

2026年11月5日Mac 應用程式、服務與韌體

當你從裝置對 Conol 聊天說話時，得到的文字應該和你直接在 Conol 的輸入框口述時得到的結果一樣。0.12.0 版把這些按鍵錄音交給 Conol 自己的語音模型，在你說話時顯示錄音時間軸，同步呈現 Conol 正在做的事，並新增含番茄鐘的「計時器」頁面。

Conol 轉寫自己的聊天

在 Conol 聊天或 + New chat 上按住 PTT，Mac 上的服務會錄下這次按鍵，並交給 Conol 桌面應用程式。Conol 以其輸入框麥克風背後的雲端語音模型轉寫，放開後裝置顯示的、實際送出的都是這段文字，包括對 Conol 提問的口述回答。

按住期間，Mac 本身的辨識器也會持續執行。如果 Conol 無法回應、發生錯誤或超過 20 秒仍未回傳，就會改用 Mac 的轉寫，因此按下的內容不會遺失。其他助理以及裝置上的語音命名仍留在你的 Mac 上。只有傳給 Conol 聊天的錄音會離開 Mac，而且只會傳到你已登入的 Conol 應用程式；設定 [voice.stt] companion = false 即可讓所有錄音都留在本機。這需要更新後的 Conol 桌面版和網頁版；若 Conol 應用程式是舊版，一切維持不變。

說話時的時間軸

Mac 即時辨識出的文字不是 Conol 將聽到的內容，所以這類按鍵錄音時，裝置不再顯示那些文字。裝置會改為顯示正在錄音、大字的經過時間和一條時間軸：紅色播放頭由左往右移動，後方填入由裝置本身麥克風測得的你的聲音波形。按得較久時會捲動。放開後，裝置顯示正在轉寫，接著顯示 Conol 的轉寫。

看見 Conol 正在做什麼

執行中的 Conol 聊天現在會在裝置上顯示目前公開的步驟，例如「Running a command」加上簡短預覽，清單和對話中都會顯示。它會就地更新，步驟結束時清除。完整的工具輸入和結果仍留在 Conol 中。

計時器與番茄鐘

從頁面管理的 + 範本庫新增計時器，就能使用含計圈的碼錶、含預設時間的倒數計時，以及番茄鐘：專注 25 分鐘、休息 5 分鐘，每四段專注後休息 15 分鐘。每個階段都會等你按下下一步 / Enter。計時器在裝置本身上執行，切到其他頁面或螢幕休眠時也會繼續，結束時會喚醒螢幕並跳出提示。

給配套應用程式開發者

任何具備自己辨識器的原生配套應用程式，都可以註冊 caps.transcribe: "push"、接收 agent.transcribe 請求、以 agent.transcribe.audio 分頁讀取 16 kHz WAV，再以 agent.transcribe.result 回覆。活動列使用 agent.reply 上的 message.summary。原生配套應用程式指南和 API 參考文件說明了這兩項。

更新

選擇檢查更新，或安裝已簽署並經過公證的 0.12.0 版 Mac 應用程式（Apple Silicon 或 Intel）。需要 macOS 13 或更新版本。錄音時間軸和「計時器」頁面需要韌體 0.12.0：以 USB 連接裝置後，開啟服務 → 更新 → 檢查韌體更新。設定和藍牙配對都會保留。
