OpenWalkieTalkie v0.8.0：螢幕鎖定與一致的滾輪操作

2026年10月21日應用程式與韌體更新

手持裝置應該拿起來就能用，但不該在包包裡誤傳一則語音訊息。0.8.0 版新增自動螢幕鎖定，並讓滾輪在切換頁面和瀏覽清單時的方向保持一致。

兩分鐘鎖定，四格解鎖

兩分鐘內沒有本機輸入，螢幕就會休眠，所有本機控制項都會鎖定，包括按住說話。按下按鍵、觸控螢幕或轉動滾輪會點亮鎖定畫面，但不會觸發底下的控制項。

解鎖時，逆時針連續轉動滾輪四格。如果第一格喚醒了螢幕，這一格也算在四格之內。順時針轉動或讓螢幕再次休眠，進度都會歸零。

最後一格只負責解鎖裝置，不會同時移動選取。鎖定期間一直按住的按鍵必須放開再按一次才會作用，所以裝置解鎖時，卡住的 PTT 不會開始傳送。通知可以點亮螢幕，但無法解鎖；按住按鍵也不能讓鎖定的螢幕一直亮著。

頁面與清單同一個方向

編碼器的實體方向已經修正。逆時針選擇下一個或往下；順時針選擇上一個或往上。這適用於 SHIFT + 滾輪切換頁面，也適用於選單項目、助理與工作階段清單、卡片選項以及清單捲動。使用教學中的頁面方向也相同。

數值設定（包括音量）仍然是順時針增加。「快捷鍵」頁面已指定的按鍵綁定和遊戲中的轉向維持原本的實體方向。

保留音訊改進

此版本保留 0.7.0 推出的揚聲器 EQ 與 Rev A 的 RAM 執行。Rev B 仍從 NOR 快閃記憶體執行。快閃記憶體分割區和復原協定都沒有變更。

更新應用程式與裝置

安裝已簽署並經過公證的 Mac 應用程式（Apple Silicon 或 Intel），或在應用程式中選擇檢查更新。需要 macOS 13 或更新版本。透過 USB-C 連接裝置，然後使用服務 → 更新 → 檢查韌體更新。應用程式、服務和韌體都應顯示 0.8.0。

已使用復原協定 2 的裝置會收到一般的應用程式更新，設定和藍牙配對都會保留。較舊的復原版本使用應用程式現有的引導式移轉。現有裝置請使用應用程式的更新功能：Rev A 與 Rev B 各自的原廠 ZIP 含有整顆晶片的映像檔，會覆寫設定和配對。

我們檢查了什麼

開發版韌體已透過 USB 燒錄到一台 Rev A 裝置並完成驗證，操作人員也確認了滾輪實體方向的修正。自動檢查涵蓋鎖定計時、按住與排隊中的輸入、PTT 抑制、滾輪選擇與邊界、算繪，以及各主機板的執行配置。這次沒有在 Rev B 硬體上實機測試。
