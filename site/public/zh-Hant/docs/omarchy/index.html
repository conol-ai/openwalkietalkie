在 Omarchy 上使用 OpenWalkieTalkie

把裝置變成 Omarchy（Hyprland）筆電的遙控器

在 Omarchy 上，裝置直接操控你的桌面和程式設計助理，不需要 Mac。筆電上執行兩個小服務：deckd，也就是 Mac 應用程式所執行的同一個服務的 Linux 版；以及 Omarchy 橋接，它把服務連接到 Hyprland，以及你的 Claude Code、Codex 與 Kimi Code 工作階段。

  • Omarchy 頁面：你的工作區與視窗。滾輪切換視窗，LEFT / RIGHT 切換工作區，ENTER 切換全螢幕，SHIFT+CANCEL 切換 scratchpad。
  • 清單上的工作階段，顯示為執行中、已完成或正在提問。選取其中一個，會把它的終端機帶到最前面。
  • 語音指令：在工作階段上按住 PTT 說話。說的話會輸入到它的終端機，這一輪結束時，回覆會顯示並朗讀出來。
  • 「快捷鍵」、「系統」與「用量」頁面，資料來自這台筆電。
  • 應用程式，與 Mac 上是同一個視窗，位於 Omarchy 的應用程式啟動器中。

Linux 版還沒有可下載的套件：你需要從原始碼建置 deckd 與應用程式，第一次大約需要十分鐘。以下每一道指令都在 Omarchy 筆電的終端機中執行。

1. 安裝工具

sudo pacman -S --needed base-devel git rustup cmake clang espeak-ng wtype
rustup default stable

cmake 與 clang 用來建置本機語音辨識器，espeak-ng 在裝置上朗讀回覆，wtype 把指令輸入到終端機。建置所需的其他函式庫（udev、ALSA、D-Bus）Omarchy 都已內建。

2. 建置並安裝

git clone https://github.com/conol-ai/openwalkietalkie.git
cd openwalkietalkie/host
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

install.sh 會把 deckd 與應用程式放到 ~/.local/bin，以 OpenWalkieTalkie 的名稱把應用程式加入 Omarchy 的啟動器，把橋接複製到 ~/.local/share/openwalkietalkie/omarchy，並將兩者以 systemd 使用者服務 deckd 與 omarchy-deck 啟動。每次登入時它們都會再次啟動。最後它會列出需要 root 權限的步驟，也就是下一節。

3. 讓服務能開啟裝置

裝置的 HID 裝置節點屬於 root，直到一條 udev 規則把它交給你。請執行 install.sh 列出的兩道指令：

sudo install -m 644 omarchy/70-openwalkietalkie.rules /etc/udev/rules.d/
sudo udevadm control --reload && sudo udevadm trigger --subsystem-match=hidraw

這條規則同時適用於透過 USB-C 與藍牙連接的裝置。

4. 連接裝置

  • USB-C：插上即可，不需要其他步驟。
  • 藍牙：從 Omarchy 的藍牙選單（或用 bluetoothctl）配對 OpenWalkieTalkie。裝置同時只保留一個配對：如果它曾與 Mac 配對，請先在 Mac 上移除。

服務會在幾秒內自動連線。檢查一下：

deckd status

link: 那一行應顯示 Connected, session Live。

5. 把工作階段放到裝置上

為你使用的助理安裝掛鉤。每次安裝都會先備份助理的設定檔，並在其中加入內容，而不是取代它：

python3 omarchy/omarchy_hook.py install claude
python3 omarchy/omarchy_hook.py install codex
python3 omarchy/omarchy_hook.py install kimi

已經開啟的工作階段不會載入新的掛鉤：重新啟動它們，它們就會出現在「助理」頁面上。

6. 語音

在選取的工作階段上按住 PTT，說話，然後放開。文字會輸入到該工作階段的終端機，接著按下 Enter。

  • 使用 Superwhisper 時（Omarchy 的口述工具，如果你有在用），不需要任何設定。它會以自己的模式、語言與詞彙辨識每次按鍵，在 Cloud 模式下不到一秒。請用 superwhisper status 確認它已就緒。
  • 不使用時，請下載一次本機 Whisper 模型（約 465 MB）： 
    printf '[voice.stt]\nengine = "whisper"\nmodel = "small"\nlanguage = "auto"\n' >> ~/.local/share/openwalkietalkie/config.toml
deckd stt install --model small
    Whisper 在筆電的 CPU 上執行，所以每次按鍵需要幾秒或更久，視處理器而定。

語音只能送達在終端機視窗中執行的工作階段。由其他應用程式代管的工作階段沒有可輸入的終端機，裝置會顯示該指令未送達。

7. 選用：「快捷鍵」頁面的快速鍵

設有按鍵組合的「快捷鍵」按鍵會在筆電上輸入該組合。若要讓按鍵除了觸發焦點應用程式的快速鍵，也能觸發 Omarchy 自己的快速鍵（Super+…），橋接需要扮演鍵盤，這需要 /dev/uinput：

sudo install -m 644 omarchy/71-openwalkietalkie-uinput.rules /etc/udev/rules.d/
echo uinput | sudo tee /etc/modules-load.d/openwalkietalkie-uinput.conf
sudo udevadm control --reload && sudo modprobe uinput
systemctl --user restart omarchy-deck

之後，你執行的任何程式都能建立輸入裝置，和 ydotool 一樣。不做這一步，「快捷鍵」按鍵仍會送達焦點應用程式，但無法觸發 Omarchy 的快速鍵。

8. 選用：Claude 用量條

「用量」頁面可以顯示你的 Claude 速率限制時段，每五分鐘以你的 Claude Code 登入讀取一次：

deckd config set 'usage.providers=["codex","claude"]'

檢查安裝

deckd care checks
python3 omarchy/omarchy_hook.py status
journalctl --user -u deckd -u omarchy-deck -f

也可以從應用程式啟動器開啟 OpenWalkieTalkie：它的「裝置」頁面顯示連線狀態，「服務」頁面可以啟動和停止服務（deckd systemd 單元），並設定登入時開啟應用程式。服務的所有檔案都在 ~/.local/share/openwalkietalkie。

更新

cd openwalkietalkie/host
git pull
cargo build --release --target x86_64-unknown-linux-gnu -p deckd -p openwalkietalkie-app
sh omarchy/install.sh target/x86_64-unknown-linux-gnu/release/deckd target/x86_64-unknown-linux-gnu/release/openwalkietalkie-app

再次執行 install.sh 會以新程式碼重新啟動兩個服務；結束並重新開啟應用程式即可執行新版本。若要更新裝置的韌體，請用 USB-C 連接裝置，執行 deckd firmware check，再執行 deckd firmware install，或使用應用程式的「服務」頁面。裝置會在安裝前要求你按 ENTER。這與 Mac 使用的是同一條 USB 路徑，但尚未在 Omarchy 上試過。

Omarchy 上暫時還沒有

  • 在裝置上回應權限請求：它們仍留在終端機中。
  • Codex 用量條，以及在閱讀畫面中查看 Omarchy 工作階段的歷程與工具活動記錄。
  • 系統匣圖示與應用程式自動更新：應用程式是從原始碼建置的，請依上面的方式更新。

解除安裝

python3 omarchy/omarchy_hook.py uninstall all
systemctl --user disable --now deckd omarchy-deck
rm -f ~/.config/systemd/user/deckd.service ~/.config/systemd/user/omarchy-deck.service ~/.local/bin/deckd ~/.local/bin/openwalkietalkie-app
rm -f ~/.local/share/applications/openwalkietalkie.desktop ~/.local/share/icons/hicolor/512x512/apps/openwalkietalkie.png ~/.config/autostart/openwalkietalkie.desktop
rm -rf ~/.local/share/openwalkietalkie
sudo rm -f /etc/udev/rules.d/70-openwalkietalkie.rules /etc/udev/rules.d/71-openwalkietalkie-uinput.rules /etc/modules-load.d/openwalkietalkie-uinput.conf

解除安裝掛鉤只會移除它在各個助理設定中加入的內容。
