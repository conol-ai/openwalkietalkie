Windows 版 OpenWalkieTalkie

適用於 x64 Windows 10 與 11 的應用程式與服務

Windows 預覽版執行的服務與應用程式和 Mac 版相同：裝置透過 USB-C 或藍牙連線，顯示你的 Claude Code 與 Codex 工作階段，回應它們的核准請求，接收按住說話的口述並朗讀回覆，應用程式也能更新裝置的韌體。它之所以是預覽版，是因為有幾項 Mac 功能在 Windows 上還沒有（見下文），而且它沒有程式碼簽章，所以 Windows 會在第一次執行前發出警告。

下載

下載 Windows x64 預覽版 ZIP。這個獨立的 Windows 預覽版包含語音、Claude Code、Codex CLI 與 Grok Bot。它的版本說明列出原始碼版本與 SHA-256 總和檢查碼。從 0.14.0 起，每個正式版本也都包含名為 OpenWalkieTalkie-<version>-windows-x86_64.zip 的 Windows 組建。要驗證下載的檔案，請在「下載」資料夾中開啟 PowerShell 執行：

Get-FileHash .\OpenWalkieTalkie-*-windows-x86_64.zip -Algorithm SHA256

安裝

  1. 解壓縮到你存放程式的地方，例如 %LOCALAPPDATA%\Programs\OpenWalkieTalkie。請保留 bin 資料夾的原樣：應用程式只有從名為 bin 的資料夾執行時才會安裝韌體，並會啟動旁邊的 deckd.exe。
  2. 開啟 bin\OpenWalkieTalkie.exe。因為程式沒有簽署，Windows SmartScreen 會顯示Windows 已保護您的電腦。選擇其他資訊，再選擇仍要執行。Windows 會為這一份複本記住你的選擇。
  3. 依照首次執行的步驟操作。這些步驟會在背景以無視窗的方式啟動 deckd.exe（與裝置通訊的服務），並設為每次登入時啟動（設定 › 應用程式 › 啟動中會列出它）。服務 › 登入時啟動則為應用程式本身做同樣的設定。關閉視窗後應用程式仍會留在通知區域；從它的圖示選單結束。
  4. 用 USB-C 連接裝置，或在設定 › 藍牙與裝置中配對。服務連線後，應用程式的「裝置」頁面就會顯示它。

語音

裝置上的按住說話由這台電腦上的 Whisper 辨識：請在應用程式的語音頁面下載它的模型（Windows 沒有內建的辨識器，所以在模型下載完成前，按下說話鍵時會提示這一點）。回覆預設由 Windows 內建的語音朗讀，你也可以選擇 Kokoro（以相同方式下載），或使用你自己的 OpenAI 或 ElevenLabs 金鑰的雲端語音。裝置的麥克風與揚聲器透過連接線與藍牙都能使用。

如果 Windows 沒有提供「仍要執行」

在部分新安裝的 Windows 11 上，智慧型應用程式控制會封鎖未簽署的程式，且無法略過。你可以在Windows 安全性 → 應用程式與瀏覽器控制 → 智慧型應用程式控制中查看它的設定。它開啟時預覽版無法執行；而在許多 Windows 版本上，一旦關閉就無法再開啟，除非重新安裝 Windows，所以請自行判斷是否值得。防毒軟體也可能暫時攔下新的未簽署下載；上面的總和檢查碼可以確認這就是版本發布的檔案。

更新裝置的韌體

用 USB-C 連接一台裝置，開啟服務，在裝置韌體上按一下檢查，再按檢視…與安裝，和在 Mac 上完全相同。在裝置恢復之前請不要拔掉連接線。在 Windows 上，傳輸使用裝置的 HID 連線，而不是較快的 USB 介面（Windows 沒有它的驅動程式），所以需要幾分鐘（在 Rev A 上安裝 0.13.0 約五分鐘）。如果你在虛擬機器中執行 Windows，請確認裝置重新啟動後再次直通給虛擬機器：更新期間它會重新連線兩次。

連接 Grok Bot

Grok Bot：開啟整合 → 機器人，新增機器人的例行工作 Webhook。「複製提示詞」會給機器人一組 PowerShell 指令，用來把回覆和提問傳回這台電腦；請在 Grok Bot 的 Computer 設定中允許這些指令。服務會把例行工作的金鑰保存在 Windows 認證管理員中。使用獨立資料目錄的服務則改用 grokbot-keys.toml。

更新應用程式

開啟服務，按一下應用程式旁的檢查，或在圖示選單中選擇檢查更新…。最新版本有較新的版本時，按一下更新：應用程式會下載該版本的 zip，用版本發布的總和檢查碼核對，把新的 OpenWalkieTalkie.exe 與 deckd.exe 放進你的 bin 資料夾，然後重新啟動。你的設定保存在 %LOCALAPPDATA%\OpenWalkieTalkie。若要手動更新，請從最新版本下載 zip，從圖示選單結束應用程式，再用新資料夾取代舊版本的資料夾。

與 Mac 版的差異

  • 雲端語音的金鑰保存在 Windows 認證管理員中，Mac 版則保存在鑰匙圈中。
  • 應用程式沒有簽署，所以服務依位置信任它：也就是 deckd.exe 旁邊的 OpenWalkieTalkie.exe。Mac 版則會檢查應用程式的簽章。
  • Windows 上暫時還沒有：需要 Apple 晶片的 MLX 語音，以及在服務共用的 Codex 常駐程式上開啟 Codex Desktop 的啟動器。終端機中的 Codex 與在 Mac 上一樣可用。

解除安裝

執行 bin\deckd.exe uninstall 可停止服務，並移除登入時啟動的項目以及 Claude Code 與 Codex 整合；加上 --purge 還會刪除 %LOCALAPPDATA%\OpenWalkieTalkie 中的內容（設定、語音模型、已下載的韌體），只保留 logs 資料夾，你可以自行刪除。接著從圖示選單結束應用程式，並刪除你解壓縮出的資料夾。

遇到問題嗎？請回報 Issue，並附上 %LOCALAPPDATA%\OpenWalkieTalkie\logs 中的記錄。
