第二章

三個通道，各司其職

螢幕是狀態看板。PTT 是對講機。按鍵負責做決定。讀對話，看誰在等你，然後在裝置上回應。

按住說話

在工作頁面上按住這個鍵，螢幕就會變成「正在聆聽」畫面。放開後，辨識完成之前轉寫內容會持續顯示。裝置的麥克風把聲音傳到你的 Mac，說的話會作為下一個提示詞進入目前的助理，回覆還能透過裝置的揚聲器朗讀出來。

清單

每個助理都是一個頻道。紅點是提問，綠點是已完成，藍點是執行中。提問排在最上面，所以你第一眼看到的那一列，就是需要你的那一個。

提問 · 已完成 · 執行中

卡片

權限請求或選擇題會變成一張卡片。捲動到一個選項按 ENTER、點一下它，或用語音回答。Claude Code 或 Codex 的權限卡片只能由人來核准。

按一下 · 完整脈絡

滾輪

轉一格，移一列。按住 SHIFT，同一個滾輪就在頁面之間滑動：助理、Omarchy、快捷鍵、用量、系統與遊戲。連按兩下 SHIFT 可以重新排序。

SCROLL · SHIFT+SCROLL

「快捷鍵」頁面

觸控螢幕上的九個按鍵，每個都有標籤與按鍵組合。主機端把組合鍵送到你的桌面。直接在裝置上編輯按鍵，用 PTT 口述它的標籤。

⌘⇧4 · 點一下或綁定

「用量」頁面

你的 Claude 與 Codex 速率限制時段以長條顯示，附上目前的帳號與每次重設的倒數。主機端只用你已經登入的帳號讀取，不用其他任何東西。

工作階段 · 每週 · 重設

有線或無線

插上 USB-C，主機端寫入一次報告不到一毫秒。拔掉後，同一條連線（包括語音）改走低功耗藍牙。只要有線接著，主機端就用有線。

        第六章

        設計藍圖

        依照開放的設計自己動手做一台，或加入候補名單等待成品。主機板、韌體、主機端服務與通訊協定都在同一個存放庫裡。

        清單 · openwalkietalkie MIT + CERN-OHL-P
        • openwalkietalkie/ 主機板、韌體與 Mac 應用程式，全都在一起。複製下來就能開始。
        • ├─ hardware/rev-b/ Rev B 主機板：一個 KiCad 專案，含 Gerber、BOM 與貼片座標。CERN-OHL-P 2.0。
        • ├─ hardware/rev-a/ 一切的起點：CoHDL 電路圖原始檔、四個已打樣的版本、外殼 CAD。
        • ├─ src/ 以 embassy 為基礎的 Rust 韌體：各個頁面、透過 BLE 與 USB 的 HID 連線、配對日誌、電源管理。
        • ├─ native/ 帶有藍牙音訊的 RT-Thread 映像檔，掛載同一套介面核心。
        • ├─ host/ deckd 與 Mac 應用程式，Rust + gpui：連線、Claude Code 與 Codex 轉接器、語音、開放 API。
        • └─ docs/deck-protocol.md 通道 5 上的通訊約定。讀完它，你的指令碼就能成為裝置上的助理。

        軟體採用 MIT 授權。主機板、外殼與所有設計檔案採用寬鬆的 CERN 開放硬體授權。製作、修改、販售，都不需要許可。

        硬體設計始於 CoHDL。Rev A 電路圖是用開源硬體語言寫成的原始碼，請見 cohdl.org，並由它的編譯器檢查；Rev B 承襲這條脈絡，在 KiCad 中手動擺放與佈線。

        ★ 在 GitHub 取得設計藍圖 ▼ 下載 Mac 版 加入 Discord

        Mac 應用程式包含 deckd、應用程式自動更新，以及 Rev A 與 Rev B 的韌體更新。原始碼中包含首次透過 USB-C 或 UART 燒錄所需的工具。

        取得應用程式

        v0.17.0，適用於 macOS 13 及更新版本，已簽署並經過公證：你的裝置的配套應用程式，支援 Mac、Windows 與 Omarchy。Windows 10 與 11 為未簽署的預覽版。

        ↓ Mac · Apple 晶片 ↓ Mac · Intel ↓ Windows · x64 預覽版 Omarchy · Linux

        開啟磁碟映像檔，把 OpenWalkieTalkie 拖進「應用程式」，然後依照應用程式中的設定操作。M 系列 Mac 請選 Apple 晶片，Intel Mac 請選 Intel。

        在 Windows 10 或 11（x64）上，未簽署的預覽版支援語音、Claude Code、Codex CLI 與 Grok Bot。設定與 SmartScreen 請閱讀 Windows 安裝指南，並查看預覽版的版本說明與總和檢查碼。

        在 Omarchy（Hyprland）筆電上，服務與 Omarchy 橋接需要從原始碼建置：依照 Omarchy 指南設定桌面遙控、助理工作階段與語音指令。

        應用程式包含自動更新，以及能辨識主機板的 Rev A 與 Rev B USB 韌體更新。首次燒錄需要相容的開機載入程式。版本說明、韌體與總和檢查碼 →
