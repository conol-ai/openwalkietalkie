OPENWALKIETALKIE

隱私權政策

更新於 2026年10月16日

本聲明適用於 openwalkietalkie.org 及其裝置候補名單，兩者由 COHDL 旗下專案 OpenWalkieTalkie 的團隊營運。聯絡我們：privacy@cohdl.ai。

我們蒐集哪些資料

  • 候補名單：你送出的電子郵件地址、登記日期，以及你同意接收裝置開賣消息時所顯示的聲明版本。
  • 連線資訊：Cloudflare 會處理請求的中繼資料（包括你的 IP 位址），以提供並保護網站。我們的登記端點會使用你的 IP 進行短時間的頻率限制。我們不會將 IP、你的瀏覽器資訊或來源網址儲存在候補名單資料庫中。
  • 瀏覽器偏好：你選擇的日間／夜間主題和 Cookie 同意選擇都保存在你的瀏覽器中。請參閱 Cookie 說明。

我們為何使用這些資料

在你同意的前提下，我們會用你的電子郵件通知你裝置何時開賣，並寄送相關的開賣消息。加入名單不代表訂購、預訂或付款，也不保證交貨日期。我們不會將你加入 Cohdl 軟體候補名單或無關的郵寄清單。

連線中繼資料用於提供網站、防止垃圾訊息及診斷故障。我們的應用程式記錄不包含登記表單的內容。我們使用 Google Tag Manager 管理網站代碼。容器載入時，Google 會處理相關請求。視啟用的代碼而定，這些代碼可能蒐集網頁瀏覽紀錄、來源網址、裝置和瀏覽器資訊，以及根據 IP 位址推斷的概略位置。詳情請參閱Google 的隱私權政策。

誰會處理這些資料

營運 OpenWalkieTalkie 的團隊可以存取這份名單，用來管理登記並寄送你要求的消息。Cloudflare 代管本網站，並將名單儲存在其 D1 資料庫中；處理可能在 Cloudflare 營運的國家進行。請參閱 Cloudflare 的隱私權政策。我們不會出售你的候補名單資料。

前往 GitHub、Discord 及其他網站的連結，會帶你到各自訂有隱私權政策的服務。

我們保留多久

候補名單項目會在兩年後自動刪除。你可以要求提早刪除。已刪除的資料可能仍會留在服務供應商的備份中，直到其正常保留週期結束。

你的選擇與請求

如要退出名單、更正電子郵件，或索取、刪除你的登記資料副本，請以你登記時使用的地址寄信至 privacy@cohdl.ai。撤回同意後，你將不會再收到後續的開賣通知信。在揭露或變更資料之前，我們可能需要先驗證請求。

視你所在的地區而定，你可能還享有其他權利：限制或反對處理、取得可攜式副本，或向當地的資料保護主管機關提出申訴。

裝置與 Mac 應用程式

本聲明說明的是網站與候補名單。加入名單不會將你與助理的對話、語音錄音或已連線裝置中的資訊傳送給我們。瀏覽器展示使用預先寫好的內容，不會錄下你的麥克風。

變更

網站的資料處理方式有所變更時，我們會更新本頁。上方的日期標示此版本。
