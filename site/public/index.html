CHAPTER II

THREE CHANNELS, ONE JOB EACH

The screen is the status board. PTT is the radio. The buttons are the decisions. Read the conversation, see who needs you, and respond from the deck.

▼ HOLD ME ▼

Push to Talk

Hold the key from any face and the screen becomes a LISTENING overlay. Release it and the transcript stays visible while recognition finishes. The deck's microphone streams to your Mac, the words land in the active agent as its next prompt, and the reply can be spoken back through the deck's speaker.

At rest. Hold the key to open a session.

The Roster

Every agent is a channel. A red dot is a question, green is ready, blue is working. Questions sort to the top, so the row you see first is the one that needs you.

QUESTION · READY · WORKING

Cards

A permission request or a multiple-choice question becomes a card. Scroll to a choice and press ENTER, tap it, or answer by voice. Only a person can approve a Claude Code or Codex permission card.

ONE PRESS · FULL CONTEXT

The Wheel

One detent, one row. Hold SHIFT and the same wheel slides between faces: Agents, Omarchy, Macropad, Usage, Settings. Double-tap SHIFT to reorder them.

SCROLL · SHIFT+SCROLL

Macropad Face

Nine keys on the touch screen, each with a label and a keystroke. The host posts the chord to your desktop. Edit a key on the deck itself and dictate its label with PTT.

⌘⇧4 · TAP OR BIND

Usage Face

Your Claude and Codex rate-limit windows as bars, with the active account and countdown to each reset. The host reads them with the logins you already have, nothing else.

SESSION · WEEK · RESET

Cable or Air

Plug in over USB-C and the host writes a report in under a millisecond. Unplug and the same link, voice included, rides Bluetooth LE. The host takes the cable whenever it is there.

        CHAPTER VI

        THE BLUEPRINT

        Build your own from the open designs, or join the waitlist for a finished device. The board, firmware, host service and wire protocol are all in one tree.

        INVENTORY · openwalkietalkie MIT + CERN-OHL-P
        • openwalkietalkie/ The board, firmware and Mac app, together. Clone it and go.
        • ├─ hardware/rev-b/ The main board, Rev B: a KiCad project with Gerbers, BOM and pick-and-place. CERN-OHL-P 2.0.
        • ├─ hardware/rev-a/ Where it started: CoHDL schematic sources, four fabricated releases, the case CAD.
        • ├─ src/ Rust firmware on embassy: the faces, the HID link over BLE and USB, the bond journal, power.
        • ├─ native/ The RT-Thread image with Bluetooth audio, mounting the same UI core.
        • ├─ host/ deckd and the Mac app, Rust + gpui: the link, the Claude Code and Codex adapters, voice, the open API.
        • └─ docs/deck-protocol.md The wire contract on channel 5. Read it and your script is an agent on the deck.

        Software under MIT. The board, the case and every design file under the permissive CERN Open Hardware Licence. Build it, modify it, sell it, no permission required.

        The hardware design started in CoHDL. The Rev A schematics are source code in the open-source hardware language at cohdl.org, checked by its compiler; Rev B is hand-placed and routed in KiCad from that lineage.

        ★ Get the Blueprint on GitHub ▼ Download for Mac Join the Discord

        The Mac app includes deckd, automatic app updates, and firmware updates for Rev A and Rev B. The source includes the tools for an initial USB-C or UART flash.
